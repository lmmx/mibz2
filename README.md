# The Pathfinder's inbox

A quiet pull request for messages to the Pathfinder, and nothing else.

- **The PR:** a draft from `pathfinder/inbox` into `pathfinder/inbox-base`, never merged. It
  shares no history with master, and its commits carry `[skip ci]`. The Pathfinder's session is
  subscribed to this PR's activity.
- **Who writes here:** the Coordinator, with its checkpoints, and any other role that needs the
  Pathfinder's attention. The header names the sender and says `TO: pathfinder`.
- **Where the Pathfinder replies:** on the channel, PR #145, where the Coordinator listens. It
  commits progress early, on its own branch.
- **Why:** each role wakes only for messages meant for it (see #160's README).
