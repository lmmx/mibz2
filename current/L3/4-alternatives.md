# 4. Alternative decoder architecture

## Service-core

- **Purpose:** test whether dedicated service threads improve whole-decoder wall and processor cost, in order to serve 0 ([registration](https://github.com/lmmx/mibz2/pull/258)).
- **Established:** #258's valid ten-thread comparison returned speed 1.045 (1.017–1.073), 12.7% less CPU, RSS 64 versus 74 MiB; FOR SVC2@10, not adoption ([result](https://github.com/lmmx/mibz2/pull/145#issuecomment-6729896575), [correction](https://github.com/lmmx/mibz2/pull/145#issuecomment-6730014313)).
- **Premise:** preparation starvation was observed, but a larger lookahead admission threshold has not been proved to improve wall time. Prepared occupancy can reach L+K−1; it is not a strict L cap. Service idle does not itself prove an eligible preparation opportunity ([Researcher](https://github.com/lmmx/mibz2/pull/145#issuecomment-6730484783)).
- **Status:** #271's direct-L design is worthwhile, but [Researcher re-review](https://github.com/lmmx/mibz2/pull/145#issuecomment-6730774618) retains a queue-admission HOLD: four fixtures with inconsistent requested rounds, raw parity, impossible idle share and NaN still return VALID. These are evidence-contract repairs, not a new performance bar. Guardian D045 independently holds further service-core timing and production admission pending reached-path safety evidence ([D045](https://github.com/lmmx/mibz2/pull/145#issuecomment-6730103867)). No new workstation run is queued.

## Run-fed table construction

- **Purpose:** test whether run records can reduce complete move-to-front and table-building cost, in order to serve 0; an arm's STOP pauses that arm on its runner, not the line ([PROTOCOL §11](https://github.com/lmmx/mibz2/blob/cb02fd95/docs/team/PROTOCOL.md)).
- **#269 measured arm:** D048 [closed D044 for this frozen CI diagnostic only](https://github.com/lmmx/mibz2/pull/145#issuecomment-6730547798). Run 42549324025 was VALID and judged Q1 STOP on its pinned CI worker: R_stage 1.1592 (1.1387–1.1801), fallback 1.110, worst synthetic 1.546. The fill cost 1.332 versus today's build 1.432 nominal c/B, but emitter 1.508 versus 1.290, sort 0.317 and fallback loss outweighed it. Run-heavy one-byte/pattern blocks returned roughly 0.64. These phase readings are nominal clock-scaled times, not measured cycles or an additive counterfactual ([journal](https://github.com/lmmx/mibz2/blob/66edecbe2b1924594e485e1f956dbee8ed9beda2/docs/journal/2026-11-09-run-fed-stage-result.md)).

Removing sort alone still leaves a nominal cost gap. R_floor 0.321 and R_warm 1.010 weaken a simple store-floor premise but do not uniquely identify the binding cause.
