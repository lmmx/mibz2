## 0. Result

- **Runs are free in the mathematics (P, Lemma §1).** T⁻¹ is a translation on each letter.
  - *Equal bytes:* if the walk's points k and k0 lie in one letter with offset δ = p_k − p_{k0},
    then for every j < L the points p_{k0+j} + δ lie in the same letters as p_{k0+j}. So the
    walk from k repeats the walk from k0 for L points: equal letters, equal words, equal bytes.
  - *The resume point:* the walk resumes at p_{k0+L} + δ.
  - *L(δ):* the first j at which p_{k0+j} + δ leaves its letter's bottom interval. Equivalently,
    the first j at which the running minimum of the room on δ's side falls below |δ|.
- **The counts (C, all 233 Wikidata blocks).** A run is taken only from a source whose
  continuation was itself walked, not copied, so the rooms along it are known:

  | β | points a letter | calls a letter | calls ÷ points | bytes a call | words not made |

  | 1.4 | 1.229 | **0.544** | 0.44 | 25 | 43% (6.45 B a letter) |
  | 1.5 | 0.664 | **0.355** | 0.53 | 39 | 33% (5.00 B) |

  - *Run length:* mean 3.2 points. 35% of the run points are in runs of 2 and 1.1% in runs
    over 64; the longest is 485.
  - *The source:* using the most recent walked visit instead of the first changes the counts by

  - *Without the walked-source constraint,* the best of the last 8 visits would give 0.32 calls a

- **The trade (M).** With runs, β = 1.4 makes 0.544 calls a letter, fewer than the plain walk's

- **What the decoder stores (P, M).** A walked point records its point, its place and its two
  rooms (2 × u16): 12 B.
  - *Size:* 0.217 r walked points at β = 1.5, so 2.6 B a letter; 3.4 at β = 1.4.
  - *Where it lives:* the induction's dead top slots hold about 6.4 B a letter.
  - *A run step:* one rank for the letter, a last-visit lookup, a forward scan of the source's
    rooms (mean 3 compares), one copy of the run's bytes (its two places), and a jump to the

## 1. The lemma (P)

**Setting.** As in records 21 and 23: the stopped exchange on D = [0, m). T⁻¹(y) = y + back(α)
for y ∈ J_α (the bottom interval of α). The upward walk p₀ = x_μ, p_{k+1} = T⁻¹(p_k) writes
w_{a_k} at [place_k, place_k + |w|), where a_k is the letter whose J contains p_k.

**Lemma (runs).** Let k0 < k with a_{k0} = a_k, δ = p_k − p_{k0}, and let L be the least j ≥ 1
such that p_{k0+j} + δ ∉ J_{a_{k0+j}}, capped so that k0 + L ≤ k. Then for 0 ≤ j < L:
- *(i)* p_{k+j} = p_{k0+j} + δ and a_{k+j} = a_{k0+j};
- *(ii)* the text at [place_k, place_k + B) equals that at [place_{k0}, place_{k0} + B), where
  B = place_{k0+L} − place_{k0};
- *(iii)* p_{k+L} = p_{k0+L} + δ.

*Proof.* By induction on j. At j = 0, (i) holds by hypothesis. If p_{k+j} = p_{k0+j} + δ, and that
point lies in J_{a_{k0+j}} (j < L), then a_{k+j} = a_{k0+j}. Both points are moved by the same
translation back(a_{k0+j}), so p_{k+j+1} = p_{k0+j+1} + δ. (ii) follows because equal letters
write equal words, so the bytes are equal. The cap k0 + L ≤ k makes the source bytes written
before they are read. ∎

**L from rooms.** Write ρ⁺_j = (end of J_{a_{k0+j}}) − p_{k0+j} − 1 and ρ⁻_j = p_{k0+j} −
(start of J_{a_{k0+j}}). Then p_{k0+j} + δ ∈ J iff −ρ⁻_j ≤ δ ≤ ρ⁺_j. So L is the first j at
which the running minimum of ρ⁺ (if δ > 0) or of ρ⁻ (if δ < 0) falls below |δ|. Only the
source's rooms are needed, not its letters.

## 3. For the kernel (M; the clock is the Pathfinder's)

**At β = 1.5:** calls a letter fall from 0.664 to 0.355, at 39 B a call against 21. If the
writer's cost is per call, as the Pathfinder found, that is about half.

**At β = 1.4:** calls fall to 0.544, still below the plain walk at 1.5, with 1.45 B a letter more
of words unmade.

**The cost of a call,** run or point: a rank, a last-visit lookup (u32 a letter), and a scan of
about 3 rooms on a run. Per walked point it also stores 12 B. This writes the bytes once each, so
total copying is unchanged; what falls is the number of calls.

**Not counted:**
- the scan's instructions in the kernel;
- the cost of the 12 B records, in the dead top slots;
- what a run's longer copies cost against 16-byte word copies.
