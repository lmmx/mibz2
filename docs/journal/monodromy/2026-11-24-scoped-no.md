# 2026-11-24 · MONODROMY 106 · The scoped no, stated as one theorem over a declared decoder class, with its hypotheses and its open residue; and four changes to how I work

## 1. The class

**Λ\*** = 𝓡 (record 103 §1) ∪ single-row positional facts (charged, main-theorem §1a clause 1) ∪ k-local multi-row facts (record 100 §3a) ∪ Λ_agg(𝒫, D) (record 101 §3). A decoder over Λ\* writes each output byte either by a chain link whose path contains the byte's row, or by placing a fact whose path contains it at a position some positional fact supplies.

This class **includes** part of global E2: every positional rule whose input is block histograms plus the records of a declared row set. It **excludes** schematic facts over scattered sets with fine input (record 105 §1). That exclusion is the residue, stated in §3.

## 2. The theorem [proved from records 100, 101, 103, given the two counts]

For a valid column c let J₁ be its width-1 rows, U(𝒫, D) the rows no blind valid flip moves (record 101), and Coll_k the rows whose k-local key is shared.

**Theorem N.** Every decoder over Λ\* with T1 has, on every valid c,

  c₁ ≥ h₁ − |J₁ ∩ U(𝒫, D)| − |J₁ ∩ Coll_k|.

*Proof.* Take x ∈ J₁ outside U and Coll_k. Its byte is written by a fact f whose path contains x.
- If x is f's start row: f is used by a link at x (charged at x), or it is placed by a positional fact for x. That positional fact is single-row (charged at x), or multi-row; a k-local multi-row fact has x ∈ Coll_k, and a Λ_agg fact cannot fix pos(x) for x ∉ U (record 101 Lemma 2). Both excluded.
- If x is interior to f's path: record 103's induction applies unchanged, whatever placed f, and ends at a compose joined at x.
Each such x has an event attributed to it; events have one row. ∎

**Corollary (the no, conditional).** If on a block |J₁ ∩ U| + |J₁ ∩ Coll_k| < h₁/2, no decoder over Λ\* meets δ = 1/2 there. Status of the two counts:
- Coll_k: ≤ 0.0034·(random rows) at k = 6 **in expectation under model I** (record 100; not per block, N-1 break 4);
- U: small iff ν′ is large, **unmeasured** (NEEDS M-4).
So the no is **a conditional effect with an unproduced prerequisite**: NEEDS M-4, and a per-block collision count.

## 3. What it does not say

- Nothing about decoders outside Λ\*. In particular a rule that reads Θ(n) fine-grained inputs once and places many rows, i.e. a schematic fact with an o(|S|) derivation. No construction is known and no obstruction; it is the only route to a yes that this theorem leaves.
- Nothing about machine time (record 105 §2), nor the unit price of an event.
- It is not obtained by refuting stream N's premise. I have not read Neon's P_N-1, P_N-2 and do not use them.

## 4. Changes to how I work (Louis's invitation, via the Coordinator)

1. **Name the operation before screening a framework.** A candidate is first written as an operation on facts (what it composes, on which row sets, with what description). Only then is it classified. Records 104–105 did this; it replaced a framework screen with a bijection.
2. **A closure must exhibit its simulation and say whether it preserves cost.** "It is in 𝓡" without a cost-preserving map is recorded as *unplaced*, not closed.
3. **A no is one theorem over a declared class, with a "does not say" section.** No table of closed branches stands in for it. §5 of main-theorem.md is now an index to records, not the argument.
4. **Obstructions carry four fields:** obstruction, scope, escape, transferable insight.
