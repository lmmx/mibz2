**Conventions.**
- *Sites:* site x (1 ≤ x ≤ n − 1) sits between rows x − 1 and x; the report's gap g is x − 1.
- *λ(x)* is the LCP of the two cyclic rotations at rows x − 1 and x.

## 1. The exact correspondence

**1a. Reducible LCP is the gap map (P; C, 0 violations in 233 blocks).**
- *The rule:* for x ∉ D, LF(x − 1) = LF(x) − 1 and λ(LF x) = λ(x) + 1. This is the report's
  LCP(τ g) = c·LCP(g), and it is exactly Kärkkäinen–Manzini–Puglisi's reducibility rule read in
  rank order.
- *Hence:* **a site's LCP is reducible iff the site is not in D.** The irreducible LCP values are
  λ on D, which is to say at the chain terminals.

**1b. A chain's length is its LCP growth (P; C, 0 failures).**
- For a chain i → … → t: ℓ = λ(t) − λ(i), and d(x) = λ(t(x)) − λ(x) at every vertex.
- *So:* length is the terminal LCP minus the initial LCP, as the CHECKPOINT says. It is **not** the
  terminal LCP. Long chains start deep: the longest chain per block runs 484–17,540 steps.

**1c. q_k is the survival function, and also the exact-distance count (P; C, 233 of 233).**
- *The two readings agree:* record 63's B_k = ∪_{j<k} LF^(−j)(D), restricted to sites, is
  {x : d(x) < k} (record 63, §4a). Each chain of length ℓ has exactly one vertex at each distance
  0 … ℓ. So:

  **q_k (sites) = #{sites with d(x) = k} = S(k) = #{chains with ℓ ≥ k}.**

- *ChatGPT's warning, resolved:* q_k counts **vertices at exact depth k**, and that number equals
  the number of **chains surviving to length k.** It is not the number of chains *ending* at k,
  which is q_k − q_(k+1).
- *Checked:* the two vectors, k = 0 … 8, are identical on all 233 blocks. q_0 = r − 1, one per
  terminal.

**1d. The off-by-one and row 0 (C).**
- *Record 63's q_k* = S(k) + [k = d₀], where d₀ = min{j ≥ 1 : LF^j(0) ∈ D}.
- *What d₀ is:* row 0 is not a site. It enters B_k as the extra point record 63 noted. d₀ = 1 on
  229 blocks and 2 on 4.
- *Checked:* this reproduces record 63's vectors exactly, 233 of 233.
- *With a sentinel convention,* row 0 is the sentinel's gap and the term disappears.

**1e. Cyclic and periodic blocks (P).**
- *A τ-cycle needs infinite LCP.* A τ-cycle of length m would need λ(τ^m g) = λ(g) + m = λ(g), so
  λ(g) = ∞: the two rows are equal rotations. This proves the report's no-cycles theorem more
  simply, for any **primitive** block. LF is then a single n-cycle, and every λ < n.
- *A periodic block u^p:* stable LF keeps each copy's index inside a class of equal rows, so LF
  has p cycles of length n/p.
  - The n − n/p gaps between equal rows lie on τ-cycles of length n/p, and λ = ∞ on them.
  - These gaps lie in no chain and in no B_k, so they appear in no q_k.
  - The other n/p − 1 gaps are u's own chains.
- *In this corpus (C):* all 233 blocks are single cycles, with no sites left uncovered.

**1f. The terminals are bispecial (P, short).** A terminal pair's two rows have different preceding
characters, so λ(t) is left-special; it is right-special by definition. So it is bispecial: a
maximal repeat, or empty at a first-column boundary. This is the report's claim, VERIFIED. Its
Weiner-link reading is an interpretation (I).

**2a. The full sum is fixed (P; C).** Σ_{k≥1} q_k = Σ ℓ = **n − r** for every primitive block. All
233 blocks match, so the full profile carries no LCP information.

**2b. Telescoping (P; C, 233 of 233):**

  **Σ_{x∈D} λ(x) = (n − r) + Σ_{chains} λ(initial gap).**

- *So:* the sum of irreducible LCPs exceeds the fixed total length by exactly the LCP mass at the
  chain *starts*.
- *What the starts are:* gaps with no τ-predecessor, namely images of run boundaries and
  first-column boundaries, where λ = 0.
- *On Wikidata:*
  - Σ irreducible LCP / n ranges over 1.85–3.05 (median 2.02).
  - Σ start LCP / n ranges over 0.92–2.25 (median 1.08).
  - Against the bound of Kärkkäinen, Kempa and Piątkowski, Σ irreducible LCP / (n lg r) is
    0.11–0.18. The worst-case bound is far from binding here.

**2c. The truncated sum and Σ irreducible LCP are nearly orthogonal (C).**
- *Record 63's tail,* Σ_{k=2..8} q_k / r, has correlation **0.09** with log mean irreducible LCP.
- *Mean irreducible LCP has correlation −0.96 with r/n:* it is essentially a function of the run
  density.
- *Why they differ:*
  - **The tail counts short-range survival:** how many chains outlive depth 1 within 8 steps.
  - **Σ irreducible LCP is set by the long chains and their start depths.**

**2d. Reversal (P; C).**
- *The total LCP is reversal-invariant:* Σ_x λ(x) = Σ_{k≥1} (n − f_k), where f_k counts the distinct
  cyclic factors of length k, and that count is invariant under reversal. Equal on 233 of 233.
- *The irreducible sums are not invariant:* reversed over forward is 0.975–1.296 (median 1.117), and
  r_rev / r is 1.008–1.042.
- *The two mean irreducible LCPs* still have correlation 0.993 with each other across blocks.
- *q_k belongs to the forward text only:* LF chains are left extensions, so the reversed text's
  chains are right extensions and have a different profile.
