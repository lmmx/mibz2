# 2026-11-24 · MONODROMY 103 · G1 as a scoped provenance theorem, with its proof; the outside review's points, each accepted, refined or rebutted

## 1. The calculus, settled (answers the review's four specification issues)

- **Columns:** valid, i.e. LF is one n-cycle. This is the orbit-coverage hypothesis: the output chain visits every row.
- **Orientation:** a fact is forward (LF^h x = x + t, h ≥ 1). `mirror` gives the backward calculus (FL in place of LF). A derivation uses one orientation throughout; the theorem is stated for forward and holds for backward by the same proof on FL. Mixed orientation is outside this theorem.
- **Free:** `prim`, `mirror`, `restrict`. They are the input and bookkeeping.
- **Charged, each once per node of the derivation DAG actually built** (reuse is free; no unfolding): a `compose` whose result has a one-row domain, attributed to its **join row** LF^{h_f}(x); a `join` never has a one-row result.
- **Charged, each once per execution:** an output chain **link**, attributed to its start row. A link emits a fact's word from one row.
- c₁ = the number of charged events. This is record 102 §3's convention; it supersedes the "attribute to the run it is built from" wording of d0d0232 (prims are free, so nothing is attributed to them).

## 2. The theorem [proved, prose; not machine-checked]

**Lemma A (run invariant).** If (I, h, t, w) is a valid forward fact then for each 0 ≤ j < h the set LF^j(I) is an interval contained in one maximal run.
*Proof.* All rows of I emit w₀, so I lies in one maximal run; LF translates an interval inside a run to an interval. Induct on j with the remaining word. ∎

**Corollary.** If LF^j(I) meets a width-1 run for some 0 ≤ j < h, then |I| = 1.

**Theorem G1 (scoped).** Let c be valid and D a forward decoder in 𝓡 with T1. For every row x of a width-1 run there is a charged event of D's trace attributed to x. Hence c₁ ≥ h₁, **and c₁ restricted to any set of width-1 rows is at least its size** (row-preserving, so streamwise floors follow).

*Proof.* The output chain is a sequence of links whose paths tile the orbit, which is all rows. Take the link whose path contains x, with fact f = ({y}∪…, h, t, w) started at row y, and x = LF^j(y), 0 ≤ j < h. If j = 0 the link is attributed to x. Otherwise define P(f, y, j): "x = LF^j(y) with 0 < j < h_f, y ∈ I_f". By the corollary f restricted to its rows through x has |I_f| = 1 at every node below. Induct on f's derivation:
- `prim`: h = 1, so j > 0 is impossible.
- `restrict f′`: P(f′, y, j) holds; recurse.
- `join(g, g′)`: the result has |I| ≥ 2 and passes through x, contradicting the corollary.
- `compose(g, g′)`: if j < h_g, P(g, y, j); recurse. If j > h_g, P(g′, LF^{h_g}(y), j − h_g); recurse. If j = h_g, this compose's join row is x; by the corollary its result has a one-row domain, so it is charged and attributed to x.
The recursion ends at a charged compose node of the built DAG. Distinct rows get distinct events, since an event has one attribution row. ∎

**What it is and is not.** A provenance theorem for the rigid calculus. It is not a bound on machine cost, nor on algorithms outside 𝓡. A claim "algorithm X is in 𝓡" needs a simulation that maps X's operations to events without inflating its cost; records 98–99 give that only for the plain walk, Open, pointer jumping as x→LF→LF², and splice contraction as described there. **"List ranking" and "sorting" as families are not covered** (review §3, accepted).

## 4. The uniform family (model I′) [definition]

**𝓖(S, m, k):** a scaffold string S over the non-hex alphabet with m slots; each slot is filled with k independent uniform hex nibbles; the column is the BWT of the filled text. Randomness lives in the *text*, not the column; this replaces model I's column-level independence. Statements are for every scaffold S and in probability over the fills. 𝓕 (the 238 blocks) is the validation set.

**Carried over** [proved under I′, same proof]: the repeats-are-wide lemma (a fill copied to two slots). **Not carried over:** record 101's "each candidate flip is valid with probability 1/2". Under I′ validity is the text order of three slots; exchanging two fills also moves the scaffold suffixes that tie up to those slots, so the column is not preserved and the exchange symmetry is not exact. It stays [conjectured]; NEEDS M-4 measures it.
