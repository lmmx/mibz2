## 3. The second claim, for reading only

**"Maximal regions with identical finite boundary-orbit itinerary" are the cylinder sets.** At fixed
depth k they are the atoms of P ∨ T⁻¹P ∨ … ∨ T^(−k+1)P, the intervals between consecutive points of
B_k. These are record 28's itinerary certificates J.

**Investigation 2's bands are the same kind of object, with the depth replaced by a stopping time.**
Each band is a maximal set of entrances sharing an itinerary *until the return to S*. So it is a
cylinder of the first-return partition, not of a fixed depth.
- *Hence:* related but **not identical.** The bands' width (A/U ≈ t) is set by the section's
  threshold, while the fixed-depth cylinders' widths are set by the block alone.

## 4. The amendment (Louis via ChatGPT): (a) and (b)

**(a) B_k is exactly O3's depth-k boundary set (P).** Take T = LF and preimages.
- *Why:* rows x − 1 and x get different depth-k labels (run(x), …, run(LF^(k−1) x)) exactly when LF^j(x)
  is a run start for some j < k. While no earlier step has separated them, LF^j(x − 1) = LF^j(x) − 1,
  so the first separation happens precisely when LF^j(x) ∈ D_s.
- *So:* the depth-k boundaries are ∪_{j<k} LF^(−j)(D_s) = B_k, apart from row 0, which can enter B_k
  but never bounds a site.
- *Hence:* **q_k = V₀(k + 1) − V₀(k)**, with the one extra point at k = 1 (q₁ = 10,955 against
  10,954) being row 0.
- *Checked:* record 63's independent counts reproduce O3's (record 62) exactly. O3's numbers stand;
  nothing new was needed.

**(b) "Process common-itinerary cylinders collectively" adds no algorithmic idea beyond what the
program has (I, with P where marked).** There are three ways to act on it:
1. **Construct the partitions.** That is O3, and it raises the work: Σ arcs 1.78 r → 4.08 r (record 62).
2. **Process the boundary-orbit events in time order,** paying once for each point of B_{k+1} ∖ B_k
   until the orbits collide. **That is what right-end Rauzy–Veech does**, and §2 shows Cells' count
   tracks Σ q_k. The forest does the same by levels.
3. **Certify a long shared itinerary from its endpoints, without the intermediate refinements.**
   Three such certificates already exist:
   - *Zorich division* (investigation 1, record 55): h = ⌈(x + w − t)/δ⌉ certifies a long shared
     itinerary in O(1), but **only for repeated passes through one atom**, a periodic itinerary.
     Record 20 found none on Wikidata.
   - *The one-bit certificate* (investigation 1): adjacent excursions are equal, propagated locally.
   - *Itinerary certificates* J = ⋂ (I − s_j) (record 28): computed along the path, not from its
     endpoints.

   The separation depth of a gap is the length of its gap path. A general endpoint certificate for a
   long *aperiodic* shared itinerary would have to know that depth without walking the path.
   Pointer-jumping on the gap graph gives that only after Θ(n log n) preprocessing (P). **No candidate
   with cost below the walk exists in the report or in the program (Conj).**

**Verdict:** the report gives an **interpretation** of existing work, and a useful explanatory variable
(Σ q_k, §2), **not a new route.**
