# Astra C · Can the marked cursor supply its own byte sources?

18 November 2026. Independent investigation for MONODROMY and the Researcher.

## Marked convention and first experiment

Let $L$ be the input last column, (p) its zero-based primary, (T) stable LF and (S=T^{-1}). Starting at row (x=p), emit the first-column byte (F[x]=L[S(x)]), replace (x) by (S(x)), and continue for exactly (n) bytes. This is the order of the pinned `Plain::walk`. A short marked cycle repeats, including a final partial traversal. Other cycles need no output addresses. For example, `L=100` at `p=0` has the single cycle (0,1,2) in forward order and spells `001`. Different marks in a column can spell different words.

**Proof.** Stable occurrence matching sends the (j)-th occurrence of (c) in $L$ to the (j)-th row of the (c)-bucket in (F). A maximal input run therefore gives one interval in that bucket on which (S(x)=x+d) and (F[x]=c). Counting byte totals and scattering one descriptor per coalesced run by byte and occurrence order constructs these local laws directly from the run input. A lookup at the current row gives both the next letter and the next row. Its output destination is the cursor. This already answers the existence question, at the price of a serial row lookup per byte. The question for the real blocks is which of these lookups can be eliminated, including the price of recognizing the opportunity.

The first experiment will certify several steps of the cursor at once. The intersection of the translated input intervals along a path is an interval of starting rows. On it both the emitted bytes and the translation to the row after the path agree. A previously completed occurrence in the output can then supply the bytes, and the current cursor supplies their destination. The cost test counts construction of certificates from the input, misses, successful queries, source reads, writes and the serial dependence through the cursor. Diagnostic uses of dense LF will be identified explicitly.

## Baseline and evidence

The baseline is the post-0.5.6 pin `1edb29fdc3d42dfddfc3d60e46456b611323760c`. Eager and lazy Cells isolate the marked row and induce ordered concatenations. Their one-scan writer obtains the marked rotation, places rule children and reuses completed output bytes in its command pass. The pinned parallel plan ordinarily chooses lazy from eight workers, with an i9-specific seven-worker lazy path. On frozen, the published counts are 92,570 cuts, 28,710 stored rules and 9,628 output copies of 735,582 bytes. These are comparators. The previous verification of slowly decaying cylinder boundaries motivates counting the intervals actually encountered by the marked cursor.
