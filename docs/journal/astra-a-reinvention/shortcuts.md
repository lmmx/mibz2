# Learning a return address from two completed output spans

## Operation and proof

Let a row x name a cyclic rotation. Following Ψ, the inverse of stable LF, emits F[x] and advances to Ψ(x). The reference starts at the primary and emits exactly n bytes, as in the pinned Plain walk. For a maximal byte-c run [s,s+w) of L, let t be the number of bytes below c plus the number of preceding c's in L. Stable ordering gives Ψ(t+j)=s+j for 0≤j<w. Thus [t,t+w) starts as a leaf with displacement s−t and literal c. The leaves tile the row space. This initial partition is available from two scans of capped records and two 256-element prefix sums.

A learned leaf U consists of a domain [a,b), length m, signed displacement e and a source in the completed output. Every row x of U emits the same m-byte word and ends at x+e. Look up the current leaf, emit its literal or copy the corresponding source, and advance by its displacement. A final visit may take only a prefix. For consecutive completed visits to U and V, let V have domain [c,d), displacement f and length k. Their *whole* concatenation is valid on

$$J=[\max(a,c-e),\min(b,d-e)).$$

For every x in J, the first word ends in V, so the concatenated word has length m+k and exit x+e+f. Its source is the start of the two spans just emitted. Installation therefore requires no byte comparisons, individual LF probes, grammar search or walk to discover the exit row. Even when m+k is in the thousands the proof takes the same two endpoints and two displacements.

If J has width at least two, replace U on J by this word. The up to two residual subintervals keep U's old word and displacement. A whole-domain replacement changes one record. A proper split adds one or two boundaries, monotonically. If the preceding installation changed the very leaf from which the current visit's descriptor was read, forget that visit as an operand for the next installation. This handles self-transitions without stale geometry. Skipping width one preserves correctness for every input. On a full-period traversal that starting row has already been consumed. A final phrase closes the output without attempting another installation.

**Induction invariant.** The live leaves remain a disjoint tiling. Each descriptor satisfies its spelling and exit claim everywhere on its domain. Its nonliteral source ends no later than the next output cursor. The intersection contains the row that just demonstrated the pair. Residuals inherit a valid descriptor, and the concatenation argument proves the new one. Induction gives the forward pre-RLE1 spelling from any primary, including several cycles, a primary cycle whose length does not divide n, and clipping inside the final phrase. The following RLE1 expansion and CRC are the ordinary ones.

The construction borrows the adjacent-phrase learning rule from Miller–Wegman dictionary compression. A chronological LZMW compressor has the text already. Here, row recognition must determine both the spelling and its exit. We keep one active word per cell of a partition, learn only on the intersection of the two active cells, and pay for splits. This distinction makes the learned map usable while the bytes are still unknown. The translation-intersection identity itself is the classical itinerary certificate. The change lies in *constructing it by composition from earlier completed writes* and providing the data structure that recognizes it. ## Recognition, allocation and dependencies

In the measured model, each 64-row tile has a 64-bit original-start mask and a prefix count of starts before the tile. Popcount up to the queried bit gives the original run-image number, even inside a tile with no starts. The initially dense array of root records uses that order. On a proper split, its parent becomes a routing record and two or three adjacent children are appended. The next child is the base index plus the number of separating coordinates at or below the query. Width-one leaves and whole-domain updates allocate no routing records.

For a bzip2 block, a row, length or offset fits in 20 bits and a signed displacement fits in 21. A leaf's two endpoints, displacement, length and literal or source fit in 16 bytes with a tag. A routing record fits in the same space. If q distinct boundaries were inserted in s proper splits, live record storage is exactly 16(r+q+s) bytes. Add 16 ceil(n/64) for tiles and 2,048 bytes for counters, alongside the input records and the n-byte output. Since q≤n−r and s≤q, a contiguous append-only implementation may reserve virtual space for 2n−r nodes after the census. Only initialized nodes are charged as touched. Geometric reallocation would add copying or the table for separate allocation slabs would add loads. The cost model makes the contiguous-reservation choice explicit.

If h internal routing nodes are visited in all and there are p phrases, recognition reads p tiles and p+h nodes. Every node address depends on either the tile or its parent. The current row itself depends on the descriptor selected in the previous iteration. A phrase can need a data-dependent source address as well. Dividing total work by output bytes misses these chains. In the worst case the tree height is linear in the number of boundaries in a root. The reference keeps only the last selected leaf in registers for composition.

## Frozen decision

The first inexpensive probe ran backwards and found 84,434 phrases, 38,614 installations and 11,403 new boundaries. The forward Ψ order delivers the production output directly and handles an arbitrary short primary cycle in n steps. It needs 83,504 phrases and 37,618 installations on the same block. 27,908 installations replace a whole live interval. The other 9,710 create 12,154 boundaries. The writer emits 56,508 literals and 26,996 source copies covering 843,423 bytes. The 73,048 records and 14,062 tiles occupy 1,395,808 bytes including counters. The dense counting probe's winner-per-row array is absent from this construction.

The adverse count is 96,288 internal routing reads, including a path of depth 42. This yields 263,296 tile and node reads for 83,504 output advances. These counts warranted pricing the address trace against the baseline’s more sequential writer. [Causal reference](shortcut.py) · [All-row interval falsifier](check.py)

## Permanent domains and retirement

The split model's 96,288 frozen routing reads suggested a different question. What can be learned if the dictionary may *never* partition an original domain?

Keep one current word on each immutable original domain U. With adjacent completed visits U,V as above, install UV only if [a+e,b+e) is contained in [c,d). This makes the composite valid everywhere on U. On failure mark U as finished. All future lookups still emit its last learned word.

**Retirement theorem.** The image of U after its m-byte word is an interval of the original width. It contains the current row of V. If the image protrudes from V, at least two of the *permanent original domains* meet the image. The next original atom of those two entrances differs. No longer common original-domain itinerary on all of U exists. All future learning at other domains preserves their boundaries. One failed check therefore settles U permanently in this model. Different original atoms may emit the same byte. The proof uses the atom identity and the associated row advance.

**Singleton theorem.** A word certified on at least two rows maps those rows by translation at every intermediate original step. Every original domain encountered has room for that width. It cannot pass through a singleton. Thus every original singleton encountered on the marked cycle must be emitted as an individual literal, irrespective of the learning schedule in this model. On a full cycle there are exactly as many singleton visits as singleton roots. They need neither a mutable word nor a containment test on their outgoing edge. A wide-to-singleton transition certifies permanent failure.

**Representation.** Keep the static tile directory. Each original run has a four-byte header. A singleton header holds its successor row and literal byte. A wide header indexes one mutable 16-byte record with its fixed endpoints, displacement, length, literal or source, and the finished bit. The first census can count wide roots, so the three arrays can be sized exactly before the scatter. With w nonsingleton roots, the working bytes for this representation are 4r+16w+16 ceil(n/64)+2,048, excluding the already-delivered capped stream and output. Each visit has exactly two serial metadata reads (tile and header), plus a third on a wide visit. The destination address of a source copy becomes available with its descriptor.

**Frozen evidence.** 35,116 of 51,184 roots are singletons. The 16,068 wide records give 688,864 working bytes. The algorithm emits 117,399 phrases, including 40,731 copies covering 823,263 bytes. It installs 25,283 whole phrases and retires 6,902 roots. The resulting 317,081 cursor-dependent metadata reads have maximum depth three. The split model has fewer visits but a variable search depth. The two schedules make different decisions and produce the same final hash. [Reference](whole.py) · [Frozen counts](evidence/frozen-whole.csv)

**Relation to Precopy.** Kärkkäinen, Kempa and Puglisi prove the constant-offset property inside an s-run and construct s-run boundary sets from adjacent-rotation common suffix lengths. Here the initial input for each worker is the existing capped run stream. Each source is an already completed output span, and the variable-length jump and its exit are learned together on a successful containment. The argument makes no claim of priority for using equal neighbouring trajectories or for copying repeated outputs. [Slashing the Time for BWT Inversion](https://www.cs.helsinki.fi/u/tpkarkka/publications/dcc2012.pdf)


For the permanent-domain version, p visits cost exactly 2p+V cursor-dependent metadata reads, where V counts wide visits. At most w failures can write a finished bit. The control work is O(m+r+ceil(n/64)+p+256), with n output bytes written and at most n bytes copied from earlier output. The whole-domain per-visit routing depth is bounded independently of n. These bounds cover arbitrary primary periods.

A five-row witness has L=(1,0,0,1,0), primary zero and Ψ=(1,2,4,0,3). Rows 0 and 1 both spell 00 over two steps. Their two-step exits are 2 and 4, so the common spelling cannot certify a single displacement. The first one-byte domain [0,2) therefore retires correctly when its image [1,3) straddles the two atoms with the same next byte. [Exhaustively generated witness](evidence/small.json)
