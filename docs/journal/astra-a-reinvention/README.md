# Astra A · Inverting a block by changing its alphabet

18 November 2026. Independent investigation for MONODROMY and the Researcher.

## Starting point

The input available on mibz2's run route is a primary row and a stream of 16-bit records with lengths capped at 127. Huffman, RUNA/RUNB and MTF decoding precede it. An expanded last column, a suffix array, a finished grammar and an oracle spelling each have a construction cost. The reference on a full-period block is the eager or lazy induction followed by the one-scan owner writer. Short periods and refused blocks have different paths. The target is a block worker sharing memory bandwidth with six to nine other workers on the i9-10900K.

On the frozen block earlier work finds 92,570 cuts, 28,710 long rules and 9,628 deferred copies. Earlier proofs fix the copy volume for any expansion-once traversal of that grammar. The first-occurrence writer illustrates the cost of a dependent read even when fewer fields are accessed. The verified arrival schedule pays for ordering; the boundary-orbit profile predicts work in the two constructions tested. Neither observation is a lower bound for an inversion that changes the alphabet. An earlier delimiter parse already built a phrase column by refining suffix intervals; its dictionary discovery must be included in a comparison.

## First experiments

* Can predictable byte adjacency recover whole chains from a bigram census? Count what the census determines and exhibit ambiguities before pricing a traversal.
* Can a reversible substitution produce an ordered BWT of tokens directly from old runs? Test a simultaneous substitution of ordered, disjoint byte pairs, including recognition, the rank of the surviving primary, and the physical fragments processed.
* Can information about a whole repeated phrase be obtained by testing a candidate from the decoded prefix or a fixed dictionary? Check what a verification query must establish, including its coordinate of re-entry.

The frozen block is large-block ordinal 0, stream block 1, primary 264,045. The comparison sample is fixed in advance at the ten archived large blocks numbered 0, 24, …, 216. Admitted eager and lazy populations will be identified separately. Exact event counts, layout or cache estimates, and unresolved questions are recorded separately. A count of removed text rows alone does not qualify a route for a decoder build.
