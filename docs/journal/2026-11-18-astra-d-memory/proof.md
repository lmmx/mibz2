# Correctness and memory bounds

## Forward reconstruction from affine pieces

Let a maximal L run of byte `c` cover rows `[a,a+w)`. Stable LF maps it to `[b,b+w)`, where `b=C[c]+rank_c(L,a)` and rank excludes row `a`. For `0≤j<w`, the forward successor satisfies `Ψ(b+j)=a+j`. The byte to emit at F row `x` is `F[x]`. Starting at the bzip2 primary row and emitting before each successor produces the text in forward order. This is also the sorted-rotation definition for a periodic block. Iterating exactly `n` times repeats a short marked cycle to the required length. It agrees with a stable inverse-permutation walk on any column and in-range primary.

Intersect the F images with consecutive 128-row tiles. Splitting preserves translation. Each header stores the first piece index, the first F character and a bit indicating whether cumulated symbol ends cross the tile. Only a mixed tile needs a search in the 256 symbol ends. A piece stores its inclusive local endpoint in the high byte and the unsigned bias `a+127-local_start` of its first row in the low 20 bits. The first endpoint at least as large as the local position selects exactly one piece. Adding the local position to its bias and subtracting 127 gives the successor row. There are at most `n` pieces. Both the index and bias fit for the tested entry bound `n < 2^20-128`, which covers all bzip2 blocks.

The builder coalesces adjacent physical recs, including fragments capped at 127. Two passes over the original records suffice. The first advances per-byte F cursors to count pieces per symbol. Their prefix sums give nonoverlapping ranges in the piece vector. The second fills these ranges in stable order and initializes every tile header. Both accesses within a byte's range advance. This scatter interleaves byte streams. Its real costs, including clearing on growth where applicable, depend on the trace. The live navigation arrays use `4*(tile_count+piece_count+256)` bytes. Temporary construction cursors, run input, symbols and the external output have their own lifetimes. All are charged by the native ledger when touched.

The forward walk emits each literal immediately. After four copies of a byte, the next token supplies its extra repeat count and resets the streak. A final unfinished run returns the same error as the worker. CRC updates cover the newly produced slice after each 4,096 inverse rows, including a run crossing a tile boundary. Memory order here means a 4 KiB batch of inverse rows, which can produce a different number of final bytes. CRC failure clears the owned slot. The run route supplies validated physical records and an in-range primary. Other front-end routes use the pinned decoder.

## In-place RLE1 with a bounded directory

The worker has an empty, exclusively owned final slot. A physical-record count `s` bounds the number of lazy letters by `s+2` because isolating the primary can split one run into three. The release layout puts at most `128+13*(s+2)` bytes of entries, bytes and bottom slots in that vector. Under the tested guard this fits the ordinary AVX2 finish reservation of `n+64`, including when the one-scan writer sizes its destination to `n+32`. An append-to-existing-output caller stays on its original path. Each tested worker slot is cleared as in production. Zero stores from growing its initialized length are charged.

First find every RLE1 marker in the encoded bytes, skipping its count byte. Record its source and final destination, repeated byte and extra count. A source fits 20 bits, a destination fits 28 bits even at the maximum expansion of 259 output bytes per five encoded bytes. Each entry occupies eight bytes in the consumed run vector. Its maximum length and the actual final slot capacity are checked before changing any source byte. On insufficient room, copy the intact encoded bytes to worker scratch and run the ordinary finish into the same slot. On malformed RLE1 or CRC failure discard the owned result.

Markers divide the remaining input into literal intervals. Within each interval the displacement is constant. Source intervals are disjoint and ordered, as are their final intervals.

1. Move each left-shifting interval going forward, using overlap-safe copy. Its destination ends no later than its source end, so it cannot clobber a later source. It cannot clobber an earlier right-shifting or stationary source either. That earlier source ends no later than its destination end, which is at or before the current destination start.
2. Move right-shifting intervals in reverse order. Each moves to or beyond its own start and cannot damage an earlier source. Later right-shifting sources have already been consumed. Every destination is disjoint from all other final intervals.
3. Leave stationary literals in place. Fill the marker destinations from the recorded byte and count after all literal moves. The union is a disjoint cover of the decoded output. Truncate and verify the normal block CRC.

This proof allows overlapping copies, zero-length spans, changing signs and both possible final length orderings. Frozen reaches +79 bytes of displacement. Block 269 reaches −3 and +39. An overall block length or a single guessed copy direction would be insufficient. The original 12-byte directory estimate and the executable eight-byte packing are both recorded. ## Scope of the lower bound

With disjoint cold input and final destinations and an external consumer that requires a materialized result, transferring a compressed envelope of `C` bytes once and publishing `O` output bytes costs at least `(C+O)/O` useful bytes per output byte under the requested input-read convention. Whole cache lines round both extents outward. In the write-allocate model a first store to a cold external output line also acquires it, giving a line-rounded `C+2O` comparator for ordinary stores. A producer and consumer sharing a cache can hand off dirty data there. Non-temporal full-line stores can avoid acquisition. An unconditional bound of two DRAM bytes per output byte would require stronger boundary conditions.

Neither the boundary-orbit profile nor general sorting and permutation lower bounds prove an additional compulsory transfer for this family of BWT inputs. A full materialized word-sized row array is optional, as the forward construction demonstrates. The least proven traffic here is an interval between the compulsory bound and an achieved upper bound for the specified replay.
