## 3. Controls, candidate families, and diagnostic ablations

All arms charge **full end-to-end `C + E`** (`A6a + A6b + A6c + contraction + A7`) on every block using reusable scratch and `out` buffers (matching production's warm-cache worker loop).

### 3.1 Matched controls
1. **`ctrl_shipped_bidi`**: Exact production `Open` (`LIMIT = 16`, `OutQ16` `wire_xor`, `emit_bidirectional` / `emit` fallback).
2. **`ctrl_fwd_1lane`**: Matched single-lane `forward-emission` (`LIMIT = 16`, `OutQ16` `wire`, forward `emit`).
3. **`ctrl_fwd_4lane_online`**: Online 4-lane `forward-emission` (`LIMIT = 16`, `wire`, $K = 16$ spaced anchors tagged in bit 31 of `edges[anchor]` with zero auxiliary anchor array, 4-lane lockstep walk into reusable lane buffers, stitched into `out`).
4. **`ctrl_fwd_4lane_oracle`**: Optimistic pre-anchored 4-lane `forward-emission` lower bound (charging full `C_fwd` = `A6a + A6b + A6c_fwd` plus pre-anchored 4-lane `emit` directly into `out`, matching `ideal-permutation-structures`'s 4-lane consumer control).

### 3.2 Candidate constructor families (frozen from train-set census)
1. **Family 1 — Whole `F`-Bucket Elimination (`DictReturnMap`, exact forward `emit`):**
   - Computes exact retained `F`-bucket boundaries `r_first[0..257]` from sorted thick strips in $O(\text{ns} + 256)$, scores each `F`-bucket's literal fraction from `bands` in $O(\text{bands})$, selects top literal-heavy `F`-buckets (`lit_frac >= 0.70`, gated to skip if `< m / 6` would be eliminated), tags eliminated vertices with bit 31 (`ELIM_BIT`) while storing compact `new_id` directly in `edges[v]` for kept vertices $v \in K$ (always preserving `mark`), resolves $K \to E^+ \to K$ chains into compact `new_edges[0..new_m]` using a 4 KiB L1d direct-mapped inline cache (zero `HashMap`), and emits via exact production forward `emit`.
   - Frozen operating points from train:
     - `fb_elim_75_L16`: `LIMIT = 16`, target 75% eliminated, 1-lane forward `emit`.
     - `fb_elim_55_L16`: `LIMIT = 16`, target 55% eliminated, 1-lane forward `emit`.
     - `fb_elim_75_L24`: `LIMIT = 24` (trimming `A6b`), target 75% eliminated, 1-lane forward `emit`.
     - `fb_elim_75_4L_ora`: `fb_elim_75_L16` + optimistic pre-anchored 4-lane `emit` (upper bound on stacking with 4-lane MLP).
2. **Family 2 — Co-Located `Edge16` `F`-Bucket Elimination (`fb_e16_75_L16`):**
   - Same 75% literal `F`-bucket elimination emitting directly into 16-byte co-located `Edge16` (`12 B` inline payload, zero inline dictionary hashing).
3. **Family 3 — Pure 1-Hop Digram Contraction (`seq1hop_digram_L16`):**
   - Direct `[u16; 65536]` digram table contracting 1-hop `K -> E -> K` literal digrams with zero multi-hop chain chasing and zero `spelling` growth.
4. **Family 4 — BWT-Space Selective `F`-Bucket / Digram-Interval `LIMIT` BEFORE `A6b` (free oracle `C[0..256]` upper bound):**
   - Applies a lower run-width cutoff `limit_e` inside literal-heavy `F`-buckets (`0-9`, `A-F`, `a-f`, `-`) and `limit_k` outside, eliminating digram runs `(a, b)` of width `> limit_e` directly inside `endpoint.rs` (`A6b`) without charging the extra `records` count pass needed to know `C[0..256]`.
   - Frozen operating points: `sel_bwt_lim_8_16`, `sel_bwt_lim_12_16`, `sel_bwt_lim_16_24` (tests keeping `16` on literals while relaxing non-literals to `24`).

## 4. Measurement & decision rule (C2)

- **Machine:** 2-vCPU Intel Xeon @ 2.30 GHz KVM VM (Haswell, AVX2, 32 KiB L1d, 256 KiB L2, 45 MiB L3, no vPMU), single-threaded.
- **Compilation matrix:** Run both default baseline x86-64 (`cargo build --release --example bwt_digram_return_map`) and `-C target-cpu=native` (`RUSTFLAGS="-C target-cpu=native"`), reporting both separately.
- **Interleaving & repeats:** `7` interleaved repeats on the `116` held-out blocks (and `7` interleaved repeats on guard corpora `runs` and forced `text`). Within each repeat, execute arms interleaved block-by-block with rotating start offset `(k + blk + rep) % n_arms` so transient shared-VM CPU load hits all arms identically, AND record whole-repeat sums (`ms` median and `min..max`) plus paired per-repeat ratios (`arm / ctrl_fwd_1lane`, `arm / ctrl_fwd_4lane_online`, `arm / ctrl_fwd_4lane_oracle`, `arm / ctrl_shipped_bidi`).
- **Projection anchor (transparent VM-to-i9 ratio projection):**
  - Reference stage-1 1-worker i9-10900K anchors (`wikidata ×4`): $W_{1w} = 1,306.0\text{ ms}$, 3.0% gate $G = 39.18\text{ ms}$, $C_{\text{base}} + E_{\text{base}} = 1,068.0\text{ ms}$.
  - Projected i9 `C + E`: $\widehat{CE}_X = 1,068.0 \times (t_X / t_{\text{ctrl\_bidi}})$.
  - Projected net saving vs control $Y$: $\Delta_{X \text{ vs } Y} = \widehat{CE}_Y - \widehat{CE}_X$.
- **Verdict rule (frozen, C2):** PASS iff a concrete, non-oracle, byte-exact candidate clears $\Delta \ge +39.18\text{ ms}$ against BOTH `ctrl_shipped_bidi` and matched `forward-emission` (`ctrl_fwd_1lane` and `ctrl_fwd_4lane_*`) with non-overlapping 7-repeat spreads in both baseline x86-64 and `-C target-cpu=native` builds, without regressing guard corpora (`runs`, forced `text`). Otherwise STOP and record a scoped row in `frontier/dead-ends.tsv`.
