#### Mandatory Referee Mathematical Corrections Applied Verbatim to `CA-30` (`[proved, verified]`)
Independent adversarial probing by the Cycle 48 Referee (`referee_probe.rs`) caught **two mathematical statement bugs** in P1's initial `CA-48-H2` writeup (zero impact on code exactness or the `killed` verdict of `MB-12`), both corrected verbatim here and in `CLASSICAL-ATLAS.md`:
1. **Exact Power-of-Two Exception ($m = 2^k$, $k \ge 2$):** P1 initially claimed $\max_u (\pi(u) \oplus \pi^{-1}(u)) \ge 2^{b_m - 1}$ for *all* single $m$-cycles $m \ge 3$. In fact, $\max_u \xi(u) < 2^{b_m - 1}$ holds iff the top-bit set $T_1 = \{u : \text{top}(u) = 1\}$ (cardinality $m - 2^{b_m - 1}$) is a union of orbits of $\pi^2$. By Cauchy's cycle decomposition of $\pi^2$: if $m$ is odd, $\pi^2$ is a single $m$-cycle (impossible since $0 < |T_1| < m$); if $m$ is even, $\pi^2$ splits into two cycles of size $m/2$, so $|T_1|$ can be a union of $\pi^2$-orbits **iff** $m - 2^{b_m - 1} = m/2 \iff m = 2^{b_m}$. Explicit alternating cycles `0 -> m/2 -> 1 -> m/2+1 -> ... -> m-1 -> 0` (e.g., `(0 2 1 3)` at $m=4$ gives $\max\xi = 1 < 2$) produced **`7/7` counterexamples** across $m \in \{4, 8, 16, 32, 64, 1024, 65536\}$. Restricting to **non-power-of-two single cycles ($2^{b_m - 1} < m < 2^{b_m}$)** yields a rigorously proved theorem verified on **`5,000 / 5,000`** random non-power-of-two single cycles (`0` violations) plus all `17/17` real non-trivial single-cycle blocks!
2. **Valid Shannon Lower Bound ($H(\text{code}) > 24 - b_m$, NOT Marginal Bit-Plane Sum):** P1 initially summed marginal bit-plane entropies $H_{\text{bit}}(\xi) = \sum_{k=0}^{b_m-1} H_2(\xi_k)$ and argued $H_{\text{bit}}(\xi) + H(\text{code}) > 24$ invokes Shannon's lower bound. By subadditivity, $H(\xi, \text{code}) \le H(\xi) + H(\text{code}) \le \sum_k H_2(\xi_k) + H(\text{code})$ — an upper bound cannot certify a lower bound. **Valid corrected proof:** once $\xi(u)$ is stored raw in $b_m$ fixed bits (forced for $2^{b_m - 1} < m < 2^{b_m}$ by the corrected Cauchy $\pi^2$-orbit theorem), only $24 - b_m$ bits/row remain for `code(u)`. On blocks with $b_m = 18$ (`block-143`, `block-210`, `syslog-0`) and $b_m \in \{19, 20\}$ (`codedocs-0..3`), `24 - b_m <= 6` bits violates *both* pigeonhole ($|D_{\text{used}}| = 647\text{–}1{,}553 > 64$) and Shannon's lower bound **$H(\text{code}) = 6.15\text{–}7.20 > 6.00 = 24 - 18$ bits/row**, proving cold escapes are unavoidable in any 24-bit raw-$\xi$ layout!
