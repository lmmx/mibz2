- the concrete **witness**;
- its exact **scope**: which algorithms, representations and cost model it binds;
- the **escape condition**: which assumption a different formulation would have to drop.

## Foundational questions (track 1)

Each questions whether a current core operation is necessary. None is settled.

1. **Must the decoder follow an orbit at all?**
   - Every production kernel ends by emitting in LF-orbit order. Rows are visited one after
     another, or retained rows are walked one after another.
   - Is there a formulation in which output positions are computed rather than reached? For
     example, a potential or ranking function on intervals that places whole runs of output
     directly.
   - **Known obstructions:**
     - text-order run labels determine the text (record 84). Computing them *is* emission, so any
       "placement" must be cheaper than the labels it implies;
     - **Lockstep Boundary Shattering of $\Delta\boldsymbol{\tau}$ (Cycle 6, Theorem 6.1):** although $[D, P_{\mathrm{LF}}]$ has rank $\le r - 1$ and $\Delta_x = (\tau(x) - \tau(x-1))\bmod n = \alpha_{v(x)}$ takes $\le r$ distinct values (`1` global run on Sturmian $r=2$ words), Kempa's first-$\overline{D}$-hit map $v(x)$ has **`1.00000n` runs on 5/6 blocks** (`899,997/899,998` on `block-207`) and $\Delta\boldsymbol{\tau}$ has **`0.9864n–0.9996n` maximal constant runs**, ruling out $o(n)$-piece affine placement functions on BWT intervals;
     - **De Bruijn Condensation, Dyadic Squaring & Fourier Cauchy Obstructions (Cycle 7, Theorems 7.1–7.3):** (a) free $(L[x], F[x])$ digrams leave $\log_2 Z_1 = 2.59\text{M}..2.81\text{M}$ bits of Eulerian tour ambiguity, requiring Kotzig context depth $k^*(T) \in [925,\, 10{,}526]$ for unique graph condensation ($Z_{k^*}=1$); (b) pointer-free stream-merge squaring $\mathrm{LF}^{2^j}$ saturates near $n$ by $j=10$ (`\sum_{j=0}^{19} r(\mathrm{LF}^{2^j}) = 12.87\text{--}14.56n$); (c) in Fourier space $\widehat{P}_{\mathrm{LF}}$ has `r_cauchy == r` active Cauchy generators (`0` cluster cancellations out of `509,269` run heads), pricing superfast Cauchy/NTT resolvents at $\Omega(rn)$;
     - **Intra-Block Parallel Escape (`SPOD-Coset512`, Cycle 10 Theorem 10.2B):** while pre-walk global offsets $\tau(q)$ are locally unidentifiable ($n=7$ witness `1001000` vs `1100000`), post-walk stitching on the 2-adic coset `(cur & 511) == 0` breaks the single-orbit sequential bottleneck across $P = 4..16$ threads (`3.89–15.28×`) with 0 visited bitvectors;
     - **Anashin 2-Adic Odometer Conjugacy & Hensel Entropy Saturation (Cycle 13, Theorems 13.1–13.2):** conjugating $\mathrm{LF}$ into a 1-Lipschitz 2-adic automaton ($\mathbb{Z}/2^k\mathbb{Z}$ triangular quotients) is equivalent to computing $\tau$ itself (`332` power-of-2 checks); in standard coordinates $\sum_{a=0}^{2^k-1} N_{\mathrm{runs}}(C_{k,a}) = \sum_u \min(w_u, 2^k)$ (`8,048` checks), driving $H(\mathrm{LF}(x)\bmod 2^k \mid x\bmod 2^k)$ to **`93.9–99.8%` saturation** for $k \le 8$, while `Open<16>` strips out the `69.8–84.3%` Van-der-Put-aligned dyadic mass of $\mathrm{LF}$ leaving **`< 0.27%`** pure-affine `64 B` cache lines in `edges[0..m)`.
2. **Is the first return the right object?**
   - Open computes returns to a retained *set* of rows. Repeated cuts shrink that set fast:
     110,273 → 17,657 → 3,916 rows on block 0.
   - What is the limit object of repeated cutting? Can it be computed directly from the band
     structure, without materialising the intermediate levels?
   - See OPEN-QUESTIONS.md §1 for the feasibility version.
   - **Resolved in Cycle 47 ([journal](../../journal/2026-11-22-carbon-kitchen-sink-cycle47.md), `p3/fq2_iterated_cut_tower.rs`):** across `5,186` exhaustive small BWTs and all `12/12` real blocks (`6` Wikidata + `6` non-Wikidata), repeated forest-chord cutting builds a nested **Schreier (`1927`) transversal SLP** of depth **`D = 5..6`** (`4..5` when `Open<16>`-rooted) terminating at the trivial 1-point system `(m_D = 1, W_D = T)` via a universal `L3 → L4` singleton-evaporation cliff (`w̄ -> 1.00`, `w1% -> 99.3–100%`, certified by overflow-free `BigInt` **Smith Normal Form `1861`**: `β₁ = 1, rk = B - 1, nu = 0` pure directed cycle $C_{m_k}$). Computing `L2` directly from `Open<16>`'s `B_cod` bands is obstructed by an exact **`11.9×–31.8×` purely geometric domain-refinement blowup** (`B_1^{exact} = 47.5k–125.8k ≈ r_thin`, `B_1^{exact} == B_aff` to `<= 1` piece on `12/12` blocks), and computing `L2` directly from `L0` is obstructed because **`59%–86%`** of `L2` rows originate inside thick `L0` runs sliced non-locally by `F_0`'s chord transport. Thus `L1` (`Open<16>`) is the unique depth achieving $O(H)$ codomain compression.
3. **Can geometry replace rows?**
   - Rauzy–Veech propagates information through interval endpoints; emission still touches
     every retained row.
   - Is there an exact reconstruction whose work scales with the number of *structural events*
     (run boundaries, overlaps, bands) and whose only n-scale work is sequential byte writing?
   - **Known obstructions:**
     - copy replay shatters into 1.8-byte fragments (round 5);
     - the in-place Φ schedule needs run labels (record 84);
     - the forest construction was 15× slower than Cells (Astra investigation 3);
     - **$G_{\mathrm{ov}}$ Spectral Pseudo-Orbit Entropy (Cycle 8, Theorem 8.3):** unweighted $G_{\mathrm{ov}}$ has $\lambda_{\max}(A_{\mathrm{ov}}) \in [3.38,\,5.35]$, generating $1.76\text{--}2.42\text{ bits/step}$ of spurious pseudo-orbits whenever intra-run sub-interval metrics are dropped;
     - **Directed FVS vs Diamond Phantom-Path & Non-Planar $\Phi$-Braid Duality (Cycles 9 & 11, Theorems 9.2, 11.1 & 11.2):** cutting **only `171–508` runs (`0.29%–0.39%` of $r$)** makes $D = G_{\mathrm{ov}} \setminus F$ a pure DAG (`0` intra-fragment repeated runs), *yet*: (a) under direct $\Phi$-copy replay, **`63.66%–75.82%` of DAG-excursion fragments STILL deadlock** due to rank-inverting diamond braids ($n=15, r=4$ minimal witness `000110010010011`, `4/4 = 100%` deadlocked); and (b) while collective topological propagation (`FVS-Topo` / `FVS-Open`) **escapes Record 84 mathematically** (`3,016` small checks + 6 blocks byte-exact without text-order run labels), pruning $2^{35}..2^{63}$ DAG phantoms propagates `85K–223K` interval splits (`8.2×–30.4×` `0.5.8`'s `≤3H+2`) and inflates per-worker working set from `0.5.8`'s `1.26–2.43 MiB` to `4.5–11.3 MiB` (`3.2×–5.5×`).
4. **Is the inverse BWT the right problem?**
   - The decoder must produce bytes, not a permutation.
   - Could information already in the compressed stream let the decoder skip parts of the

     to its neighbours.
   - **Examined in Cycle 8 ([journal](../../journal/2026-11-20-carbon-kitchen-sink-cycle8.md)):**
     - **Functorial Non-Commutativity ($\pi(\mathrm{BWT}(T)) \ne \mathrm{BWT}(\pi(T))$):** On legacy `.bz2` streams, post-BWT column quotienting $\pi_{\mathrm{hex}}(L)$ collapses runs by `43–55%`, *but* random hex suffixes have already scrambled $F$'s sort order, leaving `296K–326K` 4-bit fiber scatters (Theorem 8.1).

5. **Copies from completed output.**

   - What is the cheapest possible discovery of "which rows spell bytes already written"?
