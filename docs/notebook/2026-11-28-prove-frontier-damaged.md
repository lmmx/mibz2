# Proving `frontier/` under single hand-editing damages (`prove-frontier-damaged`)

**Date:** 2026-11-28
**Claim:** `prove-frontier-damaged`
**Scope:** Private bare Git remotes and local clones only (`/tmp/prove-frontier-damaged`). Zero test refs or commits touched `lmmx/mibz2`.
**Tested base:** `origin/master` at `bd75fc83` (`frontier/tools/frontier.py`, `frontier/tools/continuation.py`).

## Executive Summary

We applied **144 distinct single hand-editing damages** across 8 categories (`A01–A36` claims, `B01–B09` blog cards, `C01–C19` `config.toml`/`limits.toml`, `D01–D21` hold refs & leases, `E01–E13` deltas, `F01–F16` flags, `G01–G20` TSVs / `README.md` / presence / continuations, `H01–H10` CLI & edge cases) against isolated bare remotes and tested `check`, `brief`, `status`, `holds`, `claim`, `verify`, `renew`, `release`, `mark`, `population`, and `continuation.py view/show`.

- **Raw crashes before patch:** **40 / 144** single damages produced unhandled Python tracebacks (`TOMLDecodeError`, `UnicodeDecodeError`, `KeyError`, `TypeError`, `ValueError`, `AttributeError`, `IndexError`, `FileNotFoundError`).
- **Distinct defects found:** **19** (**10 `breaks`**, **7 `misleads`**, **2 `friction`**).
- **Gold-standard controls that passed cleanly:** CRLF line endings (`A11, C12, E08, F13, G07`) and presence ref isolation (`G12, G13, G14` — malformed TOML, oversized `> 2048 B` blob, and missing `presence.toml` are already isolated and reported without crashing `population` or `brief`).
- **Scratch-patch verification:** All non-`swarm-quiet-state` fixes were implemented and verified on scratch copies of `frontier.py` and `continuation.py` (without editing `frontier/tools/frontier.py` on `master`, which is currently held by PR `#1341`):
  - **0 / 144** unhandled Python tracebacks (down from **40 / 144**).
  - **90 / 90** `tests/test_frontier.py` PASS; **34 / 34** `tests/test_continuation.py` PASS (124 / 124 total).
  - **`0 errors, 0 warnings`** when running the scratch-patched `frontier.py check` against the live `mibz2` repository.
- **Follow-on claim:** Filed `frontier/claims/frontier-damage-hardening.toml` (`P2`, `idea`, sequenced behind `#1341`; coordinates `limits.toml` `brief`/`renew` fail-closed state with `swarm-quiet-state`).
