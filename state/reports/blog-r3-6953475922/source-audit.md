## Prior art

Primary texts checked this run: Qureshi/Patt *Utility-Based Cache Partitioning* (MICRO2006), [author-hosted copy](https://users.ece.northwestern.edu/~rjoseph/eecs453/papers/quereshi-micro2006.pdf); Xu et al., [CAMP paper](https://web.eecs.umich.edu/~zmao/Papers/xu10mar.pdf); Gunther, [arXiv0808.1431](https://arxiv.org/abs/0808.1431); Qureshi/Lynch/Mutlu/Patt, [MLP-aware cache replacement](https://users.ece.cmu.edu/~omutlu/pub/qureshi_isca06.pdf).

UCP supports allocating shared capacity by application utility; CAMP supports predicting application performance from cache contention, not this specific worker-count selector. USL supplies a related rational curve, not an equivalence of physical mechanisms. MLP-aware replacement directly supports the notes' claim that raw misses and stall cost can diverge; change that sentence's reference (F5). None establishes mibz2's fitted constants or validates their transfer.

Mattson et al.'s 1970 bibliographic/stack-distance attribution is consistent with the cited literature, but its original full text was not freshly independently verified this round. Yasin's author page verifies the 2014 paper's identity; direct full-text retrieval was blocked, so the exact paper passage behind the overlapping-counter attribution is not freshly certified. The general caution is also consistent with the explicit MLP counterexample and remains correct; no invented quote/page locator is supplied. These limits prevent an unqualified claim that every external citation was fully verified.
