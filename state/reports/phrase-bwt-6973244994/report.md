## 1. Proved: charge each phrase change to one raw change

Let Ψ be the inverse of stable LF, and let B be the contiguous marker bucket in F. B reindexes the boundary rows (rows with L=c) by a stable LF step. For each root row in B, its first return to B spells the preceding delimiter-ended phrase in reverse. In one cyclic source text, ordering boundary rotations compares the prefix-free words in lexicographic byte order. A pair of different words has its first differing symbol before either ends, since a delimiter cannot occur in the interior. Equal words defer the comparison to later phrases. Periodic ties give the same last-column label, so their ordering does not change the claim. The first return is exactly the phrase LF: occurrences of a phrase take the same byte steps, each order-preserving on its own symbol, and land in the F subinterval for prefix c followed by that phrase. On a general column the same description applies to the stable first-return permutation of all represented cycles, including multiple periodic copies.

Take gap (i,i+1) in B whose two preceding phrase labels differ. If the current L bytes agree, they cannot both be c because identical backward traces would then terminate with the same label. Stable LF sends the gap to an adjacent gap in the common symbol's F bucket. Repeat until the first disagreement. That endpoint is one of the r−1 internal run boundaries of L. The continuation on gaps is injective: recover the two endpoints with Ψ. If two paths of unequal lengths meet, their shorter common inverse would encounter a second root gap before the longer path's mismatch. Every step after leaving a root and before or at a transported mismatch lies in a nonmarker bucket. Thus a second root is impossible. Distinct roots charge distinct raw run boundaries, so q−1 ≤ r−1. This counts linear internal gaps. A marker-free column has no quotient and a marker-free marked cycle has no marked root.

Tight example: L=`a##`, c=`#`. B has two rows with labels `a#`, `#`. Each column has two runs. For literal cyclic text, the proof requires no unique sentinel or primitive-period assumption. A small q still gives no sublinear construction guarantee: one marker in a primitive n-byte word takes n LF steps for the only representative. With marker counts at most half at each level, summing covered sizes bounds representative steps by a geometric series below 2n. That bound charges neither rank lookup nor dictionary and emission work.

## 2. Proved: all order information lies in the mixed routing buckets

Use I(w) for rows whose **periodic forward continuation** begins with w. This definition covers short or multiple cycles and pattern lengths greater than the length of a single rotation. The nonempty words w=s c with no c in s are prefix-free. Each row on a marker-bearing cycle sees a first c, so these intervals are disjoint and cover exactly those rows. At I(w), stable LF gives an order-preserving bijection from occurrences with L=a to I(a w). For a≠c this is a child. For a=c it supplies the terminal phrase w, and I(c w) is a subset of the root B. A node with one allowed routing symbol has a constant L slice, even if different eventual phrases share its suffix. An ending and a child at the same node make it mixed.

A supplied dictionary and frequencies determine every node size by summing phrase frequencies over matching suffixes, and determine every outgoing multiplicity by considering the preceding byte. If all cycles meet c, sorting suffix strings and scanning cumulative sizes gives their absolute L offsets. Stable unshuffle from each mixed bucket, recursively merging the ordered child streams, recovers the root phrase column. Conversely, stable projection of the root order onto each suffix spells that bucket's L bytes. Writing these in suffix order reproduces L. The product of local multinomial counts cancels the child factorials and counts all root multiset orders before any single-cycle restriction. It gives a count of possibilities, not a lower bound of one read per mixed bucket for every oracle or input.

**Coverage is essential for absolute offsets and full reconstruction.** L=`#a` and L=`#b` both give dictionary `[#]`, the same frequency and the same one-label phrase column for c=`#`. The other singleton cycle is invisible to the quotient. Even knowing n cannot tell those columns apart. The marked reconstruction still works on a selected cycle that visits c: remember the boundary before the linear start and its skip. Recursion rotates the selected primitive token period at each level and the outer emitter stops at n raw bytes. The mark is extra state for a specified linear output. It is unnecessary for the unmarked L round trip.

## 3. Proved: RLE1 independence at a safe delimiter cut

At a cut after raw c, the sequential decoder is either fresh, if c served as a count, or has a pending literal run of one through three c bytes. In the latter case, the initial c bytes to the right cannot complete a four-c literal run because that contiguous quartet would contradict the premise. They emit as literals. On the first different byte the boundary history is irrelevant. In the former case decoding already restarts fresh. No count is owed at the cut. This proves composition by induction over cuts, with identical output upon success and the same terminal missing-count error for a clipped final fragment. A whole delimiter-ended phrase can never itself end owing a count: a terminal run of four would have to be four c bytes.

Identify `C[c]` and exclusive prefix rank `Occ(c,x)`. The extension is [C[c]+Occ(c,lo), C[c]+Occ(c,hi)) starting from the F bucket for c. Three extensions test the quartet. Both Rust paths compute this endpoint by finding the first usable marker run at or after x, using x within it or its start otherwise, and returning the bucket end if no such run exists. This includes x=n and the empty interval case. The recurrence ranges over all LF cycles and across each periodic seam. It can conservatively decline on an unrelated cycle or when four markers occur only across the linear seam. For example L=`#a#`, p=1 has a selected `#a` period and another singleton marker cycle. The global quartet test declines. The linear raw string `##a##` is itself a safe split example that the corresponding circular quartet test declines. The condition is sufficient, not necessary: with marker `#`, `aaaa####` uses the first `#` as count 35 for a, then emits three literals. Those cuts happen to be safe despite a quartet. When the premise fails, `!!!!A` with marker `!` shows why splitting can be wrong.

Both fused writers apply the original phase and requested n in raw units. Only full interior phrases use cached decoded payloads. A clipped first or last phrase runs RLE1 on the raw slice with fresh state. Grouped upper payloads are copied only when complete and once the raw skip is resolved. The count byte may itself be c, which the complete left phrase absorbs. Bytes after the linear end cannot satisfy a missing count. CRC checking remains required for successful native output.

I checked 27,990 arbitrary ternary columns/marker pairs (length ≤8) for gap injection and matched both rank-edge semantics and the FM interval to a direct scan of four Ψ-linked symbols. A separate state transducer checked 157,326 finite linear slices of quartet-free periodic inputs, including 1,998 terminal unfinished cases. The supplied Python verifier separately passed 7,999 arbitrary column/primary/marker checks and 9,075 direct token-BWT comparisons. These finite checks support the proofs. The native 100,840-case total comes from the archive.

## 4. Measured: what the Xeon data establish

- The corpus manifest pins twelve streams and SHA-256 `82f65ace0731962d04443bbda4cebfdccd336106049751060f477941c2c29915`. The archived `checks.txt` says both fused saves matched each other and `bzip2 -dc` over 209,700,196 bytes, with output digest `3f075e30f4f8c73414150655afbf57caa2647c7927e743fc0635b4912d65cdaf`. The native driver also compares each timed output against Cells, after timing. CSV output lengths corroborate roster/length and cannot by themselves prove byte equality. The reference, executables and full decoded outputs are not in the checked-in evidence directory, so the full-stream cmp is an archived result.
- `allocations.csv` has 431 unique block IDs per arm. Grouped and representative fused2 admit an identical set of 367, including all 233 large blocks. Full-corpus fused saves report the same count. `grouped.csv` has 396 rows because its separate dense stats driver emits marker-bearing blocks under its own conditions. Treating that file as the fused-admission roster would be wrong.
- On those 233 singly rewrapped large blocks, median incremental peak live requested Rust heap, including each returned output buffer, was 9,591,394 B for Cells, 6,129,795 B for grouped, and 4,844,950 B for representative. Grouped uses 36.09% less by ratio of medians. This metric starts above the pre-existing input, oracle and harness allocations, with a fresh decoder. It does not measure retained parallel worker memory, RSS, memory traffic or an LLC working set.
- The seven rotated rounds, excluding the first Cells warmup, reproduce Cells 0.822504 s, grouped 1.735774 s, lazy 0.897773 s and representative 2.074303 s. Grouped's median paired time ratio is 2.1464; all seven ratios exceed 1, with the first pair near parity because the first timed Cells arm was unusually slow. This is a descriptive paired comparison on a single pinned Xeon VM CPU with experimental Rust 1.90.0. It is not a production CI qualification or a measurement on the i9. The four-worker experiment is a distinct scheduler over twelve original streams. Cachegrind simulates cache lines and does not supply DRAM controller events.

The mathematical result survives. The available engineering result is a heap/throughput trade-off: the prototype saved a material fresh-block allocation peak and lost the Xeon whole-decoder timing. The next unresolved cost is compressed-input dictionary discovery and order recovery. The one-block mixed census shows where routing choices live, while the 40% column-byte share warns that few mixed intervals need not mean little data movement. A shared dictionary's high token-hit rate likewise does not bound miss-discovery cost. No evidence here supports substituting this implementation for Cells or inferring a change to the i9 plateau.
