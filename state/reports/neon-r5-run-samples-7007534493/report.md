## What is the same sampling problem?

Use zero-based coordinates. For a single LF cycle with primary row `p`, let `t_p(x)` be the unique time in `[0,n)` with `LF^t(p)=x`. In the sentinel construction, `SA[x] = (SA[p] − t_p(x)) mod n`. In the primitive cyclic construction the analogous value is the start coordinate of the rotation relative to the primary. The byte in the last column is one byte before that start. Thus the numeric information in the run endpoints agrees with classic run-boundary SA samples after changing origin and direction. The sentinel provides a fixed origin in a single cycle. A periodic marked column can have several physical LF cycles. On that domain cycle identity, phase and original output length need their own conventions. The real-block verifier checked the single-cycle case in all six receipts. [r-index, §2.2 and §3](https://arxiv.org/pdf/1705.10382) · [Checked blocks](https://github.com/lmmx/mibz2/blob/ef09f96638a3f89f1be9c6727e4de303dda949f4/docs/journal/2026-11-19-gemini-neon/round5_output.txt)

## Interval-exchange precedents and a consequence for sample acquisition

The interval-exchange interpretation is established. Ferenczi and Zamboni relate clustering BWT words to discrete interval exchanges. Standard Rauzy induction replaces the map by a first return and adds return itineraries or weights. The weighted interval-pairing algorithm of Agol, Hass and Thurston, §6 Theorem 16, goes further. It accepts interval translations and integer weights specified on intervals, and computes aggregate weights for components in time polynomial in the compact parameters including log n. Its weight partition can grow in the analysis. Their theorem supplies no O(r)-word bound. [Ferenczi–Zamboni](https://cs.uwaterloo.ca/journals/JIS/VOL16/Zamboni/zamboni2.pdf) · [Weighted orbit counting, §6, Lemma 15 and Theorem 16](https://arxiv.org/pdf/math/0205057#page=24)

**The following reduction applies that published algorithm to BWT sampling.** For one LF cycle choose the run heads, tails and primary as a deduplicated marked set. Delete the incoming LF edge into every mark. Split the O(r) original interval translations at the deleted sources (equivalently, split the image intervals at the marks), leaving O(r) translation pairs. The connected components of the undirected pairing system are then the directed segments from each mark up to, and excluding, the next mark. Put a unit vertex count on every row. Add a start tag at each mark, and a next-mark tag at the predecessor of each mark, in two separate integer coordinates. Tag values are row numbers plus one. These weights have O(r) pieces and O(log n)-bit labels. Each component aggregate reads `(distance in LF steps, start ID, next ID)` because the deleted edge is the final step to the next mark. Follow these O(r) triples from the primary and sum distances to recover all the coordinates. This gives a runtime polynomial in r and log n and can be sublinear for fixed or sufficiently small r. It does not match Neon's linear-in-r working state or its measured step cost. It rules out a claim that a full LF lap is inherently necessary to obtain these samples from bare RLBWT. [AHT, Theorem 16](https://arxiv.org/pdf/math/0205057#page=24) · [Modern statement, Theorem 3.3](https://doi.org/10.1007/s00454-026-00845-7)

## Scope of the surviving result

**The algorithmic contribution is the endpoint bookkeeping on the existing finite induction.** Maintained integer return lengths transport a head, a surviving tail token and the primary's phase. Relative differences are recorded in two O(r)-size merge forests and resolved at the end. With the run list supplied and a fixed-size byte alphabet, stable byte bucketing builds the initial permutation in O(r) word operations and O(r) words. The sampling core then takes O(r+S) word operations under the word arithmetic model, where S is the number of steps in the implemented schedule. The published six-block receipts found `S/r` from 1.684 to 1.869, with all head, tail and marked coordinates agreeing with an independent LF lap. The accelerated and unaccelerated counters were identical for every block. The reference harness derived runs by scanning a dense L, and sorted positions and replayed the output separately. The O(r)-word sampling claim applies to the core after RLE preparation. The full verifier and its elapsed time include other work. [Verifier initialization and induction](https://github.com/lmmx/mibz2/blob/ef09f96638a3f89f1be9c6727e4de303dda949f4/docs/journal/2026-11-19-gemini-neon/verify_rv_copy.py.txt) · [Pinned receipts](https://github.com/lmmx/mibz2/blob/ef09f96638a3f89f1be9c6727e4de303dda949f4/docs/journal/2026-11-19-gemini-neon/round5_output.txt)

**The exact quotient rule can still take Θ(n) steps with r=3.** Let the last column be `2 · 1 · 0^N` for even `N≥2), with `n=N+2`. LF sends row 0 to N+1, row 1 to N, and each row x≥2 to x−2. The walk visits both parities before closing, so this is a single cycle. The rightmost domain interval is the length-N zero run. In the codomain order it lies before both one-row runs. Case 1 moves the rightmost loser immediately behind the zero run, so the two losers alternate at the right end. The quotient condition `cod_prev[loser] == winner` fails at every one of the first N−1 reductions, each removing one row. I ran the exact pinned sampling function on seven synthetic members (N from 2 to 4096) and compared coordinates with the explicit LF formula. All matched. Both counters were exactly n on those examples, including 4,098 steps for 4,098 rows and just three runs. This is a lower bound on this schedule, with no implication that broader winner batching or AHT must do the same work. [Quotient test and relink](https://github.com/lmmx/mibz2/blob/ef09f96638a3f89f1be9c6727e4de303dda949f4/docs/journal/2026-11-19-gemini-neon/verify_rv_copy.py.txt#L159-L199)

**The parse is prior art and the replay is a separate cost.** Navarro–Ochoa–Prezza, Definition 5 and Theorem 7, already give the valid run-induced bidirectional scheme of size at most 2r and the affine φ fact it uses. Neon materializes its coordinates without the extra plain LF walk on the sampled inputs. Its copying phase failed its own registered fragment criterion on every one of those six blocks. Sorting the endpoints is an additional cost for extraction downstream. The reference does it with a comparison sort. A linear radix cost requires an appropriate key-width and word model. [Navarro–Ochoa–Prezza](https://arxiv.org/pdf/1803.09517#page=9) · [Replay receipts](https://github.com/lmmx/mibz2/blob/ef09f96638a3f89f1be9c6727e4de303dda949f4/docs/journal/2026-11-19-gemini-neon/round5_output.txt)

The defensible novelty statement is a **simultaneous run-head, run-tail and primary recovery algorithm using return weights only in O(r) words and O(r+S) time**, with exact results and a small S on the six admitted blocks. The sampling targets, compressed-time recovery in some regimes, interval induction and the copy scheme all have prior art. I found no published matching bound for the same compact-state induction algorithm, and the pinned implementation supplies a counterexample to an unconditional sublinear bound.
