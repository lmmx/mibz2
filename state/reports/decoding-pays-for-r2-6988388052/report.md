## Corrections in section 3

1. **The sum is fixed. The profile can distinguish blocks with the same row and run counts.** The short-tail paragraph draws the opposite conclusion about the whole profile from the identity for its sum. A replay on sorted cyclic rotations gave `baaa$` → `aaab$`, with profile (2, 1, 1), and `baab$` → `bbaa$`, with profile (2, 2, 0). Both have five rows, three runs and positive-depth sum two. Only the first has a surviving chain at depth two. Suggested wording: “The total alone cannot distinguish blocks with the same rows and runs. To distinguish them, keep track of how early their chains end.” This is a chain-level correction because the next sentence uses exactly that distinction to motivate the fit.
2. **Name the fitted excess proxy in the table and the paragraph that interprets it.** The first table row identifies its predictor as the exact `(E₀ − V₀)/r`. The text after the table and the retained replay code identify it as `(q̃₁ − 1)/r`, one gap below the exact normalized excess on the four blocks with d₀ = 2. The second model inherits this proxy. This matters most where the prose tells the reader what the baseline “already holds.” Suggested table row: “Run density and historical first-depth proxy (q̃₁ − 1)/r.” Refer to the count of chains reaching at least one step in the conceptual explanation, then say the historical proxy usually equals that count once rescaled. Keep the table's present values. In the residual figure, call the middle adjustment a first-depth excess proxy and name the historical profile in the accessible description as well as the caption.

One related wording change would keep the exact chain and the interpretation visibly connected. The partial gap map is injective, so two chains as just defined do not merge. In the interpretation, “until the chains collide” switches to the informal language of boundary orbits. Say that both methods’ work appears to respond to how long the same gaps stay together, and keep the existing sentence that there is no exact accounting of either operation count.

## Evidence and figure check

- **Profiles.** Images of the n−r same-run gaps are exactly the internal gaps that are not run-image cuts. The run boundaries outside those cuts count q₁, so q₁ = r−1−C = E₀−r, and the forest chords total E₀−r+1. In banana$, C = 3, E₀ = 6, q₀ = 4 and q₁ = q₂ = 1. In column 100, LF = (2, 0, 1). Starting at zero goes through row 2 before reaching internal boundary 1. The historical extra lands at depth 2, so the two depth-one counts are both 1 while there are 2 chords. In general q̃ₖ = qₖ + [k = d₀]. The periodic column bbaa has uncovered gaps 1 and 3. These checks confirm the mechanism.
