# Astra E's modal exceptions and move structures

Researcher response to [CHECKPOINT 7003699363](https://github.com/lmmx/mibz2/pull/162#issuecomment-7003699363). Source is PR #607 at `980edb622e4d06e3d5830958ca9137ed9a608749`. All numerical comparisons below use committed data. The only fresh calculations are the CSV aggregates, ratios and the overlay accounting.

**Physical exception ranges are bounded by the input run count. Individual exception rows and the cost of ordering them can be much larger.** A move structure supplies the exact affine LF step that Astra also uses. Brown and Langmead give linear-in-runs construction of a length-capped LF move table and linear-in-text-length inversion. The missing result is a comparable bound on acquiring Astra's marked first-return distances and ordered events.

The exception share falls from 63.27% of physical rows at k=1 to 4.55% at k=8 and 2.54% at k=16. As the partition refines, the sum of the largest incoming-byte count in each context can only increase. That explains monotonicity of the **total row count** `E`; the modal label and the identity of exceptional rows can change. On this panel the number of contexts grows from 893 to 1,170,188 while ranges fall by nearly sevenfold. The two counts describe different geometry. The original `r` is fixed across the k sweep.

### Why 647,332 is close to 690,484

For one block, let `H` count the nonempty intersections of input runs with contexts, and let `S` count common interior endpoints. Then `H = r + C − 1 − S`. Both the incoming byte and its poststate are fixed on each such piece. Every nonempty context contributes at least one modal piece. If `A` counts all modal pieces and `X` the exceptional pieces before adjacent coalescence, then `X = H − A` and `D ≤ X ≤ r − 1 − S`. Equivalently, the number of ranges is bounded by the number of original run seams strictly inside contexts. This holds at every k. It explains the scale of `D`, while allowing `D` to be zero. The source's `C_k ≤ min(n, 1+k(r−1))` bounds context growth, so the number of contexts can itself exceed `r`. At k=1 the ten final overlays add **77** pieces to the input run count. Of the 883 interior context endpoints, 806 align with run ends. The resulting **690,561** pieces lose **43,191** modal pieces, leaving **647,370** exceptional pieces. Coalescence removes **38** more, leaving **647,332**. Thus `r−D = 43,191+38−77 = 43,152`. The near equality is explained by this particular alignment and modal-piece count. At k=8, **959,646** pieces lose **838,604** modal pieces and coalescence removes **39**, leaving **121,003**. The per-depth census supplies the same accounting at all eight depths. [Final-depth overlap and exception-slice rows](https://github.com/lmmx/mibz2/blob/980edb622e4d06e3d5830958ca9137ed9a608749/research/astra-e/formulations/f2-heaviest/orientation/collation/sweep/core-transport/origin/marker-insert/quotient/fold/iterated/cut/unseeded/all-marks/exceptions/contexts/layers.csv)

A two-run single-cycle family shows why row counts have a different bound. For `a<b` and `m≥1`, take `L=b^m a^(2m+1)`, so `F=a^(2m+1)b^m`. LF is rotation by `−m` modulo `3m+1`, a single cycle. In the first F bucket there are `m` occurrences of `b` and `m+1` of `a`, so its unique modal byte is `a`. All `m` rows of the first run are exceptions, including its interior. The second F bucket is uniform. Thus `r=2`, `C=2`, `D=1`, and `E=m`. Equal incoming bytes and an affine LF step are compatible with an entire run of prediction errors. An explicit per-event clock can require linear output in the lap length even for fixed `r` and one physical exception range.

## Correspondence to published constructions

| **Nishimoto and Tabei, ICALP 2021, Lemmas 3 and 6, Theorems 7–8** | LF on every maximal equal-letter run is a translation. A move query takes a position and its input-interval index, applies that translation and returns the destination-interval index. Balancing refines the intervals to at most twice the original number while preserving the very same permutation. Astra's packets and interval overlay use the same affine geometry. Its default transition stores an incoming byte and a next **context**. Modal rows of one context map stably into one destination slice, with source gaps where exceptions were removed. The context ID and modal byte therefore provide the next output symbol and context, but may leave the exact destination rank undetermined. A pure context gives a genuine full-interval translation. Its matching-query mismatch can cause repositioning via a threshold and a query character. Astra's exception is determined by the physical row and the context's mode, with no query. Astra LF follows an original marked text orbit in **BWT-rank coordinates**, and the weighted return skips to the next selected event on that orbit. The original r-index samples support locating occurrences. They do not describe the prediction-error mask or its order. A unique sentinel gives the papers a single text lap and its origin. Astra supplies a primary and accounts explicitly for phase, shorter periods, and cycles disjoint from the mark. **The second BWT has an exact cyclic-parse precedent.** Moving the true exceptions by LF selects starts of length-(k+1) cylinders: an exceptional byte followed by its k-byte context. Between those starts, the return word `W` plus the next trigger window `P` is the full overlapping phrase `WP` of cyclic prefix-free parsing. This is the trigger-start order in Boucher et al. (SPIRE 2021, §4, Proposition 17) on covered cycles with a trigger window no longer than the circular input. The paper assumes a trigger in every input string. Astra's separate marked fallback covers cycles with none and its finite-state definition also allows longer cyclic windows. Astra stores the class without materializing `W`: the length, first exceptional symbol and terminal context identify it by replaying the defaults. At k=8 the pinned census has 409,432 selected rows, 95,150 classes and 148,077 residual incoming runs. Read these separately from the 121,003 physical exception ranges and the 127,360 canonical weighted return bands. The k=8 then k=2 policy has populations 8,999,915 → 409,432 → 66,518 → 5,313 before default-only termination on all ten marked paths. Recursive PFP already reparses a parse. I found no matching recipe that chooses each trigger set by modal errors in the current incoming column, constructs weighted marked returns from the original runs and recursively expands their class IDs through defaults. That is the specific contribution this literature leaves open as prior art. ## Acquisition costs and what the literature actually bounds

1. **Ordinary LF setup has a linear-in-runs precedent.** Input and LF-image endpoints are known from cumulative symbol counts and a stable order on (byte, source run). A monotone merge gives the input run containing each LF-image start. Brown and Langmead (SEA 2026, Lemma 6) construct a length-capped LF or inverse-LF move structure from RLBWT in `O(r)` time and space. Theorem 2 and Corollary 3 give constant amortized step time over one complete single-cycle traversal, and Theorem 9 gives `O(n)` total inversion time and `O(r)` workspace. Constant worst-case move queries with balancing hold when the source interval is supplied (Nishimoto–Tabei, Theorem 7). The balancing construction quoted in Brown–Langmead's Theorem 1 uses `O(r log r)` time. Brown–Langmead's Lemmas 7–8 give a distinct construction for φ and φ⁻¹ from bare RLBWT that walks the text to obtain SA samples in `O(n)` time and `O(r)` space. The LF setup bound concerns word operations, with no cache-miss guarantee for the subsequent traversal. [Brown–Langmead, Theorem 2, Corollary 3, Lemmas 6–8 and Theorem 9](https://doi.org/10.4230/LIPIcs.SEA.2026.9)

2. **The locality evidence is per step.** Movi's Fig. 3A reports more than fourteen times as many last-level cache misses per base for SPUMONI as for Movi on their pseudo-matching-length workload. Their method issues a prefetch for a dependent LF destination and interleaves independent reads to hide latency. The single table and amortization can reduce the cost of a step. The indexed-query result does not reduce the number of steps to the number of distinct table rows. Brown–Langmead's §5 finds length-capping useful for LF table size, with relatively little effect on LF query time versus their unbalanced table on the tested data. Neither experiment prices marked first returns. [Movi, Fig. 3A and cache-miss latency hiding](https://pmc.ncbi.nlm.nih.gov/articles/PMC11696632/) · [Orbit experiments, §5](https://doi.org/10.4230/LIPIcs.SEA.2026.9)

3. **Astra needs the event successor and its positive elapsed distance, then marked order.** The physical scan can enumerate exceptional ranges and their first LF images without expanding them. The recorded level bounds give at most O(k²r + kσ) work for direct context refinement and this physical publication with alphabet size σ, hence O(r+σ) for fixed k. The range solver's elementary birth count is at most the uncoalesced exceptional-piece count plus O(1) for isolating a mark in a block: a fixed predecessor and source context determine one destination context. With C=O(kr), its after-geometry bound is O(r log(r+1)) at fixed k. This counts word operations, including work on a balanced sequence, rather than cache misses. The static input overlay needs at most `r+2M` atoms when the retained anchor set has `M` membership intervals. The packet constructor can still make a linear-in-n number of translations with a single returned band, as the pinned two-run singleton-anchor example shows. The other, range-based constructor has a width-independent bound after geometry of `O((C+P) log(C+P+1))` with a deterministic balanced sequence, where `P` counts elementary birth intervals including any inserted mark. The reference treap is analyzed in expected time. The bound ends at band publication and carries no hardware-access or chronological-output guarantee. Classical interval-pairing compression can count orbits and aggregate orbit weights in time polynomial in the compact parameters (Agol–Hass–Thurston, Theorems 12 and 16). Those outputs lose the directed next-event order and the separate distance for each return. I found no paper giving roughly `O(r)` unpredictable accesses for Astra's general acquisition problem. The committed measurements verify the distinction. From k=4 to k=16 the plain packet pass drops from 1,122,585 to 229,013 true events, while its translations rise from 1.48 million to 3.26 million. The depth-eight width-independent native pass supplies **127,360** bands from a prepared model and already costs **2.347×** the complete scalar inverse CPU on its paired ten-block panel (95% interval **1.862–2.958**). Separately, the terminal given the model and ordered clock runs at **0.628×** (95% interval **0.565–0.698**). Those are distinct panels and endpoints. The range panel excludes physical model construction, marked chronological emission and output. The terminal comparison assumes the missing inputs are supplied. The measurements therefore establish a cheaper conditional terminal and an acquisition overrun for the priced constructor. They give no lower bound on the cost of a different acquisition algorithm.
