## Ruling on the generated guards

There are **13** compressor-made guards, six development corpora, six prose/code/structured level variants and `ho-wikidata-l1`. Five of the 18 receipt entries have exact expected digests, covering the two bases and three judged copies. The remaining 13 are checked for membership, uniqueness and lowercase SHA-256 syntax. A synthetic fixture still returned ADOPTS when I replaced the `ho-prose-l9.bz2` receipt entry with 64 `f`s, as expected from the current policy. Two decoders agreeing on an output hash tells us they agree with each other on an input. The well-formed receipt alone supplies no expected identity for that input. [Scorer](https://github.com/lmmx/mibz2/blob/8c6c1035f009623cd534fcf97c4d5716fcffd448/bench/open_port.py#L333)

The actual receipts show a source of drift. The two cloud preflights differ in decoded size or digest on both levels of prose and code, and their compressed hashes also differ on those four files. The second preflight ran at [`5308788c`](https://github.com/lmmx/mibz2/commit/5308788c3f90c166a922cd26ce4913b953215f9f). The final archive-only commit also edits the registration Markdown, which `heldout.py` selects as input from `HEAD`. It added 684 bytes to that Markdown. Each judged prose stream repeats the input four times, so its decoded length changes by 2,736 bytes between the second preflight tree and the proposed frozen tree. This is a change in the workload even with an identical compressor. [Tree comparison](https://github.com/lmmx/mibz2/compare/5308788c3f90c166a922cd26ce4913b953215f9f...8c6c1035f009623cd534fcf97c4d5716fcffd448) · [Held-out source selection](https://github.com/lmmx/mibz2/blob/8c6c1035f009623cd534fcf97c4d5716fcffd448/bench/heldout.py#L29)

Freeze the held-out source tree independently of the registration and archive updates. Use exact compressed SHA-256 for the judged generated streams, with the canonical streams available to the workstation or regenerated and checked during untimed setup. If encoder portability is required, freeze the decoded SHA-256 **and** the encoder and block-layout contract, and verify that contract on the measured streams. Decoded identity alone establishes payload identity. The decoder's path selection uses per-block run density and depends on block boundaries, so a compressed representation change cannot be assumed to preserve the guard. Choose and verify the corpus contract before timing. [Registered gates](https://github.com/lmmx/mibz2/blob/8c6c1035f009623cd534fcf97c4d5716fcffd448/docs/journal/2026-11-19-open-port-registration.md#L28)
