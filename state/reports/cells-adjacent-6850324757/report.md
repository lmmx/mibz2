## 1. Output-order expansion of the marked grammar — highest value

**Change of formulation:** retain the exact admitted grammar, but traverse its output in order instead of first assigning each rule its earliest output position.

Current write_cells walks the marked spine three times, initializes pos for all nr rules, scans rules backward to propagate first positions and forward to expand/copy them, then recopies long factors along the spine. These are distinct tasks, not synonymous with the mandatory n-byte output. The F01 recopy is necessary in this formulation; deleting it is not an optimization.

Let W be the marked root word of length p; its unique marked byte lies at index j. Current code fixes start=(j+1) mod p. The target period is therefore
V = W[start:p] followed by W[0:start].
The block is the first n bytes of V repeated. This is the existing rotation/repetition equation, not a new MONODROMY theorem or inference from the measured corpus.

Proposed reference formulation: find j with the existing marked-child descent; traverse the grammar twice, restricted to those two intervals, emitting terminal slices in forward order. Mask MARK for lengths, preserve the mark only to locate j. Every rule is a concatenation of earlier positive-length words; literals are at most16 bytes. Skip subtrees outside the interval using their lengths. Materialize one period, then retain the existing bounded doubling repetition. No overlapping long-factor source copies, first-position table, backward propagation scan or spine recopy is needed: the bytes arrive at their final period positions.

**Bound:** expanding a positive-length binary concatenation tree of total length p visits O(p) nodes even if the grammar DAG shares rules: the expanded tree has at most p nonempty literal occurrences and at most p−1 internal nodes. Interval pruning adds boundary paths of depth at most nr, hence O(p+nr) visits for the two traversals, plus n−p repeated-byte writes. Depth is at most nr≤B because child rules precede parents. This is an algorithmic work bound, not a speed prediction. Byte writes by the emitter are p for the period and n−p for its extension, apart from the unchanged output initialization/slack. It does not remove the unavoidable output or finish/CRC work.

**Memory obligation:** use explicit bounded traversal state, never the native recursion stack. A pending-right-child frame can be a parent-rule index: its second child descriptor is recoverable from the existing rule. At most nr pending parents fit a u32 stack using the existing pos allocation, with the active node and interval position in scalar registers. The node index fits u32 under the existing bound. Verify the exact simultaneous high-water bound and stack discipline before claiming the existing scratch envelope; do not add an unpriced descriptor vector. Two independent interval traversals permit the same scratch to be reused. The existing output Vec, admission and fallback stay in place.

**Falsifiable prediction:** on identical successful grammar inputs, the reference emitter produces byte-identical rotated/repeated output with zero first-position propagation and zero long-factor/spine recopy calls. Its non-initialization output-write count is exactly n. If saved pattern records show these removed operations scarcely occur, the specific explanation “pattern writer cost is dominated by those operations” is rejected; the formulation remains a bounded alternative but loses priority.

**Limits/counterpressure:** a compact DAG can share a long word many times. Current bulk memcpy may beat visiting its literal leaves repeatedly; O(n) scalar/node work need not beat O(n) optimized copy traffic. A short p already enjoys existing doubling; this is not a novel short-cycle shortcut. Deep skinny grammars stress traversal state. Rotation may cut through a literal or nested word; a streaming-only API would complicate CRC/error semantics and is deliberately not proposed.

**Cheapest falsifier (future, not run here):** a safe untimed reference emitter over saved admitted grammar fixtures, if such grammar state is actually archived, or existing tiny corrected365 witnesses. JSON route counts alone are not a grammar. Test every rotation of the tiny roots, p=1/p=n/short cycles, terminal splits at1/16, deep chains, shared factors, and the F01 n550/period55 witness. Compare complete bytes against the established oracle and writer; count node visits, pending-stack peak, initialized bytes and copy lengths without clocks. Abort this candidate on a mismatch, fallback change, or scratch-bound breach. No full corpus re-decode merely to obtain missing grammar state.

## 2. Write only the representation retained by each induction cell

**Static fact:** induce_cells computes len=la+lb, unconditionally performs two16-byte arena copies and two8-byte rule stores, then keeps arena bytes iff len≤16, otherwise the rule. It advances only the selected representation's cursor. The source comment explicitly calls these alternative representations; this is not an inferred CPU bottleneck.

**Construction:** select the same small predicate before materialization. For a short unmarked concatenation, retain the two existing bounded copy16 operations and omit the discarded rule stores. For a long or marked concatenation, retain the two rule stores and omit the discarded arena copies. Leave slot updates, mark arithmetic, counters, budget checks, closed-cycle termination and fallback untouched.

For U long/marked cells and S short cells, removed source-addressed store bytes are **32U+16S**, with 32U source-read bytes also avoided by the omitted copies. This is a symbolic work identity, not DRAM traffic or numeric pricing of the submitted run. The retained representation is unchanged. MARK is deliberately included in the existing predicate: a marked word stays a rule even when its unmarked length is small. Do not replace the predicate with masked length and silently change the marked representation.

**Proof obligations:** establish that discarded bytes are never subsequently consumed as a retained word, including speculative16-byte slack accesses. Existing buffer initialization and slack must remain sufficient; do not combine this with removing zero initialization or shrinking regions. A prefetch address is not evidence that a stale representation may be dereferenced. The safe boundary, budget≤floor(4n/25), complete-cell count and refusal-before-output behavior remain exact. This proposal touches unsafe helpers' execution and requires the ordinary independent B5 evidence before adoption; it does not reopen or self-clear F01.

**Falsifiable prediction:** a symbolic induction-state trace has identical selected word descriptors, slot/link transitions, admitted/refused outcome, cell count and resulting bytes, but no stores to the unselected representation. It should remove the exact addressed operations above on both successful and abandoned prefixes. If preservation needs formerly discarded payload/slack, the proposal fails as stated.

**Cheapest falsifier:** future bounded trace comparison on existing tiny ordinary/forced fixtures with length16/17 transitions, marked-short words, equal-length steps, budget0/B−1/B boundaries and the retained F01 long-factor witnesses; compare every committed cell state, not just the final hash. Count removed operations, then require targeted Miri/mutation evidence if implementation is admitted. No timings now. A branch can harm prediction/vectorization or code layout enough to erase the benefit; reduction in writes is not a performance verdict. Lower rank because the supplied pattern diagnostic points at writer work, not because induction is intrinsically cheap.
