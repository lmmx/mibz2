## 1. Directed four-gate screen (stop at first "no")

### (a) Escape: Does it give facts outside `𝓡`? — **NO** `[proved]` (for canonical BV/Ostrowski acquisition; `[argued]` via Record 100 §1 for arbitrary interval-vertex BV diagrams)

In symbolic dynamics and interval-exchange theory (Vershik 1981; Durand 1998; Berthé–De Felice–Dolce–Leroy–Perrin–Reutenauer–Rindone 2015), a Bratteli–Vershik (BV) diagram `B = (V, E, ≤)` represents a discrete IET `(LF, [0, n))` via nested Kakutani–Rohlin towers:
- Level-0 vertices `V_0` are the base intervals (the `r` maximal runs of `L`, or the pieces of an induced return map).
- Edges `E_k` from level `k` to level `k + 1` record how each level-`(k+1)` tower traverses level-`k` towers, ordered linearly by the Vershik order `≤`.
- **Ostrowski / Dumont–Thomas numeration** assigns to each text position `j ∈ {0, ..., n - 1}` its unique greedy digit expansion `(e_0, ..., e_{D-1})` in `B` by subtracting tower heights `h_v` top-down, giving random positional access `j ↦ T[j]`.

We separate **readout** from **acquisition**:

1. **Readout (given `B`) is positional (E2) `[proved]`:** Given `B = (V, E, ≤)` and the tower heights `h_v = Σ_{e=(u,v)} h_u`, mapping a path `(e_0, ..., e_{D-1})` to its Vershik rank `j = Σ_k Σ_{e' < e_k} h_{src(e')}` is a positional fact outside `𝓡`.
2. **Canonical acquisition of `B` from `(L, p)` is strictly inside `𝓡` (`R1`) `[proved]`:**
   - For a discrete IET `(LF, [0, n))`, the Kakutani–Rohlin tower sequence is generated by **Rauzy–Veech induction** (or return-word / endpoint induction): each elementary incidence matrix `M_k` records one interval split (`Restrict`) and one return composition (`Compose`) in `𝓡`.
   - Every maximal width-1 run `R = {x}` (`h₁` of them) is a level-0 vertex of measure (width) `1`. By Record 92 Lemma 3 (width monotonicity), any rigid tower merge absorbing `{x}` into a higher-level tower acts on a width-1 interval `{x}`, incurring at least 1 width-1 event in `c₁`.
   - By Record 98 Theorem G1 (on single-cycle columns, repaired per `N-1`), building `B` from `(L, p)` by Rauzy–Veech / Kakutani–Rohlin induction therefore requires **`c₁ ≥ h₁`**. Calling the resulting induction DAG a Bratteli–Vershik diagram and reading positions top-down by Ostrowski numeration is **R1 (reshaping inside `𝓡`, the salami trap)** — the positional coordinate is obtained only after paying `c₁ ≥ h₁` to construct it.
3. **Non-RV acquisition obstruction for interval-vertex BV diagrams `[argued]`:**
   - Even if one drops Rauzy–Veech induction and asks for *any* construction of a BV diagram `B` whose level-0 vertices are the maximal runs of `L`, every width-1 run `R = {x}` is a singleton vertex that must receive at least one outgoing edge in `E(B)` connecting it to its parent tower.
   - Under Record 100 §1 (anti-cheat clause 1: `c₁` charges single-row determinations of *any* fact type), determining each width-1 vertex's incident edge from `(L, p)` costs `≥ 1` per width-1 run (`c₁ ≥ h₁`), unless a single multi-row rule (`subject size ≥ 2`) determines the BV edges of `≥ 2` scattered width-1 runs simultaneously. Standard BV/Ostrowski theory provides no such scattered-set grouping; its vertices are contiguous intervals of the phase space.

### (c) Viability note (diagnostic) `[measured]`

The cost of Ostrowski/BV numeration scales with the **number of diagram edges `|E(B)|`** and **depth `D(B)`**. On a 2-letter Sturmian block (`n = 900,000, r = 2`), `|E(B)| = O(log n) ≈ 40` (`≪ h₁`). On the six admitted Wikidata blocks, the canonical RV Bratteli diagram (Cells' induction DAG) has `|E(B)| = 1.68–1.87r = 86k–240k` edges (`> h₁`), of which at least `h₁ = 34,262–97,054` (`63–75%` of runs) are width-1 merges. Even an ideal DAG collapsing all repeated substrings cannot merge unique GUID random nibbles (`18,810–57,090` width-1 rows per block).
