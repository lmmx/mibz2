# Sparse rank landmarks with direct final-slot output

The frozen edge emitter follows one packed successor chain, writing a literal or dictionary slice before testing the mark. Select rows with the same residue as the primary modulo a power of two. This always includes the mark. A first pass follows independent subchains from all selected rows, recording their end landmark and exact spelled length. Walk the coarse primary cycle to assign output starts. A second pass follows only primary segments in independent lanes and writes each label directly to its final output range. Any further periodic copies use the original repeat rule. The intended scratch scales with landmark count and lane count.

Historical ranked Open-Return at 2b53453 already selected the primary residue modulo 128 with eight lanes. It staged one word code per visited rank before serially expanding in segment order. The dictionary anchor writer at 9a93d9d overwrote edge tags and buffered literal tails. The GPU Helman–JáJá review described per-row list IDs and local ranks plus a final scatter. These alternatives do not price the proposed second walk and direct dictionary copies.
