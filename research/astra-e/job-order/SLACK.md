# Single age and service tradeoff after the longest-first panel

The first registered panel found that unrestricted and four-oldest longest-first could delay ordered release. Test one policy integrating the service estimate with publication urgency, without fitting a coefficient. Under mean throughput one completed block takes one service interval divided by W. A block j with predicted service d_j and a soft ordinal deadline j has latest start j−W d_j/mean(d), measured in block-completion intervals. Among already complete queued jobs, select the smallest latest start, ties FIFO. For the deployable estimate use symbol count per block and its arithmetic mean among all jobs enqueued so far. The scanner already knows all these quantities. The diagnostic oracle substitutes true per-job work and a prefix mean. Neither knows future releases or delays an idle worker. Use the unchanged frozen model, eight W4 traces and the same central/stressed target scenarios. The comparison is post hoc relative to the preceding longest-first study and prespecified for these two policies.
