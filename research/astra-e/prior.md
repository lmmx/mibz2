## Exact constraints and results worth building on

* Stable LF maps the kth occurrence of each byte in L to its kth occurrence in F. The primary selects the component and phase. Produce exactly n inverse bytes, even if the marked cycle closes early. RLE1 can expand or contract this length. The scorer checks independent per-block and combined-stream CRCs, mutation results, periodicity, arbitrary multiple-cycle columns, scalar and detected paths, and worker drains. [Release implementation](https://github.com/lmmx/mibz2/tree/1edb29fdc3d42dfddfc3d60e46456b611323760c/src) · [Gate](https://github.com/lmmx/mibz2/blob/9c31461df7bef24cecf79348545b27ee26846835/bench/moonshot/src/check.rs)
* Adjacent-rank induction certifies equal words from source adjacency, compact image adjacency, equal return length and a boundary bit. Its per-level bound is 3R−2 retained atoms. Ordering and eventual expansion still cost work. In Open-Return, a restriction to narrow runs including the primary leaves 89,874 retained rows on frozen, with 50,709 representative letters and 11,215 endpoint steps at width 16. The representative and marked exit must both be correct when contracted words replace a chain. [Adjacent-rank review](https://github.com/lmmx/mibz2/blob/276db91c46df7027534785562a89bdac669e635c/docs/journal/monodromy/2026-11-18-rank-gap-verification.md) · [Open-Return review](https://github.com/lmmx/mibz2/blob/432a6ce03857b21e57b03ff8d97094d0f96eff97/state/reports/open-return-6978698021/report.md)
* The frozen forest retains 10,955 chords from 62,138 overlap arcs. Routing that first cut takes 16,230 reported bands or 48,647 slab stack matches. ## First engineering discriminator

At width 16 on frozen, queued Open-Return builds its exact table in 1.847 ms and emits in 1.019 ms (medians of rounds 2 onward in the historical VM file). Both phases matter. Count retained literal edges, nonliteral edges, residual table size, and the fraction of blocks that need the separate wide-code table. A branch specialised once per block can handle the two edge layouts separately. A larger opportunity is to pay once for each return band's spelling/exit descriptor and bring the navigation table into a private cache. Charge both residual rank-to-band lookup and dictionary access per visit. Compare complete block times, inspect a code-size control and reject a table compression that saves capacity but adds a costly dependent lookup. Include ungated Open-Return as a high-density comparison on real blocks and text.
