# Exact partner acquisition and the protected contraction bound

For a physical convex stable source class I, T is strictly increasing on I. Its image lies in one chosen convex target class J if and only if the two endpoints of T(I) lie in J. Original bands and queues supply a row endpoint with a band rank, its queue offset and one existing Q access. New physical class-start rank supplies its target ID. The data check compared this two-endpoint test for every class against an independently enumerated full pair histogram. It works on the alternating column as well. An equal-spelling target may have disjoint physical pieces, so an endpoint match on just that raw spelling does not certify the interior. The equal-spelling results below grant complete recognition by scanning true transitions.

If I has one distinct successor class g(I), selecting it appends its successor spelling to I and skips the former destination row. A set of selected classes with neither endpoint of one selected arc pair both selected has disjoint deleted positions and exactly sum(width(I)) fewer residual rows. This is an original-admission structural count over the whole permutation. The closed-form count coincides with marked visits on these real tables; on arbitrary marked components only the concerned orbit counts. A marked deleted destination is recovered at its retained predecessor with an offset of the predecessor’s original weight. If the marked section must survive, exclude it both as a selected class and as a target of selections. Self transitions are ineligible for this pair rule. Two selected classes can have the same unselected target since their destination rows are disjoint. Each retained selected convex source remains increasing under the composed return, through a single convex stable destination class. Compression of retained rank order preserves its stability.

The dependency graph has at most one outgoing edge per eligible class. Delete ineligible endpoints, strip leaves by maximum-weight independent-set tree DP, then solve each residual cycle with first-on/first-off path DP. The independent verifier compares the result with enumeration of every legal selection on every partial loop-free functional graph through five vertices with varying positive masses. The bound is specific to this pair rule. Equal raw word types may also be merged in a nonordinary graph. The corresponding calculation gives that approach free full-transition information.
