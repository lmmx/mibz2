# Obtain the first protected cut certificate without an incoming RLE

The 14,430,696 run/bucket fragments of the first ordinary protected cut are avoidable **for cut choice**. Starting after the original edge bands, word labels and byte queues, the direct method obtains the same joint source/target mass for every pair of seeded source classes on every admission. It never queries the dense old successor or publishes its high-ID incoming to acquire those masses. The chosen XOR cut therefore has the same 6,842,139 entering rows and the same protected-primary orientation as before. [Corpus-by-corpus acquisition](choose.csv) · [Independent full-root comparison](check.txt)

Give source classes their ordinal IDs by merging physical bands of equal old spelling, with the primary rank its own singleton. A bitmap and prefix counts map any physical y to its source class J. Split an old band also where it crosses a seeded boundary. Within resulting piece x=d+i with source class I, T(x)=Q[k+i] is increasing. The observed target classes J occur in order, each on a single consecutive subinterval. Following bands of the same I preserve this order by the global equal-spelling monotonicity theorem. Hence adjacent identical (I,J) records can be coalesced. Their widths directly supply the full E(I,J) counts, or just D[I xor J] if only a parity cut is desired. The numeric scorer checks all E against independent dense counts.

For a current queue position read Q[pos], rank it to J, and take the remaining piece immediately if its already loaded last Q rank is below J's upper boundary. Otherwise use exponential search followed by binary search for the first Q beyond J. On the corpus, 827,858 original bands become 827,937 source pieces after the singleton refinements. The scan obtains 2,568,304 fragments, of which 607,218 have width one, coalescing to 2,401,001 distinct seeded ordered pairs. It costs **11,692,513** explicit Q reads, **2,568,304** destination bitmap-rank queries, 827,937 source rank queries, and subsequent per-fragment mass additions. The old constructor has already paid its own queue writes. Additional physical band ordering, class-boundary setup, exact byte aliases and cut scoring also remain chargeable. A smaller record count is not a CPU benchmark. [Native direct algorithm](choose.cpp) · [Complete ordinary route](../CUTS.md)

The joint masses alone do not encode the marked return. Take ordered source labels F=0122 with singleton primary 0. Incoming ID columns L=1202 and L=1220 have exactly the same count of every (source, destination-class) pair. Stable decoding starting from zero gives four emitted IDs 0210 in the first and 0221 in the second. The order *within* a target bucket has been lost. The direct method still has Q and the bands, so those original relations are available, but recovering deleted row ranks, merged partner spellings and the correctly ordered next residual requires a distinct publication algorithm. The bound supplies a genuinely cheaper candidate list and a counterexample to any solution claiming reconstruction from that list alone. [Reproducible witness](check.py)
