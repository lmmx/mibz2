# Per-page successor displacement

Keep the original physical row ordering, every edge and its original numeric word code. Test 16-, 32- and 64-row successor pages. A page chooses raw bitpacked rows or an integer-slope prediction base + slope × local index, with at most eight exceptional positions and at least three quarters of the positions regular. Candidate slopes are zero, one, the rounded endpoint slope, and the median adjacent difference. For each number of exceptions and each tested slope, find the narrowest interval containing enough residuals, including repeated values. Compare the complete format with a blockwide raw-bitpacked fallback. Independently address every original label through a separate 16-row constant, palette or raw page, or globally packed labels if smaller.

Measure a floor for the same page formats allowing every integer slope. For a fixed stride, removing each exceptional point removes at most two pairs. All surviving differences must lie within twice the regular residual spread of each other. This yields a data-dependent, optimistic lower bound on the number of bits needed by a regular offset. Apply separately for strides 1, 2, 4 and 8. Keep the cost of page pointers, masks, exception values and block header. Compare with the previous three-byte split-label P16 implementation on the identical input. Price the byte representation and validate every random access. The result is a structural screen, without performance timing.

## Native commitment

Freeze 32-row successor pages and the 16-row numeric label palette before native measurements. The all-block 64-row layout gained only 468,420 more bytes of aggregate storage and one more 256 KiB fit with the original spelling dictionary. Preserve all original edges, the marked rank, same spelling, and the same periodic repeat. The reference endpoint first materializes the original packed edge array. The second pass builds the new representation from it, then clears the original vectors while retaining their capacities. Encode the CPU cost of both passes and include the original edge-vector capacity in the memory result. For fast unaligned reads, give both byte pools seven guard bytes and charge them. The native interface is an isolated generated kernel.
