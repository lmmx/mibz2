# Stable high-nibble queue scatter

The measured edge constructor appends every retained L rank to its byte's row queue. Stage one would append one packed descriptor per retained piece to one of 16 high-nibble streams. Stage two would consume each stream in stable order and fill the original row queues. The experiment holds the old strip, band, mark and emission semantics fixed. The earlier queue-spans experiment replaced each final queue with spans and changed band projection. [Queue spans](../queue-spans/README.md) · [Edge admission](../edge-budget/README.md)

Test all actual edge admissions in the frozen Wikidata stream. Compare the original order, grouped final-row writes alone, and the complete staged queue/descriptor reference trace. Model 64-byte lines, warm reusable queue capacities, and fully associative LRU from 1 through 32 KiB. Vary queue alignment and measure set conflicts. Count retained pieces, rows and obligatory descriptor stores and loads. Reading one packed word for each reconstructed piece is real work even if all loads hit. The cache model omits other data, instructions, write bandwidth, allocator growth and hardware prefetch. It makes no prediction of decoder wall time.

Advance to a native comparison if the complete staged trace reduces modeled line misses at both 8 and 16 KiB or if an observed set-conflict/alignment exception plausibly changes that diagnosis. A model advantage limited to severe queue-capacity starvation warrants recording its crossover. Quantify the best improvement that only optimizing final queue order could deliver. Preserve raw block and locality data on rejection.
