# One turn of the open endpoint exchange

Suppose a strict winner A is at the end of one order. Write the other order as P A B C, where C is a nonempty suffix of distinct losers and B may be empty. Let C consist of consecutive tail elements whose cumulative width stays strictly below A's starting width and does not exceed the amount left to eliminate. The primitive endpoint takes the tail element and moves it immediately after A. After the last j elements of C have moved, those same j elements occur immediately after A in their original forward order. What remains of C is still the live tail. Induction gives P A C B after the entire suffix. A loses the sum of its losers' widths. No loser changes width. Each hypothetical intermediate winner still has positive width.

Joins occur in reverse traversal of C. For an original top winner, each losing bottom handle becomes join(A,loser). For a bottom winner each top loser becomes join(loser,A). The winner's handle stays unchanged. The arguments to each chronological join are therefore identical, including the case of equal handles on distinct nodes. This implies identical inline encodings, rule append order, symbol lengths and rule references by induction, for arbitrary valid incoming word handles. Subsequent writer access sees identical live orders, widths, marks and words at every legal termination of this computation. The claim controls the endpoint stage; the original mark and its surrounding constructor still require the separate complete decoder gate. The earlier full-Cells one-turn substitution proof is MONODROMY 20 at `2b7a6871`. [Original full-exchange result](https://github.com/lmmx/mibz2/blob/2b7a6871/docs/journal/monodromy/2026-11-16-loops.md)

When B is empty the chronological moves form a complete rotation and restore the original links. An implementation can skip all links but must still record all joins, loser handles, width loss, eliminated width, and primitive step count. Always applying the three nonidentity joins is incorrect: in a tail A, U, V it links V back to U instead of to the sentinel. The reference deliberately starts a fresh group on each complete turn; a large winner may revisit the same physical nodes the next turn, with the *updated* word handles. When the remaining winner width equals the next loser's width, the original asymmetric equality step retains the top node's joined word and removes the bottom node from both lists. Coincident endpoints remove their common node from both orders without a join.

The executable compares array erase/insert operations with an independent pair of intrusive circular lists. It compares both physical orders, both directions of every live link, node widths and handles, every chronological join including empty/immediate cases, and the appended binary rules after *each* group. It enumerates every scalar-legal stopping budget. Only budgets on scalar step boundaries satisfy the original endpoint's precondition. All permutations with up to four labels and widths 1–4, all five-label permutations and widths 1–2, and four adverse long examples are covered. Fixing the first order to increasing labels removes only a simultaneous label renaming. Three starting handle layouts include zero, aliased literals, two- and three-byte immediates and an older concatenation rule.

All 31,224 layouts and 239,097 stopping horizons passed. The comparison included 885,234 primitive steps, 40,602 groups with multiple losers, 31,089 complete multi-loser turns, 5,286 boundaries stopping before the next strict step, and up to 49 consecutive whole turns of one winner.
