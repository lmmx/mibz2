# Construct whole equal-prefix intervals

The first paid constructor cost about 13.8 ms for quadruples against 6.8 ms for stock’s 1,796 tables. Test a dyadic fill that recovers the identical four-byte LUT without taking every prefix through the full constructor. At ten-bit probe w, record a decision depth d. Every ten-bit index sharing its first d bits must receive that exact entry. Successful final phrases need only their consumed code lengths, and a reduced alphabet ID that precludes any longer phrase is decisive as soon as that code finishes. When remaining bits are shorter than the table’s minimum code length, no extension is possible. If an attempted next code exceeds those remaining bits, or encounters invalid/long, conservatively use depth ten. Fill to the end of the corresponding aligned dyadic interval. The lookup preserves each row’s first symbol and length, so already filled rows remain valid probes. Raw entries and complete decoded semantics will be checked. If this fails to reduce setup or complete scanner time, retain the independent scatter candidate.
