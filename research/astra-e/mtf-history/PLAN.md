# A last-occurrence selection front

MTF order after any prefix is the list of previously selected identities sorted by last use, followed by unseen identities in original alphabet order. Divide that order at the last 64 literal updates. The recent list becomes one live bit per still-current literal position, ordered by recency, and the older identities occupy a residual deque. A rank selects the corresponding live bit or a residual deque index. RUNA/RUNB repeat the current first byte and leave all last-use times intact. Opening repeats can precede every literal. The 64 is a sliding age window, independent of whether literal bits cross a stock bitmap-word boundary.

For rank r<64, deposit one bit at position r into the live mask with BMI2 PDEP. A nonzero result gives the bit of the requested old occurrence. Its trailing-zero count addresses a 64-byte circular history. Clear the bit. A zero result (and every r≥64) takes the original r less the live popcount from the older deque. Once the chosen identity is removed, a still-live oldest bit means the overwritten ring cell names a current identity: prepend it to the old deque in O(1). Shift the mask, insert the new identity at bit 0 and advance the write pointer. The deque pop can cost up to 255 byte copies (less for a head-based circular representation). This alternative has no composed-shuffle table and never moves a recent list prefix. It introduces a serial PDEP, bank lookup, and a potentially short store-to-load dependency in the history, and up to two extra tail decisions. Resource costs must include them.

Cheapest falsifier. Use a stock scalar list of ordinal IDs to collect recent hit share, ageing events and residual copy lengths on every one of 431 real Huffman blocks, with W=16,32,64 sliding literal updates. If W64 misses more than one fourth of real literal updates or averages more than two residual shifted bytes per complete literal, reject the simple deque before implementing. A survivor receives a complete native RLE2/MTF/record front, compared with stock after real cap records and both per-byte counters have been materialized. Keep the 32-rank worker's current stock-anchor result independent. No production changes.

The W=64 census passes the gate at 92.34% recent hits, 7.64% age-outs and 0.584 tail-byte shifts per literal, costed across every real route. The following stronger invariant removes physical tail wrapping. If d recent identities are live, store the older suffix in T[d..256], in global rank order. A tail removal at r reads T[r], moves T[d..r] one position right and increments d. After the raw hit/miss step, decrement d and overwrite T[d] with the oldest ring cell only when that cell remains live. Slots below d have no meaning. Thus initializing the 256-byte fixed tail once per block suffices, and only positive residual shift lengths move data.

Gate each exact frontend on 11,770 boundary and malformed streams plus all 431 original column fronts. On a survivor run three six-order-balanced, 12-round trials at stack depths 0, 3 and 9, comparing the shipped library front, same-source copy, and the new history selector with the actual full stock RLE2/record code. Each timed sample includes the bitmaps, list initialization, emitted cap records, counters and validations through all 383 selected stock fronts. Use one shared cap scratch for both generated arms. Freeze a separate complete worker, gate against libbzip2 and record large declined rows if the stage evidence indicates useful headroom. A direct complete decoder or connected marked block-level exact check is required even if the native timing rejects the state representation.
