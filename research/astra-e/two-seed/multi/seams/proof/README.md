# RLE1 parsing across physically separate bounded arcs

Let x be the finite RLE1-coded bytes in logical marked order, after any period repetition and clipping to the declared block length n. A token is one literal byte or a quartet of equal literals followed by one count byte. The count is unsigned and can be zero, 255, or the same byte as the quartet. The stock parser greedily recognizes the quartet first. Four final literals awaiting a count give `RunUnfinished`.

## Token separation and state reset

At an internal cut i, require x[i−1] ≠ x[i]. Also require a witnessed inequality among the last four raw bytes ending at i−1. When i < 4 measured from the **true block start**, the second condition is automatic. A simpler sufficient witness, when available, is x[i−2] ≠ x[i−1] together with the first condition. A fragment start inside a block introduces no such exception. If the prefix contains fewer than four observed bytes but includes a witnessed inequality, that inequality suffices even for unknown prior history.

**Left side.** A five-byte token crossing i in its first four literal positions would have two equal bytes on opposite sides of the cut. If i is just before its count, four identical raw bytes end immediately before i. Each possibility contradicts one condition. A malformed unfinished quartet crossing i fails the same adjacent-byte condition. Greedily decoding the left side therefore ends at a complete token boundary and produces its full original output. The partial literals in a streaming implementation need not themselves constitute an empty state.

**Right side.** After at least four visible preceding bytes, a streaming entry that is still awaiting a count at i requires all four immediately preceding raw bytes to be equal literals. The inequality witness excludes this. Otherwise the decoder is empty because x[i−1] was a count, or its last partial run consists of x[i−1]. The first right byte x[i] is then a literal with run length one regardless of the incoming state. Every subsequent transition, output and final error agrees with an empty-entry parse of the right side. Arbitrary prefix states, including four foreign literals followed by a count in the fragment, satisfy the argument. A numeric count can equal the previous run byte and reset the state. Treating it as another literal would break this proof.

The stock scalar implementation withholds the terminal four bytes on error. The left-side token-boundary proof also gives equality of its partial append before an unfinished right tail. The complete decoder saves the caller’s initial length, rolls back on RLE error, and computes the block CRC on just the newly appended output after successful RLE1. A stored mismatch rolls back with `BlockCrc { stored, computed }`. The separated parser retains this order, so a bad count ending takes precedence over a bad CRC. The combined stream CRC uses the same sequence of accepted block CRCs. [Stock parser](../../../../../../src/rle.rs) · [Block finish](../../../../../../src/lib.rs)

## Necessary counterexamples

* The five-byte block `09 09 09 09 | 00` is the shortest failure of a merely adjacent-different cut. The whole block decodes to four literal 09 bytes. The separate left side returns `RunUnfinished`. No shorter block can place a real count at a cut.
* In `01 02 | 02 02 02 00` the last two left bytes differ but the right starts with another 02. The complete parse emits 01 and four 02 bytes. Separate parsing emits an extra 00. The shorter witness still needs the cross-cut inequality.
* In `04 04 04 04 04 | 08` the fifth 04 is a count. The split is valid for this actual parse despite the final four equal raw bytes on the left. These certificates are sufficient.
* Suppose a fragment starts at the last two bytes of `07 07 07 07 | 00`. Granting the short-prefix exception after the visible 07 would misclassify its successor. The true parser is waiting for its count.
* A one-byte periodic raw lap of 07 repeated to length four is unfinished. At length five its fifth 07 is a count and the eleven output bytes are 07. A periodic cycle closing does not close or reset the RLE state. Certify cuts at true logical coordinates and supply only the n-byte clipped extent.

## Nearest certified bridge

Given fragments in logical cyclic traversal order, each byte remains at its physical offset until the original full-rotation fallback or the last read. At a certified seam, invoke the stock RLE parser separately on the neighboring portions. At an uncertified seam, choose the nearest certified position up to W=32 bytes backwards within the left fragment and the nearest up to W bytes forwards within the right. True block endpoints are valid positions. A check may read the logical four-byte left halo through the fragment map. If a witness is absent, including inside a short fragment surrounded by a long constant run, select the original joined route. Make every choice before appending any output.

**Nearest cuts cannot cross.** For two uncertified seams around one fragment, let p be the earliest certified position reached from its left and q the latest reached from its right. If q < p, then q is also within W of the left endpoint and was available strictly earlier in that same nearest search. This contradicts selection of p. A certified neighboring seam consumes no trim. If p=q the untouched fragment body is empty. An empty interior fragment at an unsafe seam fails the radius test. Hence the overlap guard is redundant mathematically whenever all radius searches succeeded against one position-invariant predicate. Keeping the check defensively preserves correctness.

Partition each accepted fragment into prefix, body and suffix. Decode bodies directly. Copy the left suffix and right prefix into one bounded scratch buffer and decode their concatenation once in logical order. Every piece starts and ends at an actual certificate or a true block endpoint. The bridge interior can contain any number of equal bytes or count fields. With k fragments there are at most k−1 bridges, at most 64(k−1) total bridge bytes copied, a 64-byte scratch buffer reusable for all bridges, and O(k) span metadata. Each uncertain seam tests at most 2W candidate positions, with at most five logical raw-byte loads per test. The implementation with k≤4 can resolve each logical byte by scanning at most four endpoints. The exact tests and suffix/prefix copying are real costs. Disjoint immutable raw storage and an ordinary final-output vector avoid overwriting input during RLE expansion. Final output capacity, the scalar/AVX reserves, CRC, misses and full fallback remain paid. A cut may destroy an AVX2-length stretch by splitting it into short input spans.

**Limits of bounded certificates.** On a run consisting entirely of one raw byte c, let k=0,1,2,3,4 be the incoming consecutive literal count modulo five, with 4 denoting an awaited count. For any number L of consecutive c bytes, the five states end in five distinct phases (k+L) mod 5. The count can itself equal c, so a longer constant window gives no reset. For every finite W there exist completed streams sharing a uniform 2W-neighborhood in which the seam is a real token boundary in one stream and lies immediately before a count in the other. For example, with W=32 a split of a 70-zero block after byte 35 is an actual token boundary but has no local strict certificate. A completed 75-zero block split after byte 39 has the identical local window and the next byte is a count. Supplying the modulo-five phase can distinguish the cases. This lower bound applies to local state-independent recognition and leaves checkpointed or stateful fragment parsing open.

**Decoded bridge size.** A successful m-byte standalone slice with q complete run tokens expands to at most m+254q bytes, since each five-byte token can produce 259 bytes. Thus at m≤64 its expanded output is at most 3,112 bytes. Twelve zero quartets with an ff count and four alternating trailing literals attain equality at m=64. The bridge is decoded straight into the final vector. A hypothetical fixed-size decoded bridge buffer would need to account for this expansion.

This specializes F5’s earlier safe-cut transducer theorem to a few physical reconstruction arcs. F5 proved reusable interiors of dictionary words from the same strict input predicate. The separate monochrome-cylinder study located Ψ-images of every b⁴ row to conservatively protect complete quartet-plus-count windows on the whole marked output. Here only O(kW) candidate positions are examined once raw arcs already exist. The global hazard dictionary and its construction are unnecessary for this test. The bounded fragment bridge, its no-crossing theorem and the fallback resource bound concern the four-forward representation. ## Exact verification

`check.py` uses a greedy whole-string token oracle independently of the certificate. It preserves the partial emitted bytes even for a malformed block. It exhausts ternary words and all 17 reachable incoming-state representatives (empty or 1–4 repeats of a test byte or foreign 255). Every one- and two-seam partition is checked at W=2 to force competing neighborhoods. The W=32 fixtures include periodic clipping, long uniform inputs, short fragments and a realized 64-byte bridge. A further 8,192 partitions cover every count value 0 through 255 and quartet bytes 0, 1, 4 and 255. Each of the 244 boundary and period fixtures checks both a correct CRC and a corrupted stored CRC with a nonempty caller prefix. The independent MSB-first bzip2 CRC routine checks the standard `123456789` vector, 0xfc891918.

```bash
d=research/astra-e/two-seed/multi/seams/proof
taskset -c 0 nice -n 16 python3 -B "$d/check.py" --max-length 8 | diff - "$d/receipt.json"
```
