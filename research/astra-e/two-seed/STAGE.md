# Native emitter differential

With all 233 real Wikidata tables checked and the same output capacity history in every arm, the simple provisional-split and boundary-directed writers reduced mean emitter CPU to 0.9221 [0.8876, 0.9578] and 0.9228 [0.8879, 0.9591] of the frozen edge writer. The one-forward writer holding the same store representation ran at 1.0115 [0.9703, 1.0543]. The new writers’ intervals relative to that control were 0.9116 [0.8843, 0.9397] and 0.9124 [0.8828, 0.9428]. Each contrast pairs the two same-code labels for an implementation using the geometric mean within each of 40 complete 14-block rounds. All four same-code intervals include parity. These are CPU observations of the emitter on this Xeon. [4,480 raw observations](paid.csv) · [All contrasts and block intervals](summary.json)

Both writers executed 6,496,920 two-edge iterations across the real admissions. Sixteen blocks hit a provisional byte boundary before either seed closed. The simple writer relocated 57,966,109 initialized bytes. The boundary-directed writer relocated 52,763,621 bytes, each staged byte at most once on these full-return blocks. The two implementations have a measured stage ratio of 1.0008 [0.9622, 1.0410]. The smaller copied volume breaks this tie for the whole-worker trial. Each uses the ordinary output's original reserve size and no second allocation. All 209,697,662 real pre-RLE bytes matched an independent eager Cells decoder.
