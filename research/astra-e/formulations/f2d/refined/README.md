# Seam-refined powers of LF for actual first-level unary discovery

Existing [whole-run certificates](../) at `a095bfa` can skip through a run whose entire LF image fits its certified successor. Its native [eight-lane learned successor](../frontier/) at `796c2bf` also preserves the original 12-byte run cell. The [exact band memo](../../f2-dual/) at `ad512f2` intersects original-run intervals with translated downstream corridors along representative paths to maximal first returns. LF² and superalphabet walks are older BWT inversion machinery. This experiment uses the original-byte seam refinement at every depth up to k, to certify entire *current FM intervals* in the first quote trie. It retains bounded spellings and tests actual interval widths. A source run whose image straddles a seam can have several valid descriptors. It is not a whole-run successor table. The lazy exact-cell variant is the finite-horizon restriction of the band-intersection principle.

**Partition.** At depth one, each maximal L run is affine. For each depth-j cell, its live original rows are translated by LFʲ and spell the same j backward bytes. Split that image at original run seams and map the cuts back to the source. Distinct live-cell images are disjoint since LFʲ is a permutation. At most r−1 new cuts arise at a level. The unrestricted and quote-stopped partitions both have at most min(n,1+j(r−1)) cells. A stopped cell returns the displacement to its first original L quote and preserves that terminal run id; the quote byte is excluded from the consumed spelling. A previously stopped cell incurs no further split. Maximality follows from the first differing itinerary byte at a new seam. Adjacent equal byte itineraries with no internal seam share the same accumulated translation. The dense checker verifies each partial displacement, stopping run, spelling and interval boundary on all 3,279 ternary columns through length seven, including examples attaining the bound. [Exact check](small.json)

The structural builder prepends one original affine step to a previous stopped table and intersects their intervals. It records both the general LF-power count and the smaller stopped count. At k=4 a separate composition of the two-step table with itself checks *every* final boundary, translation, spelling and terminal run, and avoids constructing a three-step table. The prototype binary-searches for the first intersected previous cell. An implementation can replace those seeks by scanning in image order and arranging pieces back into source order, which requires its own ordering, rank-directory and storage work. The final table alone needs one emitted descriptor per resulting cell. All intermediate emitted intersections are counted separately.

**Queries and width.** A single location on the refined table addresses the interval's left end. If its right end is within the same descriptor, consume the known nonquote bytes and cumulative displacement. A recorded quote gives the native terminal run directly. If the interval crosses the refined boundary, use the stored first original run id to execute one original unary step or classify a branch. Closing branch selector scans and complete edge/dictionary spellings remain payable. Every leap is checked against the literal node-by-node ordinary LF path. The eight-lane model publishes actual children after their parent completes, in ascending lane order, and refills available lanes before the next query. Reducing those query waves does not make differently sized descriptors equally cheap on a real cache hierarchy.

**Lazy prices.** Exact per-original-run construction is charged for all source cells in requested run buckets and all prerequisite image intersections. For the separate per-cell memo, the initial original run lookup selects a cache bucket on every call. On first use, walk up to k original runs, preserving left and right slack after every translation, and charge all additional original ranks. This independently recovers the exact precomputed maximal interval and spelling even when the query interval crosses its seam. The census counts memo entries, missing-cell classification and subsequent original ranks. Cache lookup/insert work and the cost of updating intermediate state still apply.

Frozen has 51,184 original runs. Eager LF² uses 57,904 stopped cells and reduces dynamic discovery from 70,560 original queries to 36,497 refined queries. LF⁴ uses 61,854 cells and 19,433 refined queries, but its two-level doubling construction emits 119,758 descriptors in total. Only 14,476 final cells are queried at k=4. An exact on-demand memo instead requires 60,558 (k=2) or 60,408 (k=4) original rank lookups including cold construction. The earlier measured whole-run learned constructor used 51,229 on the same input. The count tradeoff rejects a claim of cheap eager setup or superior primitive-rank traffic from this particular lazy memo. It does not establish a runtime lower bound, since sequential setup might cost less per action than dependent rank queries. The present experiment implements no worker or allocator change.

Across the **nine admitted systematic blocks**, counting all retained queries and compulsory final work, modelled discovery goes from 751,521 queries / 94,236 eight-lane waves to 388,508 / 48,705 for LF² and **207,250 / 25,983** for LF⁴. The unchanged schedules' baseline query and wave counts agree exactly with the native dynamic scheduler on each block. The four-step construction emits 674,963 stopped final cells and 1,306,769 intermediate plus final cells using doubling, for 544,271 avoided ordinary probes. The simple builder makes 1,151,789 first-image seeks. A lazy per-original-run doubling construction can restrict this to 523,644 emitted pieces, but must still identify run buckets and intersect their subordinate tables. The exact cell memo pays 651,152 original ranks before memo lookup/bookkeeping, compared with 553,516 for the existing eight-lane whole-run certificate on the same inputs. Only 155,677 distinct final four-step cells are queried. The input density-refused tenth block is recorded separately. These tradeoffs support revisiting a physically economical constructive index; the query count alone cannot advance a worker. [Complete census](real.csv) · [Paired-input totals](summary.txt)

A straightforward immutable four-step descriptor would store a four-byte source start, four-byte displacement, four-byte tagged first-run identifier, four-byte terminal-run identifier and four inline spelling bytes. This is 20 bytes per cell before original branch records, location directory, construction scratch and allocator capacity. On frozen, the final stopped table alone would occupy 1,237,080 logical bytes in that representation. Other encodings can change this price; there is no process-RSS measurement for this structural prototype.

Reproduce the capped run inputs using the existing F2d extractor, and the counts using Python from the worktree root:

```sh
study=research/astra-e/formulations/f2d
tmp=$(mktemp -d)
cargo build --release --locked --manifest-path bench/moonshot/Cargo.toml --target-dir "$tmp/build"
rustc --edition=2021 -O "$study/extract.rs" --extern mibz2="$tmp/build/release/deps/libmibz2.rlib" -L "dependency=$tmp/build/release/deps" -o "$tmp/extract"
"$tmp/extract" corpora/wikidata.bz2 "$tmp" > "$tmp/inputs.csv"
export PYTHONDONTWRITEBYTECODE=1
python3 "$study/refined/check.py" | diff - "$study/refined/small.json"
python3 "$study/refined/refine.py" "$tmp" | diff - "$study/refined/real.csv"
python3 "$study/refined/summary.py" | diff - "$study/refined/summary.txt"
```
