# How many runs can marker induction create?

Consider all section rows in original rank order. Their labels are the reverse words read from each row to its first positive LF return. Reversing every label preserves equality. Let r be the original number of maximal L runs and t the number of runs of these complete return labels. This counts the induced token last column. The bound deliberately excludes work to discover the labels.

**A word section.** For S=I(P), where P is any one nonempty word, t ≤ r. Two adjacent section rows begin with identical P. While the two predecessors have the same byte they map by the same LF translation to adjacent rows. The prepended equal bytes followed by P determine the first |P| bytes at each reached row. Both rows therefore hit S simultaneously or both continue. A difference in their return label requires an original L-run seam. Each source gap before the first mismatch has a unique reverse path (LF is bijective); distinct internal starting gaps cannot claim the same seam. Otherwise the longer path would already have re-entered S when it met the other start. Thus at most r−1 internal section gaps can change label. Equality is attainable with P of length two. The statement applies equally to a token BWT over any ordered alphabet, so exact single-delimiter recursion has a nonincreasing sequence of run counts. Equal consecutive counts can persist even when the number of residual rows shrinks.

**Several markers of the same length.** For k distinct nonempty word cylinders of a common length, internal adjacent rows of any one cylinder have shared enough context to answer membership in their entire union after each agreeing step. The same injective seam argument applies across all the internal paths. The concatenation of the k sorted cylinders adds at most k−1 seams, even if some of those cylinders touch in rank space. Hence t ≤ r+k−1. The examples in the exhaustive receipt attain the extra seam at k=2. This permits marker sets including several equally long synchronising words to be priced before running an inverse.

**Arbitrary sections.** If S is any union of k maximal row intervals, one must also charge gaps where the two translated rows first disagree on membership in S. There are h such adjacent gaps in the entire row line, h ≤ 2k. Injectivity up to the first terminating event gives t ≤ r+k−1+h. One contiguous non-cylinder section already defeats t≤r. The companion reverse-constructor study gives a tight r+2 example for one arbitrary interval. [Reverse-gap proof and sharp witness](../f2-dual/)

**Exact check and consequence for memory.** Exhaustive direct return-word enumeration on all binary columns through length nine checked 348,502 arbitrary sections, 17,392 nonempty word sections of length one to four and 36,604 pairs of equal-length word sections. These counts include periodic and disconnected permutations. The test verifies the actual label sequences and injectivity of the charged gaps for the first two classes and counts the exact output runs for every two-marker union. [Counts and minimal witnesses](exhaustive.json)

If m=|S|, dense token links can pack a successor into ceil(log₂ m) bits and a zero-based token ID into the rest of a 32-bit word. The number of distinct word labels is bounded by t. The native run front already exposes the number of capped records, an upper bound on r available without another scan. The [real packing audit](packing.txt) evaluates this certificate before token discovery and also records an a posteriori bound with the true roots and words. This certificate says nothing about the cost of finding each word. The twelve-byte FM lookup records and spelling work can still dominate the four-byte final table.
