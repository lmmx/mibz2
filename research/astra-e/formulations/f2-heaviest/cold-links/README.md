# Stop the first quote trie before discovering singleton terminals

At a first-level quote FM interval of width one, keep the original row x and the already consumed nonquote suffix in backward order. Replace the remaining subtree by a unique cold label. The selector order up to this point is unchanged. By stable inverse merge the root assigns this label to its exact section destination rank. An ordinary discovered terminal knows the first-column base of its word, so all of its sorted destination occurrences determine their source ranks. This constructs the pool of hot return links before exploring *any* cold tail. An alternative dense walk was used only as an independent check. A singleton word that first separates at a terminal of a wider interval is already known and remains hot.

A deferred destination consumes its saved suffix, then follows original LF from x through the first L quote, including that last lookup. Its image is the exact predecessor section rank and its emitted bytes are available in backward order. For an eager hot return from a to b the backward arc owns the half-open raw word from a up to b. Its spelling starts with quote, while the existing F2b dictionary owns the ending quote. Rotating that one quote converts the two conventions. Every word, projected row and source rank independently matched the exported first-level token dictionary/BWT on the ten real inputs.

This differs from [mixed output ownership](../../f2d/mixed/) at `d4bec98`, which discovers the second-level terminal words first, then decides between a compact dictionary and previously written output. Here the first-level source permutation itself is incomplete before the marked tour. One representation stores hot rank translations on the T−C known root runs and one cutoff recipe per cold destination. An implementation using one full slot per first-token row has a different storage price.

## Known source set preserves a second induction

Let f map each first destination rank to its predecessor source rank. Hot f entries are injective. Their complement E in the set of all source slots is therefore known even when each cold edge's own f value is unknown. For a hot delimiter token d let D be its first-column bucket. Set B=D∪E. The membership set is known, E and D are disjoint, and |B|=|D|+C. Every missing edge lands in E. Consequently a backward return to B traverses only known hot links up to a terminal of one of two kinds. A hot d lands in a known D row. A cold label is guaranteed to land in E, and its cutoff is known. Only its final landing rank and raw bytes need to be resolved later. Each cold edge is the final edge of exactly one B-return because its first-level cycle contains its E endpoint. There is no need to include the cold destination ranks in B.

This also admits an ordered FM constructor. Start one root per contiguous component of B. Each hot token other than d maps the selected occurrences to a known contiguous first-token interval. Each d group terminates with a known source. Each cold singleton terminates immediately with its own known cutoff id, before a rank lookup that would need its missing first-column base. The oracle implemented the interval partition and stable inverse merge and compared every resulting root macro with a separately constructed backward walk from its B rank. Colored proper suffix counts predicted every corresponding second-rank query. [Partial construction](barriers.py) · [Independent eager-stop construction](truncated.py)

The marked decoder rewinds to a reachable section rank and records its byte displacement. It walks backwards until its own section anchor recurs, reverses that full lap, rotates to the original primary and repeats or clips to n. This handles marked periods that do not divide n; blindly reversing n steps from the initial mark does not. A quote-free marked cycle falls back. A cycle meeting the first section but missing B is already entirely hot, so that cycle can be completed at the first level. The current oracle pays the reversal/rotation copies. A production writer would have to charge them or prove a different addressing scheme. The exhaustive check covers 3,279 ternary columns, 15,274 covered marks and 6,050 quote-free refusals, including 9,738 nondividing-period cases and 166 hot marked cycles missing B. ## Measured geometry

Across the nine systematic admitted blocks, 22,168 missing edges remove 598,425 of 751,521 first-level rank queries from discovery. Every one is visited on these full marked cycles, so all 598,425 original lookups reappear when cold tails are resolved on the tour. The avoided eager raw dictionary spelling is 712,934 of 890,273 bytes; the avoided private suffix-trie edge payload is 576,257 bytes. Cold tail lookup counts have median 18, 95th percentile 45 and maximum 273. Removing the missing edges opens one independent hot path per missing source. Median and 95th-percentile hot gap lengths are 21 and 168 links, with only two empty gaps; none of the nine inputs has a remaining all-hot cycle. A full first inverse requiring one arbitrary-rank step per emitted first token would still visit 1,221,659 token occurrences.

Ordinary second induction has 220,497 delimiter rows. The partial repair has 242,665 retained rows and 2,375 contiguous components summed across blocks. Its hot interval construction uses **22,773** second-level queries versus **54,511** for standard second induction. The recurrence visits 84,379 interval/run intersections including unary levels. There are 12,024 complete colored macro types storing 528,967 raw bytes, plus 22,168 dangling macro types with 209,116 bytes of already known hot prefix; the dangling cold suffixes/cutoff recipes and deferred bytes remain additional. A dense reference implementation of this repair follows one first-token link per row; a sparse constructor must realize the interval schedule and pay root sorting, selectors, rank-directory setup and output. [Full per-block counts](census.csv) · [Exact distributions](histograms.csv) · [Matched totals](summary.txt)

Frozen removes 55,164 of 70,560 first queries and keeps 15,396. Its 2,118 missing source slots extend B from 24,165 to 26,283 rows. Complete output agrees with Segmented in both the one-level incomplete-link algorithm and the repaired second construction. Eight independently resolved cold tails could in principle be active after the first stage; the optimal-work lower bound and a longest-first schedule both use 6,896 waves on frozen, or 74,806 summed over nine blocks. This schedule is an oracle on actual tail lengths. The directly marked variant instead places the original lookups on one serial orbit. The partial second construction survives the structural gate; a wall-time benefit remains open. A decisive native test would compare the same partial constructor with cold tails resolved on first marked use and with eight independent cold tails batched before publication of final output, retaining any extra byte storage and copies in the measurement.
