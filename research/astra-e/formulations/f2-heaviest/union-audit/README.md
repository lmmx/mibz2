# Return induction on a union of complete parent types

Let Ψ be the stable forward map of an arbitrary byte last column L and S=I(P) a nonempty word cylinder. Write its complete forward first returns as X. Each source type is the contiguous interval I(XP) inside S, and its source order is the parent token alphabet order. The source of an incoming X is found by stable LF in the parent token last column E. Let r count the maximal equal runs in E. Select any nonempty set A of available parent types, take their source intervals' union U, and write h for the number of maximal connected components of U in S rank order. Adjacent selected types can belong to one component. Let Y be a full byte spelling between consecutive visits to U. Let T and C count runs in the incoming Y column, respectively with plain Y and with the pair (Y, destination component). The following bounds are sharp.

- **T ≤ C ≤ r+h−1.** Coloring adds at most h−1 runs. Furthermore C=h+D, where D counts internal adjacent U-rank gaps at which Y changes.
- The source positions of one Y occupy at most h intervals in packed U rank. All h can be necessary for one Y. Each individual (Y, component) occupies one contiguous source interval and preserves destination rank within its equal occurrences.
- The h colored roots and all expanded nonterminal direct byte intervals are disjoint. If q counts all of these expanded intervals and R counts byte runs of L, they intersect at most q+R−1 byte runs in total when counting intersections separately per expanded interval.

## Run accounting and projection

Induce first on the token column E. U is exactly the union of the parent *first*-column alphabet ranges for selected letters. Within one component take adjacent destination ranks. While their two incoming E letters agree, parent LF translates them to another adjacent pair, and the common letter decides whether both are now in U. A return-label difference therefore requires reaching a parent E-letter seam. Charge the starting gap to its first such seam. Until this event every followed adjacent gap has a unique predecessor under the inverse permutation. Two starting gaps cannot charge the same seam. If their path lengths differ, the longer path already reached the other starting pair in U before the event. If equal, reversing to the starts gives the same pair. There are at most r−1 such charges. Every intercomponent adjacency changes color, regardless of whether the spelling already changed. This yields C=h+D≤h+r−1 directly. Counting the color boundaries a second time would give a weaker upper bound.

A projected parent-token sequence determines a byte spelling Y. Conversely YP determines all positions between 0 and |Y| inclusive at which P starts. These are precisely the parent visits in the macro return. Cutting Y at those positions recovers each entire parent type. This argument uses occurrences of P, including overlapping ones and a final occurrence crossing the end of Y. Equality of projected spellings preserves the seam proof. The proof uses bijectivity on every LF cycle and requires no primitive string or unique primary.

## Direct links and collation

For destination component J, start a backward search at its full byte interval. For each prepended byte restrict to matching L entries and apply stable LF. These images are contiguous and preserve order. After spelling a nonempty u, all rows in the resulting interval share uP. If the prefix does not start with P, the interval is outside U. If it starts with P, the next P occurs by position |u|, where the destination begins with P. The location of that first positive occurrence is determined by uP, so the entire interval starts with one complete parent return type and enters U together or remains outside together. Stop on the first positive hit of U. This proves that the sources with label (Y,J) form one interval and gives its actual beginning. For each destination row with that label, its predecessor U rank is the beginning plus the number of earlier destinations with the same label. Inverse permutation gives the packed forward links. Retain Y for physical spelling.

This also gives an independent exact collation rule if the parent alphabet is already available. Express Y as the parent-token sequence w, in source alphabet order, and append any representative parent letter from destination component J before lexicographic comparison. For equal w, the representatives order the disjoint J. When one w properly prefixes another, the longer sequence's next token is unselected, whereas the next letter of the shorter sequence belongs to J. Every letter in a contiguous component has the same comparison to this unselected letter. For differing symbols earlier, the ordinary parent-token order suffices. Thus the resulting finite keys sort exactly as the true source intervals. Sorting the bare bytes of Y or the tuple (Y,J) in ordinary byte order can misorder buckets. On byte L=101, P=1 and U=S, native source order is 10 before 1, since the continuation after the shorter word starts with 1.

Every row of a nonterminal interval is outside U and has a unique first future visit to U. Its distance fixes the depth, its byte prefix the word, and its destination the root component. Distinct nonterminal node intervals are therefore disjoint, including across depths. The h root intervals are disjoint from those nodes. A maximal byte-run seam interior to an expanded interval can split that interval only, giving the q+R−1 overlay bound. The number of nodes, long unary searches, dictionary copying, branch ordering and merge work still require construction and measurement. Missing components on a marked orbit require the usual fallback. A mark that does reach U rewinds by LF to the preceding selected row, skips the intervening byte count in the first outgoing word and expands exactly n bytes.

## Sharp witnesses over a fixed ternary byte alphabet

Start with parent token last column E=1100220 and select {0,2}. In destination order, the incoming macro token words are 01, 21, 0, 2, 0. There are four parent runs, two components and five plain and colored runs. Concatenate m copies, relabeling the ith copy's three letters by the consecutive disjoint alphabet {3i,3i+1,3i+2}. Stable token LF acts within each copy. Between copies the largest and smallest selected letters touch, so h=m+1. Adjacent macro labels from different copies differ. Thus r=4m and T=C=5m=r+h−1 for every m≥1. Using the same concatenation with base E=1020 instead yields C−T=h−1 for every m≥1.

For maximum fragmentation let E consist of the ascending letters 0,…,2h−2 followed by 2h−2 zeros and select the even letters. Each parent first-letter bucket contains exactly one incoming zero. Among the outgoing-zero source ranks, the next letter ranges once through 0,…,2h−2 in order. Hence the one-token macro Y=0 is outgoing on alternating ranks 0,2,…,2h−2 of the fully selected first-letter-0 bucket. Exactly h source pieces are necessary.

To realize all examples in original bytes for arbitrarily large parent alphabets, code type j by Xj=0·2^j·1 with delimiter P=0, using j repetitions of byte 2. The byte L begins with |E| copies of 1. Append one group per d=0,…,max(E), reading the entries j≥d of E in their original order and writing 0 for j=d, 2 for j>d. The byte first column orders marker rows first, then the suffixes 1P, 21P, 221P and so on, each group internally sorted by the following marker's rank. A marker LF step leads to group zero at its own rank. Within group d the continuation predecessors 2 go stably into group d+1, while the terminal predecessors 0 go stably into the marker rows with rank start for parent type d. Returning to P therefore reproduces E and its stable LF exactly, including multiple cycles. These byte examples have unequal word lengths.
