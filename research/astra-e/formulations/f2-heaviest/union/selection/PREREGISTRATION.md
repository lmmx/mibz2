# Fixed quote-marker selection screen

Freeze the eight most frequent first-return token byte strings in the development block (stream 1), breaking frequency ties by increasing source bucket rank. Enumerate all eight singleton and all 28 distinct unordered pairs. The reference is token `3a22`, selecting the quote-colon-quote cylinder. These token strings are bytes from the quote-excluded prefix through the next quote; a token b selects the quote cylinder beginning with quote followed by b. Identify the same byte strings independently in other blocks. On each block coalesce adjacent selected first-column token buckets to get the union's actual components. An absent token is an empty bucket. If the entire union is absent, that candidate fails on the block.

Do not use returned-label workload to choose the family. Test geometry identity first, with each block's native top-k winners k=1,4,8. Then evaluate all 36 *fixed* choices. The eight admitted systematic streams other than stream 1 are the held-out decision set. The density-refused stream 41 is an additional control. Development and control do not influence the result.

A strict screen winner must use at most 95% of reference discovery queries Q and at most 95% of residual rows, with no increase in distinct destination-colored raw spelling bytes, **on every held-out admitted stream**. Compute the same tests on pooled counts as a separately reported weaker screen. Also report a zero-margin pointwise comparison to distinguish real tradeoffs from the margin. A gain on the frozen block, only in frequency, or a non-Pareto pooled gain does not advance a worker. Record all raw counts, include the reference among all candidates, and perform no adaptive marker substitutions or score rounds in this screen.
