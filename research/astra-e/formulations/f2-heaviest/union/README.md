# Direct return to several selected parent words of unequal lengths

Take a parent marker P with rank section S=I(P). Each first-return type X from S occupies one first-token bucket I(XP). Select k of these buckets, including words of different byte lengths, and let U be their union, with h maximal contiguous components in original rank order. The top-k heap selects them directly from the original byte runs. Once the kth most frequent word has frequency f, at most floor(n/f) nonterminal intervals can be popped. When fewer than k types exist the full search returns them all.

**Run count.** View the rows of S as an ordered token BWT with rₚ runs. Between any two adjacent U rows within the same component, two equal predecessor tokens map them by the same translation to adjacent parent ranks. Membership in U after this step is determined by that common token, even if the rows originally began with different selected tokens. Continue to their first hit of U or the first unequal predecessor tokens. A change of macro return requires such a mismatch. Distinct starting gaps inside the components cannot charge the same one of rₚ−1 parent seams, by uniqueness of the reverse path to its previous U visit. There are h−1 gaps between U components. Thus even after tagging each incoming macro return by its **destination** component, there are at most rₚ+h−1 runs. This works for the raw byte labels too. A sequence of complete parent returns spelling Y can be uniquely parsed by finding P occurrences in YP, including overlaps and returns shorter than P. The parent bound uses rₚ rather than the often much larger number of original byte runs.

**Ordering and exact reconstruction.** Equal untagged spellings can occupy disconnected source buckets. For a word Y and destination component C, repeatedly prepending fixed bytes to the rank interval C gives one contiguous FM interval of sources. Every nonempty partial spelling u applied to C fixes uP. If it begins with P, its next visit to P is at most |u| away, since the destination starts with P. Consequently uP already determines the next complete parent return and whether the entire partial interval hits U. This proves uniform termination even for unequal and overlapping selected marker words. The tagged pair (Y,C) has a contiguous source bucket. The tag often needs no extra stored byte because destination components are contiguous in rank order.

The included constructor follows LF from the first unprocessed destination row of each component. It tracks the minimum remaining width inside an original BWT run along that backward path. Uniform membership lets that whole width move together until its terminal U hit. When the width expires, either the component ends or the next backward spelling changes. It stores the source base, destination base, width, and recovered word. Sorting by source gives exact forward return arrows as affine translations, with no intermediate token BWT and no per-row final link table. From the actual primary it rewinds to its first U hit and retains the byte offset. Expanding precisely n bytes handles periodic, nondividing and arbitrary multi-cycle cases; a disjoint marked cycle is reported for fallback. Representative paths have distinct destination rows and are disjoint up to their first U hits. Hence the total number of LF probes to spell these bands is at most the total size of the source cycles meeting U. Run location, membership tests, sorting, retained word bytes, and one band lookup per emitted return remain charged. The native follow-up uses a different stable-merge schedule for the same tagged semantics.
