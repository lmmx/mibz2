# When a section return can feed the token BWT

For a stable bzip2 column let F[x] be the byte emitted before moving from rank x to Ψ(x). Fix a nonempty set U of rows. From x in U let D(x) be the first positive return to U, and W(x) the nonempty raw word emitted on the way. These definitions act on each cycle, including tied periodic continuations. The destination-ordered column attaches W(x) to D(x).

**Exact certificate.** One token per distinct word, reconstructed from this column by stable matching, recovers D precisely when each word's sources form one contiguous bucket in the sorted ranks of U and D increases within that bucket. Necessity follows from the contiguous first-column bucket and stable occurrence numbering in any such matching. For sufficiency, at the jth destination occurrence of a word its source must be the jth source in that bucket. The bucket base is its smallest source rank in U. Token identifiers can be assigned in any order if these bases accompany them.

**Every single rank interval qualifies, including a noncylinder.** Write U = [a,b). Take x < z with W(x) = W(z) of length k. For every intermediate step j through k, stable Ψ on a common next byte strictly preserves order. The rank separation of the endpoint pair can only grow with j, since a strictly increasing map of integers cannot decrease distances. The final endpoints D(x), D(z) both lie in U, so every intermediate pair has separation at most b−a−1. At each internal j the two endpoints lie outside U and are too close to straddle U. Any row t between x and z has the same first k bytes and its successive ranks lie between the corresponding endpoint pairs. This follows inductively from the contiguous F-byte buckets and stable Ψ. Hence t avoids U at each internal step and lands in U at step k. It shares W and its destination lies in increasing order. The argument uses no marker spelling.

For the special cylinder U = I(P), the class of a present word W is exactly I(WP). The prefix WP determines the initial P, the terminal P at offset |W|, and absence of a complete P at each internal offset. This also applies to overlapping occurrences of P. The representation at the writer boundary consists of actual source bucket bases, destination token runs and one byte reference per word. In the earlier endpoint construction the retained primary may split one return and the 5,009 frozen bands are in LF(U) entrance order; they require a further ordering/label step before use as this token column. That study is pinned at 368710e. [Endpoint construction](../../../../../../../f2-endpoint/README.md)

## Limits of the interval theorem

- **Dictionary byte order can differ from base order.** For L = 1001, F = 0011, Ψ = [1,2,0,3], and the noncylinder U = [1,4), the source-ordered words are 0, 10, 1. Sorting raw bytes puts 1 before 10. Even the one-byte cylinder I(1) on L = 101 orders 10 before 1. For a fixed cylinder the longer terminating keys WP distinguish the classes; sorting the raw W alone loses that terminating context.
- **Backward partial membership can be mixed.** For L = 100, U = [1,3), both destinations 1 and 2 extend backwards with byte 0. Their respective predecessor ranks 0 and 1 lie on opposite sides of the section test. The completed classes have exact buckets despite this mixed intermediate extension.
- **Arbitrary unions can split equal words.** For L = 01000 and U = {0,1,3,4}, the source-ordered words are 0, 00, 0, 1. Even a single common leading byte across U does not prevent splits, as the six-row witness in the receipt shows.
- **Destination tagging has a sufficient diameter condition.** Fix a class (W,C), where C is the destination's component of U. If its maximal minus minimal destination rank is at most the width of the narrowest component of U, internal endpoints cannot bracket any complete component. The interval proof then applies to all intervening *section sources* and every destination lies in C. This certifies all destination-colored classes of any union whose component widths differ by at most one. For unequal widths in general, L = 111000 and U = {0,1,2,4} gives equal W = 01 from sources 0 and 2 to component [0,3), with a different word at source 1. The earlier union theorem uses additional marker structure to certify destination-colored buckets of unequal width. It is pinned at 34310a6. [Selected return cylinders](../../../../../../union/README.md)
- **Without stable original ranks, the order condition matters separately.** An arbitrary labeled permutation with F = 00, Ψ = [1,0] and U = {0,1} has a single contiguous word class, but stable token matching gives the identity. Checking the marked bytes alone can miss a broken permutation in this case.

There is an exact minimum refinement when word classes may split. Scan sorted sources. Start a fresh token at each change of spelling or whenever the destination fails to increase relative to the preceding source. Each resulting run certifies one stable bucket; its byte spelling can be shared with other runs. Every stable contiguous-bucket labeling that keeps distinct words separate must introduce each of these cuts. This supplies the minimum possible alphabet under that contract. Stable original columns never need the destination-decrease cut between equal spellings. W may be compared via the canonical seam triple when the schedule assigns all equal words the same triple.

## Mark transfer and the second level

Raw W at a section state emits the original bytes from that state up to its next section visit. Walk backwards from p to the nearest section state including p itself, carrying the byte distance d. The first raw emission skips d bytes. If the cycle misses U, follow the original permutation and emit n bytes. For a uniform-leading-byte section, the conjugate W[1:] + W[:1] instead spells the block starting one byte after the section state: the first byte of the *next* state equals the byte moved to the end. Use the strictly preceding section state and skip d−1. It suffices for consecutive section states to have equal leading bytes around the marked cycle. In L = 10, U = {0}, p = 0, using the inclusive state with rotated words yields 10 where the correct bytes are 01. With U = {0,1} on the same column, the strict rotated method also produces 10 because the two leading bytes differ.

On the token column the dense audit chooses the most frequent first token with ties broken by smallest source base. A second word anchored at that token emits the sequence *after* it through the next heavy token inclusive. Rewind to the strictly preceding heavy token, adding the byte lengths of skipped nonheavy tokens to the existing byte offset. A homogeneous token column and a marked token orbit missing the globally heaviest token both admit exact first-level expansion. The latter arises already in L = 01, U = {0,1}, p = 1. All emission paths clip to exactly n original bytes.

The independent Python experiment enumerates all binary stable columns through seven rows, every nonempty section subset and every mark whose source buckets pass the first-level certificate. It checks 5,630 single rank intervals, 8,704 cylinder-word identities, 58,752 diameter-certified colored classes, and 107,560 marked paths reaching U. Among the latter, 74,812 used the dense second-level walk, 24,292 required the disjoint-heavy fallback, 8,456 had a homogeneous first column and 63,186 had a cycle length that did not divide n. It separately checked 27,526 original-cycle misses and both rotation conventions on all 27,144 uniform-leading certified marks that reached U. On all 125,162 section instances of arbitrary permutations with binary F labels through five rows, the refined labels recovered the exact original section permutation, including 15,948 cases where the plain word buckets were contiguous but unstable. The script operates on ranks and complete words for validation and makes no throughput claim.
