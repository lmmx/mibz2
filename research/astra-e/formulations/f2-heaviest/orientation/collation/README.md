# Ordering the return alphabet on any contiguous rank interval

Let U = [a,b) be a nonempty interval of rotation ranks in a finite stable cyclic BWT. Let W denote a word emitted from a source in U up to its next positive return to U under Ψ. Different occurrences of W have contiguous source ranks and reach their destination ranks in increasing order. The recent [source-bucket proof](../seams/async/native/token-writer/audit/) establishes this for arbitrary intervals, including those that cut across rotation-prefix cylinders. This raises a distinct question: if a constructor knows incoming word names but lacks the source bases, can it recover their exact token alphabet order?

**Common-tail collation theorem.** Choose any single rank q in U. Write T for its infinite forward byte itinerary. Order the distinct return words by the ordinary infinite lexical keys W·T. These keys are distinct and their order is exactly the source-bucket order for U. Every q in U gives the same order, including on stable cyclic columns with multiple LF cycles or equal infinite itineraries.

To prove it, first take two words that differ before either ends. Their first differing byte determines the source order. Otherwise let the shorter word be W and the longer word Wv with v nonempty. After their common W steps the first source is at a rank y in U and the other at y′ outside U. Their relative order is the order of y and y′ because Ψ along a common finite prefix is strictly increasing. The rank q is on the same side of y′ as y is. If T differs from v in its first |v| symbols, that first difference decides the comparison of T and vT in the required direction.

Now suppose q also begins with v. Moving along a common finite byte prefix preserves rank order and cannot shrink the rank gap: all intermediate starting ranks have the same prefix, and the iterated map takes strictly increasing integer values. Following v sends y′ to a rank z in U. If y′<a, then Ψ^|v|(q)−z ≥ q−y′, so Ψ^|v|(q)>q. If y′≥b then Ψ^|v|(q)<q. These strict rank inequalities give strict infinite-byte inequalities too. If the shifted itinerary equalled T, the finite class of ranks with that itinerary would be mapped strictly increasingly into itself by Ψ^|v|, hence identically. That contradicts the strict rank movement. Comparing the shifted tail to T therefore orders W·T and Wv·T correctly.

**Finite computation.** Store the first L bytes and the ranks reached at those offsets from q, for L the maximum dictionary word length. Compare ordinary nonprefix pairs directly. For a prefix pair, compare v against the first |v| tail bytes. If equal, compare the precomputed shifted rank with q. That final rank comparison handles exact periodic ties without infinite strings, sentinel assumptions or reconstruction of the entire marked block. The implementation pays up to L original forward steps and the cost of the finite dictionary sort. This is an algorithm for ordering an already recovered return dictionary. A constructor that already retained the source bases can read the order from them directly.

On 55,796 small contiguous sections, 177,210 independent choices of q gave the correct order. Rebuilding the induced first-return permutation by stable matching every incoming word against that order yielded 420,038 exact marked inverses, including 105,024 marks on disjoint cycles handled by the original navigation. Ordinary finite word lexicography failed on 14,588 sections. The shift comparison was exercised 22,042 times. On all ten frozen Wikidata tapes the code also rebuilt the first-return permutation for four sections per block: quote, the most frequent quote return and two fixed contiguous windows.
