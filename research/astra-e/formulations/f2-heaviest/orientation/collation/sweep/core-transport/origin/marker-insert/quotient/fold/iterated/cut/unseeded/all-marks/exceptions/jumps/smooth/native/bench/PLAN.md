# Price the prepared smooth jump terminal at three fixed context depths

A physical state with a single predecessor can emit an entire spelling along a deterministic chain and advance by translation. A branching state must locate the source row's branch and recover its true physical destination. Test whether this can compete with the entire scalar inverse even when the exact index is already supplied.

Use context depths 4, 8 and 16 in the three candidate slots of the byte-identical capped Rust donor. The three remaining slots are scalar d0a42980e896211906234c7679b38760ae44a46e, LazyCells and OpenGated. Use the same ten registered real Wikidata blocks. Cache each prepared index by the block's unique true row count, mark and cap count in a private per-arm state. Each measured call emits all original marked bytes from that index, including any required periodic-phase correction and the resize of a reusable output buffer. The complete Rust controls receive the original caps. The supplied index is a deliberately favorable comparison for smooth emission.

Every arm must reproduce the authenticated original marked inverse. At each depth collect one untimed preflight then 24 six-position-balanced rounds in the frozen donor, pinned to one local CPU. Reconcile every raw and capped output hash. The native finite/adversarial gate and exact ten-block gate must pass before the paid panel. Retain all raw Rust thread timings and stamps. For each of the 24 rounds sum all ten times before taking paired log ratios. Compute two-sided 95% t intervals on four consecutive six-round mean log ratios. Record per-block ratios, index and output capacities. Obtain fresh one-block process VmHWM at every depth and for each control, three processes per block and arm, including the cold preparation of the supplied index. Read peak before opening the oracle output.

If any prepared depth's upper endpoint is below one against scalar, investigate the cost of building that geometry and its working set. If its result overlaps one, treat it as unresolved and extend or independently replicate before proposing a worker. A prepared loss at every depth closes the tested terminal implementation even with free construction. A good prepared result would establish local terminal headroom only. No discovery, CRC, scanner or target performance fees are inferred from that conditional experiment.
