Use the ten systematic real source blocks already fixed in the powers experiment. Each arm receives the byte-identical capped record stream, true row count and primary rank produced by the frozen Rust frontend. Time the C++ maximal-run coalescer, dense-byte-ID assignment, complete marked grammar construction and all literal output for both the exact and gap-coarsened graph-free choosers. Include a C++ dense reference with the same coalescer. Time the frozen Rust scalar-cap, OpenGated and shipped LazyCells run entry points on the same inputs. Every call must match the LazyCells output and each block must match the independently checked raw inverse in the earlier original-byte receipt.

Use one untimed warm cycle then 24 paired six-arm rounds on a single pinned CPU, rotating both block and arm order and periodically reversing arm order. Use thread CPU time. Report the ratio of each round's equal-block summed times, geometric mean with two-sided 95% Student log-pair interval (23 df), as well as per-block results. The stage begins after the common input frontend and ends before the common RLE1/CRC stage. Existing Rust scratch persists across blocks. The grammar implementation rebuilds its temporary working arrays on each call and retains its previous output until replacement. Use this only for the distance to actual kernels on the local host. There is no official scorer or target timing in this round.
