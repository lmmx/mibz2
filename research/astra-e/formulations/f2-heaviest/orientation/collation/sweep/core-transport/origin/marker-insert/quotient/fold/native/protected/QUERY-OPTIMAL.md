# Maximizing saved dependent search queries over the eligible fold classes

Treat the old d-return search as a known disjoint family of suffix-state intervals. For a nonempty state I, let E(I) be the set of distinct incoming label IDs in it. I is eliminated precisely when all of E(I) are selected. An ID outside the protected eligible pool renders I ineligible for this reward. Otherwise I belongs to a single first-source bucket j, because the suffix has a definite initial symbol j. Every k in E(I) occurs in the incoming tape at one of these j source coordinates. Eligibility forces g(k)=j globally. Thus every nontrivial incentive is a positive conjunction over children of the same parent j in the functional eligibility graph. Duplicate supports can be counted together. Distinct support incidence is bounded by the number of original d-reachable rows, since the old intervals partition those rows.

Let T_i(0) and T_i(1) be the best downstream reward in the tree rooted at i when i is skipped or taken. If j is taken its children all skip and its own sibling-group reward is zero. If j skips, start with the sum of T_i(0) over children, and give child vertex i unary score T_i(1)−T_i(0) for selecting it. Add one auxiliary vertex of positive score w_E per support set E with multiplicity w_E, and a directed implication from that auxiliary vertex to each i in E. The maximum-weight *closed* subset has exactly the desired value. A feasible family earns the positive reward precisely when all required children are present. Conversely a closed subset induces a feasible family and can include every earned auxiliary reward. The standard source/sink min-cut computes the optimum: source arcs encode positive unary profits, sink arcs encode negative ones, and each implication has capacity greater than the sum of positive vertex profits. Isolated ineligible target j receiving eligible children is a fixed-skip tree root. Recover choices by backtracking each conditional cut.

For a parent on a directed cycle, force its own binary choice and the choice of its cycle predecessor, leaving the attached tree children's subproblems unchanged. Infeasible adjacent takes have value minus infinity. A reward requiring an off predecessor is unavailable; when the predecessor is on remove that requirement from its remaining sibling support. Supports reduced to the empty set contribute a constant. The previous closure now computes a local table with at most four entries, including the tree descendants' rewards (each exactly once). Condition the first cycle vertex on its two choices, solve the binary path recurrence around the cycle, and enforce the closing pair. Summing component optima maximizes the exact second-discovery query saving. The proof uses no source frequency proxy and assumes the cost criterion counts each actual stock discovery query once. Selection setup, solving closure, republishing the chosen weighted BWT and final reconstruction still have explicit execution cost.

A faster negative bound may suffice on a given tape. Count every old interval supported wholly on eligible IDs, disregarding their incompatibilities. If a tested feasible set eliminates the same number, its achieved query saving is optimal. More generally the difference bounds the number of additional queries that any alternate simultaneous protected choice could remove.
