# Exact complementary index size for any deleted set of source buckets

For each original source bucket p, count rₚ maximal label/LF-translation records inside Bₚ. Store the label and unnormalized LF of its first and last row. Two consecutive **retained** buckets p,q can share their boundary record exactly when the two facing labels agree and LF(first q)=LF(last p)+1. The LF rank for each label changes by one fixed base translation in the complemented index; this equality is independent of which other buckets were removed.

Each old row's absolute LF value is unique. Thus for a given p there is at most one later bucket q whose first row has the required label and LF value. Look it up by the pair (last label, last LF+1) in the table of bucket starts. For any deletion set, list remaining buckets in their old order. The exact complementary run index size, excluding its sentinel, is the sum of rₚ over retained buckets minus one for each adjacent retained pair that is one of these unique matches. This counts a bridge over any number of deleted buckets and correctly preserves a boundary when removed occurrences of the same label made its LF discontinuous. The table requires O(K) candidate bridges for all source subsets. The initial per-bucket counts and endpoints take O(R+K) from an ordered run/bucket sweep.

The formula applies when the only row-coordinate change in each target class is a constant translation, as in the certified subtree construction. For uncertified arbitrary subsets the formula still describes the complementary lookup table under this chosen translation; the mark and query contract may separately disallow that subset. It gives an exact retained storage count before building any candidate subset's actual index. [Constructor and independent record stream](bridges.py)
