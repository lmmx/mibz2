# Jump over default predecessors while retaining the exact physical source

Let C be a lexicographic interval of rotation ranks with common k-byte forward context c. Write m(c) for its modal preceding byte, ties smallest. A true predecessor LF that emits m(c) enters a known context d, obtained by prepending m(c) to the first k−1 bytes of c. Call a rank good for h if all its next h backward transitions use their modal bytes.

**Interval identity.** For fixed c and h, every good rank emits the same word backwards. The final rotations begin with the reverse of that word followed by c. Conversely every rotation beginning with this concatenation is reached from one good start in C. Its terminal ranks are therefore one contiguous interval Iₕ(c). Stable LF preserves the order of equal preceding bytes in each step, so the good starts map increasingly onto this interval. Periodic ties preserve the same stable order. This statement also follows by composing stable rank maps, independent of rotation terminology.

Let M be the h-good bitmap in old physical rank order, B(c) the start of Iₕ(c), and rank(x) count set bits strictly before x. For good x in C=[s,e), its true destination is **B(c)+rank(x)−rank(s)**. Emit the common word and enter the known target state. For a one-step exception the dense index among exception records is x−rank(x). Each such record holds one physical LF target, poststate and byte. No event clock or physical successor table indexed by every byte is necessary.

**Doubling.** The ordered set bits in M[s:e] name, in order, every physical row of Iₕ(c). The 2h-good bits equal the subsequence of these set bits where the *target* h-good bit is set. Take a source machine word with mask V and q=popcount(V). Read the next q bits from M across Iₕ(c) and deposit them into V, resetting other positions to zero. Mask partial words at context ends. The new target interval begins at B(d)+rank(B(c))−rank(start(d)), where d is the h-step target state. This formula gives a valid insertion boundary for the empty interval as well. Compose the two spelling and state transitions. Each context fragment requires O(1+length/wordsize) fixed-width word operations at one level on a machine with constant-time bit deposit, unaligned word extraction and prefix-rank lookup. Disjoint contexts give O(C+ceil(n/w)) per level, excluding the initial context construction. Spellings can be prepacked for a bounded jump size. Reading and storing an unbounded literal word of length h costs O(h/w) words. The real implementation must charge exactly its selected tables, lookup, first context partition, exception directory and emitted output. The portable finite checker uses integer bit loops.

**Mark and multiple cycles.** Fill n bytes in descending output order starting at the original primary p. The buffer is now the n forward bytes beginning at LFⁿ(p). If the final rank is p, output already starts at the mark. Otherwise obtain the true lap d≤n by using the unit transition index from p until its first return. The final d bytes in the existing buffer are the full forward lap beginning at p. Move that suffix to the front and repeat it to length n. Thus an arbitrary marked column requires neither an ordinal dictionary nor a fallback BWT reconstruction. The optional repair is bounded by n unit steps and n byte moves. This argument uses bzip2's horizon equal to the input row count.

The independent finite model verified all four jump levels on 115,212 source checks across 4,806 models, then all 28,803 marked outputs against stable sort. 11,106 of those marked cases exercised phase repair. It includes arbitrary multi-cycle binary columns through length eight and ternary columns through six, with k=1,2,3. [Exact model](finite.py) · [Counts](small.json)
