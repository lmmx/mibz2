# Native physical-section publication

Physical follower publication at cap eight took 1.986 times named Compact's complete inverse CPU time on ten systematic tapes. First discovery fell to 0.844 times Compact. Second discovery and spelling grew to 1.435 times Compact. All 684 physical objects across the 228 admitted blocks passed independent marked correctness checks. Physical h8 also used more single-worker peak memory, reaching 12,488 KiB versus 8,492 KiB for named Compact. These results close this paid formulation as a local performance candidate. ## What the writer consumes

The packed eight-lane core constructor discovers one untyped core C and its source base in cut-section V, then publishes incoming core runs in the original destination order U. The new constructor sorts the B forward atlas bands by their original source rank. It sweeps the incoming core runs and these bands once. The next physical word consists of the incoming core and the **destination's** forward prefix. Within each core, a prefix change creates a new ordinary ordinal ID starting at that core's current source cursor. Distinct ordinals can spell equal bytes. Each original destination band receives a consecutive range in a shared fragment buffer. Reading those ranges in physical order publishes the final RLE. There are at most R+B−1 intersections for R incoming core runs. The constructor allocates by core, label, band and fragment. The successful second induction consumes the first column directly from its runs. The identity cap-zero atlas can reuse the root and original core word ranges directly. [Native publication](publish.rs) · [Formulation and Python oracle](../physical.py)

The original primary is transferred to its nearest inclusive physical source. A primary in V is already at offset zero. A primary strictly inside a stripped prefix rewinds to its known original U source and adds its forward-prefix distance. The remaining retained LF walk reaches V with the rest of the offset. For a cycle disjoint from V, the byte-cycle fallback starts at the corresponding compressed original primary. The unmodified second writer and packed fallback handle marked intervals whose second delimiter is absent from that cycle. [Physical mark](mark.rs) · [Dense source, partner, spelling and marked-offset verifier](oracle.rs)

Every physical source, positive-return partner, emitted spelling and primary matched an independently stable-sorted original Ψ walk on 228 real admissions at depths zero, four and eight. Every real object entered the second writer and emitted the complete original marked bytes. The arbitrary-column suite passed 233,480 marked configurations, including 62,112 disjoint marked cycles. The specialized atlas/mark tests also cover primary rows strictly inside the prefix. The independent Python producer matched all 30 systematic native objects on mass, number and size of word spellings, winning-label frequency, atlas bands, overlay fragments, discovery states and both RLE lengths. ## Paid paired panel

The native panel compares seven arms on identical original capped runs, counts, marks and preselected heaviest quote-return source intervals. Each arm pays its setup, first discovery, publication, second construction and final output. The shared section-selection cost is outside timing. All arms use the same observer in the unchanged second algorithm. The 35 balanced rotations include all seven arms at every block, for 2,450 checked outputs. ## Why fewer residual links increased work

An untimed build recorded the actual second-stage vector lengths after the successful writer. Each discovery loop issues one rank lookup per unary extension plus the final lookup at its contracted node. The length of the second edge array counts exactly those lookups. On ten tapes the original-publication controls at h0, h4 and h8 all recover the same object and give the same counts.

| All ten blocks | Original object | Physical h4 | Physical h8 |
|---|---:|---:|---:|
| Second residual links | 31,358 | 31,357 | 13,341 |
| Second rank lookups | 107,637 | 107,622 | 166,837 |
| Contracted nodes | 16,165 | 16,172 | 14,088 |
| Second words | 14,843 | 14,842 | 12,766 |
| Compiled second spelling bytes | 5,525,525 | 5,525,525 | 8,741,631 |

Across all 228 admissions, h8 reduces 705,337 second links to 302,049 while increasing rank lookups from 2,360,866 to 3,648,625 and compiled second bytes from 125,949,883 to 197,647,056. [Aggregated counts](geometry-summary.txt)

At h8 the most frequent refined token has fewer occurrences. The resulting longer second returns have 55% more rank lookups and 58% more compiled bytes despite the smaller residual and fewer distinct second words. This is a measured limitation of the second writer's single most-frequent-ID policy for this physical alphabet. The original explicit forward atlas is also an independent cost. A new formulation would have to address both before the observed stage timings support whole-worker evaluation. [Second-stage ten-block counts](second-geometry.csv) · [All admission counts](second-admissions.csv)

Each memory arm used a fresh persistent process across all 228 admissions, checking independent marked-output FNV hashes. Named Compact peaked at 8,492 KiB, physical h0 at 8,760 KiB, h4 at 11,392 KiB and h8 at 12,488 KiB. The corresponding old h8 producer peaked at 13,084 KiB. Peak retained vector capacity including output for physical h8 was 9,898,302 bytes. These stage-process peaks and paired CPU times are specific to the local environment.

## Reproduction

Implementation commits are 02d0bb2 and 0ae7e18. Native paired, RSS and correctness receipts are at 71ce931. Use the Rust 1.99.1 research toolchain, the existing release library and the [original-cap exporter and reference hash instructions](../../native/README.md). The research adapter verifies its source hashes through the packed eight-lane constructor. The instrumented second observer is confined to the scratch build. The same three input and reference hashes apply as in the previous native study.

```sh
d=research/astra-e/formulations/f2-heaviest/orientation/collation/sweep/core-transport/follower/native
out=$(mktemp -d)
bash "$d/build.sh" "$out" "$PWD/target/release/deps"
python "$d/../../../../clipped/native/tapes.py" research/astra-e/dense/target/wikidata "$out/ten.bin"
"$out/check"
"$out/check" check "$out/ten.bin" > "$out/ten.csv"
python "$d/crosscheck.py" "$out/ten.csv"
"$out/check" check /tmp/astra-token-all/admissions.bin > "$out/admissions.csv"
nice -n 8 taskset -c 3 "$out/price" price "$out/ten.bin" 35 > "$out/phase.csv"
bash "$d/memory.sh" "$out" /tmp/astra-token-all/admissions.bin /tmp/astra-clipped-final/expected.csv 2 > "$out/rss.csv"
python "$d/report.py" "$out"
geo=$(mktemp -d)
python "$d/second_geometry.py" "$geo" "$PWD/target/release/deps"
"$geo/geometry" geometry "$out/ten.bin" > "$out/second-geometry.csv"
"$geo/geometry" geometry /tmp/astra-token-all/admissions.bin > "$out/second-admissions.csv"
python "$d/geometry_report.py" "$out/second-geometry.csv" "$out/second-admissions.csv"
```
