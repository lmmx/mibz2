# Inverting marker identification on the first weighted token column

A label k is eligible if the destination of every source with ID k lies in a single other source bucket g(k). The minimum and maximum positions of k in the incoming column decide this exactly. One scan computes them, and the old source bases locate their two owners. Suppose a set D of eligible IDs satisfies D ∩ g(D) = ∅. For each occurrence of k in D, delete its successor vertex. The deleted vertices have distinct incoming labels drawn from D and lie entirely in surviving label classes g(D). No two deletions are consecutive on an orbit. Each source with ID k now emits W_k W_g(k) and goes directly to the original successor's successor. Every surviving source of any other type keeps its old spelling. A target class can itself disappear if every source in it is deleted. Keep the relative order of all surviving vertices and skip empty buckets.

The composition from a k source to its destination is increasing on the entire k bucket. Both old steps are increasing on the used subset of their respective buckets. Deleting vertices preserves destination order. The unchanged vertices of a target form a subsequence of its old bucket and retain stable order. This gives one ordinary weighted token BWT with m−Σ f(k) rows, in a single transformation. Each deleted mark has a unique predecessor k and moves there at offset |W_k| plus its old skip. Every nonempty cycle retains vertices. Repeated spelling across the old byte horizon therefore reconstructs all marked cycles, including a marked primary inside a deleted word or inside a nonprimitive orbit.

For a target j, read its old source bucket as a stream of labels. At each position use its old incoming ID k if k is in D and use j otherwise. Read these streams in occurrence order as follows. Consume the old incoming column L, dropping each k in D. For every remaining occurrence of target j emit its next stream entry. All other labels stay unchanged. A j occurrence always lands at a surviving vertex, since every deleted vertex had incoming label in D. Occurrence rank of j names precisely the source to which the j occurrence belonged. Its stream entry thus identifies the true predecessor of that destination in the contracted graph. This constructs the new RLE by run intersections. It needs no dense token permutation or set of row IDs. The original coincident-marker construction is its inverse on each eligible target class. A free-choice independent deletion can therefore simplify an existing word column without first publishing any markers.

## Largest possible one-pass contraction under this sufficient condition

Each chosen class k deletes f(k) rows. The only incompatibility between eligible IDs is an edge {k,g(k)} when g(k) is also eligible. The directed graph has outdegree at most one. Every weak component is a tree or a cycle with attached trees. A tree dynamic program computes the maximum weight independent set, with weight f(k) and two states at each node. On a cycle condition the first vertex on taking or skipping it and compare the two consistent solutions. This takes O(K) time and storage once eligibility is known for K types. It maximizes removed ordinal rows among these simultaneous whole-class choices. Largest-ever downstream speedup, optimal spelling bytes, and arbitrary row-level contraction are different optimization problems. Finding eligible IDs requires a pass over old R maximal runs and locating the two relevant bases per ID. A linear merge with sorted endpoint events or walking monotonically through source intervals can supply owners as the input is scanned. Constructing the new column and dictionary, choosing the mark, and subsequent induction are all chargeable.

The first falsifier measures the *exact* maximum removed mass, resulting runs, change in spelled dictionary bytes, the actual old and new stock second writer, and independently checked marks. A small structural effect would limit this one-step policy. It would leave open paths, subclasses or multiple contractions.
