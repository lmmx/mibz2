# Delimiter-preserving deterministic fold

Fix a token BWT with positive word weights and a source interval D consisting of all occurrences of its most frequent ID d, with smallest source base breaking ties. Take any compatible deterministic-successor fold set A as in the original one-step theorem. In addition require both d ∉ A and g(k) ≠ d for every k ∈ A. Every old d vertex survives, in unchanged relative order. It emits the same byte word as before. Every other source class can only lose mass. A tied source class earlier than d would contradict the original smallest-base rule. The relabelled stock second root therefore selects precisely the retained D.

At token level, every surviving symbol k expands as (k,g(k)) if k is selected, otherwise as the singleton (k). No two selected edges share an intermediate vertex, and the two-symbol expansions contain no d. On each original strand from one d to its next positive d, deleting the determined intermediate symbols is a deterministic rewrite of the strand alone. No choice depends on the neighboring strands. The deterministic expansion is its left inverse on strings that occur. This provides a bijection between the original and folded d-return token types, even when two byte spellings agree across distinct token strings. The type encountered at a particular d rank is relabelled by this bijection, and its return lands at exactly the same next d rank. Thus the full second weighted dictionary, with each spelling keyed by its first d source rank, and the incoming column of those source bases agree exactly. Replacing a selected two-token pair with the concatenated byte weight preserves every byte along the strand. Compact's trailing orientation rotates by the same complete d word in both representations.

A marked point in a deleted word moves to the preceding surviving word at the original skip plus the predecessor's old byte length. The d boundary before the mark, its d-visit rank, and the subsequent byte offset from it are consequently identical in the two representations. Cycles disjoint from d stay disjoint, so a mark there uses the same fallback decision. An all-d component remains unchanged. Tied byte itineraries do not identify any distinct ordinal row; all arguments use stable input ranks and physical first return to D.

The second discovery builds a return trie over its input token alphabet. Folding can change its rank queries and selector merges while preserving the normalized root and bytes. The local test compares the actual complete stock objects and marked shifts outside timing.
