# Linear construction of the marked grammar by local events

Fix the initial stable token source buckets and each physical vertex's original rank. A vertex keeps its type until deletion. When eligible type k absorbs its single successor type j≠k, each living k vertex x replaces its successor y by the successor of y. Delete y from the ordered living vertices of class j, and append one grammar node for the class k. The k destinations were distinct and sorted; their new destinations remain distinct and sorted. Type membership of all other living vertices remains fixed. Consequently **only k and j can change their eligibility**. Relabeling the contents emitted by k changes no other outgoing edge or destination class. A target completely exhausted by this rule had no incoming arc from another class. If the physical primary y is deleted, move it to x with |W_k| added to its byte skip. The marked singleton variant keeps its physical primary throughout.

For each class keep its first and last living source and frequency. Test eligibility in constant time by comparing the immutable owners of the successors of those two sources. Their agreeement suffices by stability. Initialize a FIFO from eligible types. After each accepted contraction retest or enqueue just its two affected types. Suppress duplicates or retest upon removal. The upper bound on attempts is K plus two per completed class contraction. Unlinking and redirecting one occurrence earns a charge from a distinct physical vertex permanently deleted. Over the full schedule **at most m−1 occurrence edits** are needed, without a global per-round reclassification. Building the initial forward table from the old run column writes m successor entries by ascending source cursors. With constant-time ownership and deletion the total construction costs O(m+K+R), including queue operations and grammar node creation. The rule changes scheduling and the number of grammar nodes. The theorem does not give an absolute performance or peak-memory result.

## Compact ordered deletion

Use one immutable source-boundary mask and a running count per global chunk of 64 consecutive original ranks. The inclusive count of boundaries at x minus one is its owner in original source order. A second 64-bit mask holds the living rows. Link only the nonempty chunks in a doubly linked list. For the next or previous living row, test the eligible bits of the current mask, then take the first or last set bit in the adjacent nonempty chunk. Removal unlinks a chunk only when its last bit clears. When a deleted y was its class endpoint and that class still has other rows, the next or previous global living row belongs to this same original contiguous class. All of these operations take constant time. The same primitives enumerate the surviving k sources in increasing original order.

With u32 successor, 64-bit masks, u32 boundary prefix and u32 chunk links, nominal array payload is **4m + 28 ceil(m/64) bytes**. This is 4.4375 bytes per word vertex away from the last partial chunk. It excludes source metadata, queue, output, initial word dictionary, grammar, spare capacity and process memory. A row-linked version using one mutable successor, owner, previous and next u32 per row costs 16m before per-class data. The linear time bound applies to both. A true paid comparison must also include the simpler one-level direct walk given the same initial word column and a fixed original successor.
