# Exact query-optimal protected choice on fresh original suffix support

The independently checked first screen found a total of 7,716 eliminated stock queries at maximum removed row mass, with at most 7,853 possible even before imposing incompatible classes. The new question is how many queries and how much first-dictionary publication are actually required at the exact optimum. Freeze the lexicographic objective **maximum saved discovery query count, then minimum bytes appended by the existing native spelling publisher**. A selected class costs its old word length plus the length of its deterministic successor. Every remaining tie can be resolved deterministically by the solver. This criterion is distinct from maximum removed rows. An increase in saved query count has an absolute ceiling of 137 over ten predeclared tapes.

Implement a separate sparse input census directly on the old maximal token RLE and its LF starts, emitting one distinct-label support per eligible suffix interval and the spelling-cost table. Track overlap pieces, unique incidences, ineligible states, distinct supports and the actual source/second work to obtain these data. Compare an independent exact maximum-closure solver and the previous mass-driven selection, verify exhaustively on small weighted graphs with odd cycles, and reconstruct using the resulting masks on each real native first root. Compare actual stock find count, normalized second object and mark, as well as number of selected types, removed rows and appended bytes. A cached external policy mask is an oracle for its fresh selection and must be labelled and priced separately. Archive original supports, optimal masks, raw construction times and checked marked output. No full-worker selection can follow from an offline optimum or capped additional query savings.
