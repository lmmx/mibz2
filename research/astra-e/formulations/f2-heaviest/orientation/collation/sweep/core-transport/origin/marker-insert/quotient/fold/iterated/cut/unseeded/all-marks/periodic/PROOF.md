# Periodic lifts, independent cycles and numerical positions

For a nonempty arbitrary byte column L, let F be its stable sort. The permutation Ψ maps the j-th occurrence of a letter in F to its j-th occurrence in L. At original rank x the output is the first n symbols of F[x], F[Ψx], … . No assumption on the number of Ψ cycles is needed.

## Exact test for a single primitive circular tape

Let g be the gcd of maximal L-run widths. Divide each width by g to form a quotient column L′ of length d=n/g. Each symbol occurrence count, each F bucket base and the old width before each run are multiples of g. Within each run, stable matching of successive occurrences therefore proves

    Ψ(gq+i) = g Ψ′(q) + i       (0 ≤ i < g).

All g lanes of any quotient row spell the same infinite output. A quotient first-return walk from the chosen primary bucket is an independent transitivity certificate when it visits d rows. On this admission, label its positions by the walk index modulo d. Every original row gq+i then uses the coordinate of q; positions relative to an arbitrary original mark subtract that mark's quotient coordinate. This gives a grammar-free atlas of d offsets and one periodic tape of d bytes. RLE width division and the test cost one maximal-run pass plus a quotient index and at most d ordered successor steps. In particular a cut certificate can still stop early on its own admission. An unchecked prefix of d bytes may end mid-cycle on a heterogeneous quotient; use its actual first-return length if reconstructing just one mark.

For the converse, associate to each row its infinite periodic forward word. Their order is lexicographic: within one F byte, Ψ is strictly increasing, so the ordered rank comparison can be passed forward until two bytes first differ. Identical infinite words occupy one contiguous interval. A periodic infinite tail has a unique predecessor letter among periodic words (choose a common multiple of both periods); thus Ψ maps an entire equal-word group bijectively and increasingly onto the group for its next rotation. For a primitive necklace of length h, its h distinct rotations have equal group width m. After h advances an increasing bijection of the group to itself fixes every row. The original permutation therefore has exactly m distinct h-cycles for this necklace, with no repeated word traversals within one cycle. Conversely, sorting the periodic rotations of any multiset of primitive necklaces, including all multiplicities, and taking their predecessor letters gives exactly this stable column. This is the usual extended BWT correspondence.

Writing m_C for each distinct necklace multiplicity, every L run is a union of whole equal-word groups: their predecessor letters coincide. Thus gcd_C m_C divides g. The exact g-lane cover implies g divides every m_C, proving equality. In particular a genuine BWT of one primitive word repeated m times has g=m, and its quotient contains one cycle. Conversely quotient transitivity is necessary and sufficient for the one-necklace representation. When g=1 a general heterogeneous column can still contain individually duplicated necklaces.

## What the numerical reverse needs for ordinary cuts and powers

Attach positive weights to current source rows. Removing a destination y following x merges its weight onto x. Numerically the old x maps to the surviving source with offset 0 and y to that same source with offset w(x). For a power, let s begin a maximal run of d current source types a. The new source represents s and carries weight d·w(a). Map Ψ^j(s) to this source with offset j·w(a) for 0≤j<d. These are additive old-to-new coordinates. For a byte-rooted system all started weights are one. A constant-type cycle consists of a fixed row: on the set of constant-type cyclic rows Ψ is an increasing bijection, hence fixes each row. Save each removed fixed row as a side terminal with its current weight and numeric owner. Erasing it without this side record loses valid all-primary queries.

Ordinary contractions and run contractions preserve every represented cycle with its sum of weights. Under an exact geometric cut, removing fixed components as side terminals and continuing with all remaining components ends with one terminal per original cycle. Initialize each terminal t with its own base address and position zero modulo its weight W_t. Reverse the retained survivor/offset records. The cumulative offset is the original forward byte distance since the terminal's represented source. On reaching original rows, scatter F[x] to the appropriate terminal tape and offset. For unit input bytes the original rows of each cycle occupy every offset in its W_t exactly once. This needs terminal identity and an integer position, plus transported weights, and no spelling DAG. Equivalent cyclic tapes may be interned independently by the necklace theorem. A dense verifier below checks this identity for arbitrary stable permutations using ordinary and run contractions, including fixed side terminals. The verifier represents maps explicitly and gives no sparse time bound for constructing or reversing the power descriptors.

## Sharp limits and a compact positive family

Suppose an atlas represents all primary outputs by an offset in one of a dictionary of primitive circular byte tapes. Indefinite output requires exactly one distinct tape per distinct primitive necklace, irrespective of multiplicity. Let P_s(h) = (1/h) sum_{j|h} μ(j) s^(h/j), the count over an alphabet of size s. The maximum number of distinct necklaces for input length n is exactly the largest number whose shortest possible lengths, drawn with multiplicities P_s(h), sum to at most n. Unused length can always be filled by duplicate single-letter cycles. For fixed s≥2 this maximum is Θ(n/log_s n): at most O(s^(D+1)) distinct necklaces have length at most D; choose D=floor(log_s(n)/2) and charge all others at least D+1 bytes. Conversely use all primitive necklaces at one length h, with P_s(h) asymptotic to s^h/h, then fill residual length as necessary. On the exact length n=h·P_s(h), every n-byte output is an integral number of periods; even a dictionary of circular n-byte windows must distinguish their conjugacy classes. This bound concerns the number of circular base tapes, not general substring dictionaries.

The numerical atlas itself can need linear information. At prime length n there are (s^n−s)/n distinct primitive necklaces and therefore that many transitive BWT columns. Normalizing an offset permutation at row zero determines Ψ by adding one modulo n. For a given Ψ and F counts vector, L is forced by L[Ψ(x)]=F[x]; at most binomial(n+s−1,s−1) columns can share that normalized atlas. Thus its worst-case encoding on this family takes at least n log₂ s−O(s log n) bits for fixed alphabet. Storing L supplies an O(n log s)-bit representation if query time is unconstrained. There is no n log n lower bound from the fact that offsets form a permutation.

A sharper representation-specific obstruction already occurs with two original runs. Let L=b^k a^(k+1), a<b, k≥2, n=2k+1. Stable Ψ(r)=r+k mod n is transitive. Every cyclic forward coordinate satisfies O(r)=−2r+c mod n, as −2k≡1 mod n. Since adding one rank never increases O by one modulo n, any cover by intervals on which O(r)=r+c_i mod n needs exactly n pieces. One modular affine formula gives all positions. More generally, if every LF-inverse band has the same Ψ translation a modulo n, put h=gcd(a,n), d=n/h. For d>1 the h cycles are the residues i modulo h, and a position within its cycle is (a/h)^(-1) floor(r/h) mod d, since Ψ advances that coordinate by one. For d=1 all rows are fixed. This arithmetic atlas works even if different lanes spell different necklaces. Recognizing a common modular shift costs a pass over the original ordered bands. With two runs the formula above includes the special case of a repeated primitive tape after gcd division.
