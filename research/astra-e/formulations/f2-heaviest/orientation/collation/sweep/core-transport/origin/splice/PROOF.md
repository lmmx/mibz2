# Sparse deletion from a weighted ordinary token BWT

An ordinary token object on m ordered vertices consists of positive contiguous source buckets, a nonempty byte string per bucket, and a run-length encoded incoming column in destination order. If a source bucket starts at b, the j-th occurrence of its ID in the incoming column at destination y defines F(b+j)=y. The IDs may be arbitrary ordinals and distinct IDs may share their byte range. F is a permutation. Let E be a sorted list of e removed vertices. Retain H=J∖E in physical source order and write h(x)=x−number of deleted vertices below x. A marked J object gives a source r and a byte offset inside its outgoing word. Cycle length, full period and distinct rotations are unrestricted.

## Local change of successor

For each live s whose successor is deleted, follow its maximal chain s → e1 → … → et → d, with live d. These q chains have different starts and different landings. Each hole on a chain belongs to exactly one such chain. Every remaining deleted vertex belongs to an entirely deleted cycle. This follows from the unique predecessor and successor of every vertex. For changed s, assign h(d) as new destination and concatenate the original words at s,e1,…,et. Every other live vertex keeps its original word and has destination h(F(s)). The new permutation is the induced first return to H. Concatenating its words gives the same bytes on that original physical trajectory, including arbitrary truncation and repetition of a short marked cycle.

Mark transport uses the same chains. A live r becomes h(r) with its existing byte offset. A deleted vertex ei in a live chain becomes h(s), with its old offset increased by the combined length of the original words at s,e1,…,e(i−1). A mark on a deleted-only cycle invokes the original J object with its original offset. The H object still exists on the remaining live cycles. Empty H gives the same fallback for every old-J mark. A raw mark on a cycle disjoint even from J requires the preceding byte-level fallback already present in the J constructor.

## Recovering only the required partners

Scan the incoming runs once, with one occurrence cursor per source bucket and a destination cursor. A run of ID a and width w describes the translations from the w consecutive source ranks beginning at the current a cursor into the w consecutive destination ranks beginning at the destination cursor. Maintain a globally ordered pointer into destination holes and independent per-bucket pointers into the sorted source-hole ranges. Intersect both coordinates with their hole pointers. The scan records F(e) and F⁻¹(e) for every hole, at most 2e values. Its construction never allocates an array indexed by the m vertices. The predecessor list identifies the q changed starts, and the forward list suffices to trace each removed chain. Deleted-only cycles need no traversal to emit H. The stored chain owner per hole also answers any marked query.

## Publishing a valid ordinary object

Within each old source bucket, give every changed live source a distinct singleton ID. Each intervening nonempty stretch of the other live sources receives a fresh ordered alias for the *existing* word range. Removing source holes compacts a stretch and introduces no alias boundary by itself. If an old bucket has q_a changed sources, it produces at most q_a singletons and q_a+1 unchanged aliases. Hence the new number of IDs satisfies K_H ≤ K_J+2q. Intervals can be empty, and identical spellings need not be merged across source buckets.

Project the old incoming sequence by first deleting physical destination holes and the q changed landing slots. These deletions cannot increase its run count. The remaining occurrences of each old label are in old source order by the definition of an ordinary BWT. Renaming this monotone subsequence by its new live-source stretches can split at most q_a old runs for label a. Now insert each changed singleton at its own surviving landing. Inserting one symbol adds at most two runs. Thus R_H ≤ R_J+3q. Every unchanged alias preserves stable source occurrence order, and the singleton has a unique source and landing. Stable select on the published column therefore recovers the asserted new permutation. The statement allows any number of removed-only cycles. [Independent sharpness examples and validator](bounds/)

The code intersects each old destination run with source stretch boundaries and ordered destination edits. It skips deleted destinations, substitutes singleton labels at changed landings, and immediately joins consecutive equal output IDs. It preserves unchanged word ranges verbatim. Each new standalone compound is placed contiguously after the original dictionary, satisfying the existing second reader's one-slice ABI.

## Costs

With K original source buckets and R incoming runs, the two sweeps plus source-alias construction take O(K+R+e) visits, apart from sorting and locating the sparse edits. The implementation sorts the q starts and at most e+q destination edits, and uses binary searches of the hole list while linking them. This adds O(e log(e+1)) time. An input with numeric source IDs out of physical order can add O(K log K) to normalize base order. The naturally ordered input takes the linear branch. It uses O(K+R+e) metadata including the output runs. The returned alias starts and ends are counted separately from the temporary vectors. There is no additional token-per-vertex map. Dense oracle arrays in the test harness are outside the algorithm and timed region. When e=0, it returns a borrowed identity view in constant time.

The dictionary extension writes exactly the sum of the original word lengths over the q changed starts and all holes on their chains. A long word may occur at any of these sites. Sparse topology alone cannot bound this byte total by O(e). Because the native ABI uses one contiguous dictionary, growing its inherited Vec can also copy the old dictionary and retain extra capacity. The real check records the initialized original and appended counts, exact-fit and new capacities, and whether the pointer moved. Repeated pricing retains the warmed capacity and explicitly excludes constructing J or discovering the supplied hole list. The native reader may allocate a dense direct fallback when its own second induction declines. This is recorded independently from the splice's sparse work.
