# Contracting all initially deterministic chains on one fixed geometry

Let D be the original eligible classes. Each k in D has all its f(k)>0 successor images in one *different* target class g(k). Here D stays frozen for the entire construction. New eligibility can arise afterward.

On a directed cycle of D, f(k) ≤ f(g(k)) at every step. Hence all frequencies on the cycle agree and all images exhaust the next bucket. Neither eligible trees nor any other incoming classes can attach. Stable source order gives a physical cycle through the i-th vertex of every class for each ordinal i. Retain one bucket from the cycle, spell one full lap there and make each retained row a fixed point. The new incoming for retained rows is just that chosen label. Its choice rotates the seam. A self-only class outside D already has this representation.

All other D classes form an acyclic graph leading to classes outside D. Call a surviving vertex an anchor if its incoming original label lies outside D. Starting at any anchor k, read its source class word and follow deterministic transitions until including the first vertex from a class outside D. The next vertex is another anchor. The class sequence in this segment depends only on k. In particular an anchor outside D spells just its own old word. These segments partition every non-cycle orbit because any orbit avoiding all outside-D vertices would contain a directed D cycle. The ordinary ordinal order on surviving anchors gives one stable weighted token system. To see stability without a new rank assumption, process each original D class once in reverse topological order, closest to its outside-D sink first. At its turn the successor's spelling has already been extended down its chain. Each arriving branch retains its own successors until it absorbs them. This sequence of legal whole-class folds gives precisely the anchor partition. A length-d pure cycle similarly takes d−1 legal contractions.

Consequently the simultaneous removal count is

    sum(f(k) for k in D) − sum(f(any member) for each pure D cycle).

The surviving frequency of each non-cycle k is f(k) minus the sum of f(child) over all original eligible children landing in k. The removal count prices one complete pass over the *initial* eligibility. The confluence result covers later passes with newly deterministic types. [Confluence](PROOF.md)

## Building the destination RLE

For a source class j let A_j list, in original source-row order, the class of the anchor covering that row. In a non-cycle source bucket j, scan the old incoming labels. For an outside-D label, the row itself is an anchor so emit j. For an eligible incoming k, the anchor is inherited from the old predecessor of this row. The next such k row receives the next entry of A_k, by stable occurrence matching. Each k in D delivers its entire stream to its sole target g(k). Compute these streams with children first. To publish the new incoming column, scan original L. Drop all rows whose old incoming label lies in D. At each surviving occurrence of outside-D label j emit its next A_j entry. Its old j predecessor ends the contracted segment and A_j names that segment's surviving source. Retain the original source-bucket order with the new positive frequencies. For an isolated cycle replace its old buckets with the chosen single bucket and emit that label at every surviving row there.

There is no per-row LF permutation in this construction. Obtain f, g and the input bucket slices by one scan over the old maximal runs, splitting at source-bucket boundaries. With K old classes and R runs there are H ≤ R+K−1 slices. In non-cycle bucket j let S_j be the run count of A_j. A stored A_k is consumed once, by its only eligible target or by final publication for a sink. Stream splicing therefore takes O(H + Σ S_j + R_new) elementary run operations, besides O(K+R) geometry and topological work. Total A-stream length *before run compression* is at most m old rows, so Σ S_j ≤ m. Storing all streams and old slices takes O(K + H + Σ S_j) words before charging the new output and dictionaries. These are upper bounds for an implementation which stores run lists; they do not assume free overlays.

**Removing the depth factor.** A child stream is consumed once, in prefix order. Store it as a balanced sequence of run-length leaves with subtree weights. Each eligible input fragment detaches a weight-specified prefix and joins the entire subtree to its parent's output. Each outside-D fragment contributes one literal leaf. Entire subtrees move without copying. Final publication can use old maximal incoming runs directly: a pure-cycle label occupies a single complete source bucket, so it can be recognized or dropped as a unit. At most one leaf splits per non-final prefix cut for any consumed stream.

Let R_N count old maximal runs bearing labels outside D, and c be the number of pure D cycles. In the non-cycle buckets let H_D and H_N count input fragments inside and outside D. The H_N initial literal leaves incur at most H_D minus the number of acyclic D classes internal splits during construction, because the last draw from each class consumes its remainder. During final publication there are at most R_N minus the number of outside-D labels internal splits by the same reasoning. Add one leaf per pure cycle. Each pure-cycle bucket contributes exactly one initial fragment; subtracting the class count K cancels those cycle fragments. Consequently

    R_new ≤ H + R_N − K + c ≤ 2R − 1.

The last inequality uses H ≤ R+K−1 and R_N+c ≤ R. These bounds include unmerged adjacent equal-label leaves: coalescing can only decrease R_new. Destructive tree splits and joins therefore give O((H+R+K) log(m+1)) worst-case operations and O(H+R+K) auxiliary words for the streams, before flat spelling, mark and output costs. No propagation term proportional to the sum of ancestry-run counts at all levels is inherent in this constructor. Balancing and subtree metadata carry real costs. The reference program uses explicit run lists, checks the stronger leaf bound for each tiny column, and compares its published column with an actual sequence of legal dense contractions. [Batch enumerator](batch.py) · [Small comparison](batch-small.json)

One grammar concatenation per acyclic eligible class and linear storage in the length of each pure class cycle suffice for spelling. Materializing actual flat spellings costs at least the output dictionary bytes. A source-rank mark can follow its old predecessors until the anchor is reached, accumulating preceding word lengths. Its walk is bounded in class steps by maximum acyclic depth plus one, or by the length of one pure class cycle. Charge predecessor location and the count of surviving rows preceding its anchor. Prefix-surviving counts over the original incoming runs and stable occurrence endpoints supply these with O(R+K) setup and O(log R) per point operation. On a pure cycle the within-class ordinal remains unchanged. Thus the complete transformation includes output publication, spelling and mark work in addition to the saved ordinals.

## What the ten existing real blocks permit

The initial eligible mass and optimum independent deletion were both recorded before this hypothesis. Subtracting the second from the first bounds the *largest additional* row decrease even if all eligible chains are fused. On frozen block 0 the bound is 1,276 extra rows, 1.320% of the 96,634 left by the independent fold. Across the ten bounds it is 537–1,396 rows, or 0.544–1.467% of the residual. For an ordinary token BWT induced at a named quote, whose physical orbits have the same type-ID word up to cyclic rotation, any pure D cycle would occupy the entire type support. Every tape here has an outside-D class. Under this common-pattern condition the bounds are equalities. The unconditional bounds alone limit the extra row savings. They do not bound savings from avoiding repeated setup or predict second-writer time. The measured frozen independent fold already raises second discovery from 5,694 to 17,723 queries. No native timing of overlapping batch contraction is used here. The additional row counts give insufficient evidence to prioritize it over the separately tested end-to-end writer. A direct run-intersection implementation and measured S_j would matter if future integration avoids a substantial construction cost.
