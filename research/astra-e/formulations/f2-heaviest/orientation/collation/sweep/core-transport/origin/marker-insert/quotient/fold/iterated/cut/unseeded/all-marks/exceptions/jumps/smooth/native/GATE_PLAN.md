# Independent smooth-terminal gate

Recover the stable order of original source indices by their last-column byte. Its inverse is the physical LF and the stable order itself is Ψ. For every gate, emit exactly n forward bytes starting at the supplied primary via F and Ψ and compare them to the production-shaped smooth terminal. Include exhaustive arbitrary binary last columns through n=8, ternary columns through n=6, explicit periodic and non-dividing marked cycles, cap fragments and large unary clips. Preserve the witnesses and counters. For the ten checked real inputs compare physical row transitions against independent LF across each depth and compare every output byte with both the dense marked oracle and immutable libbzip2-backed original inverse hashes. These are correctness and scope receipts only. RLE1 expansion, CRCs and worker decoding stay in the original donor receipt. Use CPU2 for local oracle calls.
