# Does one directional cursor per first-column symbol replace random rank searches?

A row in a second-trie interval has exactly one forward itinerary until its first return to the delimiter. Nonroot query intervals are pairwise disjoint, including across unary steps and depths. The root visits the delimiter's entire source bucket once. These facts suggest a stronger representation with a single advancing cursor for each source class. This is an ordering question because a child may be discovered only after its parent supplies its interval.

Form one vertex per queried interval, counting the exact stable images suppressed by unary contraction. Include an edge from each parent to each child. Within each source bucket, order the vertices by their interval starts. Choose a direction for that bucket and add edges between consecutive intervals in that order. The one-cursor schedule exists for that choice if and only if this finite graph is acyclic. A valid execution respects every added constraint; conversely any topological ordering discovers each interval after its parent and can use the indicated monotone cursors. This equivalence assumes all per-interval rank translations are available and is therefore a necessary optimistic test for this representation.

One cheap obstruction is a chain of comparable same-bucket intervals requiring increasing source rank, and another pair in that bucket requiring decreasing rank. Depth-first traversal with the extant minimum and maximum ancestor start per source symbol certifies both requirements in linear time and O(K+depth) auxiliary words. Such a bucket must support a reset, a random access, or different dependencies. The test allows arbitrary parent interleavings and independent per-bucket orientations.

Enumerate the global graph and every direction choice on finite three-symbol columns, preserving a minimal counterexample separately for a direct conflict and an incompatibility between otherwise feasible per-bucket orders if either occurs. Count conflicted buckets, searches and row mass in 40 actual token objects (named and the three coincident quotients). Treat each order obstruction as a statement about this representation only. A different treatment of already known full source buckets or speculative discovery can change the dependency graph. [Construction and checks](cursor_order.py)

A quantitative lower bound uses the sequence of starts for a single source class along any trie ancestor chain. If that class's chosen direction is increasing, each descent forces a reset. For decreasing order, count ascents. Taking the maximum over paths separately for each orientation, then the smaller maximum, bounds the resets of the best fixed direction. A freely reversing cursor still needs at least as many direction changes as an ancestor subsequence. Record the largest such count per class while restoring its path history on DFS exit. These are lower bounds even if other branches interleave perfectly.

For a binary token alphabet with delimiter d and one other label c, all possible live suffixes are c^k d. They form a single ancestral chain; their order inside the c bucket is monotone since the first distinction is d versus c. A third symbol suffices for an obstruction: the primitive cyclic word d c c x c, ordered d<c<x, forces searches for c d, c x c d, then c c x c d. Their relative ranks in the c bucket are first, third, second. The intervening search for x c d cannot remove that reversal.
