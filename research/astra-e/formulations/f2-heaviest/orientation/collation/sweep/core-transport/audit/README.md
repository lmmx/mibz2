# A positive first-hit word occupies a full physical rank interval

The result at `26ec650` extends to every source rank. Given a positive spelling C and a contiguous landing section U, the set Z(C) of **all** original ranks whose first positive visit to U spells exactly C is empty or one interval. On the ten Wikidata tapes, filling the holes in the selected top core added only 8–9 rows in total for the frequent section. For quote at depth four, it added 17,526. [Independent interval and selector implementation](intervals.py) · [Per-tape measurements](panel.csv)

## Exact endpoints from the original LF runs

Write U = [a,b). Let F be the sorted first column, L the original last column, and Ψ the forward permutation inverse to stable LF. From source x the decoder emits F[x] and moves to Ψ(x). For byte d define E(d,[s,t)) = [base[d]+rank(d,s), base[d]+rank(d,t)), where rank counts d in L strictly before the indicated endpoint. This interval consists exactly of the rows that emit d and move into [s,t). LF maps L-occurrences of d stably onto successive F-ranks. It therefore preserves all rank identities, including distinct ranks whose infinite forward bytes coincide.

Process C backwards, starting with J = U. For the last byte of C replace J by E(d,J). For each earlier byte first replace J by J ∖ U, then replace it by E(d,J). Return J immediately after the final extension. Induction on the suffix length proves the invariant. J for a nonempty suffix contains exactly its positive-first-hit sources. To prepend a byte, the intermediate row must be outside U, otherwise that byte already ended the return. The starting row of the completed word can be inside U. For the one-row fixed point with U the whole tape the single byte is a valid return, and the two-byte spelling is absent. This example detects both a misplaced final clip and a missing intermediate clip.

At every step |J| ≤ |U| because E selects at most one predecessor per input row. An interval of this width cannot include a point to the left of a and a point at or beyond b. Hence J ∖ U has at most one nonempty component. Rank extension of this component gives one interval, proving full-order convexity without any condition on the set V of selected sources. For a supplied C the implementation uses two original-rank queries per byte, starting with an O(r+256)-entry index built in O(r+256) time from r runs. A symbol query binary-searches the starts of that symbol's runs. A cycle disjoint from U contributes no row to a positive first-hit interval, even if its bytes match indefinitely.

## Why the emitted pieces equal the full-word runs

Suppose old sources s in U move forward t(W) steps along their own original return W with 0 ≤ t(W) < |W|. The distinct physical cut rows form V. The source atlas records the maximal bands of adjacent V positions that are also physically adjacent, come from consecutive original sources and carry the same forward prefix P. In physical V order the rows of each positive core C form one bucket by full-order convexity. Its old destinations increase with its cut-source ranks by stability of Ψ along the prefix C. Giving each incoming C run the next unused slice of this bucket therefore pairs every destination with the correct source. Intersecting those slices with the source atlas recovers P and W = PC.

Consider adjacent old destination ranks returning by the same W. Their sources are consecutive. Indeed, W's U sources are the intersection of U with Z(W), an interval, and Ψ along W increases strictly, so no source could lie between their preimages. At each step of their common spelling, stable select can only increase their rank gap. Its initial and final values are both one, hence all intermediate pairs are adjacent. The common t(W) puts their cut rows at the same depth, physically adjacent, with one prefix and consecutive origins. No forward select seam or early stop splits that pair. No core destination run splits it either. Conversely, every nonempty atlas intersection has a single P,C, hence a single original W. These two implications prove exact equality of the number of emitted intersections and the number R_full of maximal original destination-word runs.

Every atlas band supplies at least one nonempty intersection, giving B ≤ R_full. In V order the core-run slices collectively partition all m positions, despite arriving interleaved in destination order. Each of the B−1 interior atlas boundaries splits at most one of these slices. Thus R_full ≤ R_core+B−1. A general choice t(W) must itself be recognised and paid for. The finite-depth rule in the panel has an online first-return test. These statements require the natural atlas or its maximal-band equivalent. Artificially subdividing a band can raise the raw count before coalescence. Source order, distinct cut ranks and stable pairing still suffice for the transport with occurrence-dependent cuts. The exact run count can then fail.

The minimal failure for occurrence-dependent cuts has L = [1,1,0,0], U = [0,2) and Ψ = [2,3,0,1]. Both old words spell [0,1] and their destinations are consecutive. Choosing depths 0 and 1 gives two cores, two atlas bands and two intersections for one full-word run. Two changed occurrences of one word each need length at least two, which already requires four rows. For nonconvex landing sections the three-row example L = [0,0,0], U = {0,2} has Z([0]) = {0,2} and a disjoint middle row. Even on a single cycle, L = [1,0,0,0], U = {1,3} gives Z([0]) = {0,2} while row 1 spells [0,0]. At n = 3 a split bucket would require the extreme ranks 0 and 2 to emit the same first byte, forcing F to be constant and Ψ to be the identity. This excludes shorter single-cycle examples over any alphabet. [Exhaustive witnesses](exhaust.json)

## Recognising the most frequent occurring core

The fixed depth rule is t(W) = min(h, |W|−1). The panel builds the published run-based forward atlas and coalesces its physical bands into a mask for V. The rank index over this mask uses one start, end and cumulative width per component. A best-first search starts at U, reads original LF runs inside each live interval and uses the recurrence above. For each generated nonempty Z, two mask rank lookups count |V ∩ Z|. The queue bound for longer words ending in C is |Z(C)|. Their distinct starting ranks inject into Z(C) under a common prefix. A branch with no current V intersection can still contain a winning descendant, so its full mass remains eligible. The search stops only when every queued bound falls strictly below the best observed mass. This also certifies all ties. The minimum unsigned-byte spelling breaks ties deterministically. Children are generated by scanning intersected original runs, with a symbol-rank lookup for the first run of each distinct child. The reference stores reverse strings and charges heap work and copied spelling lengths in addition to the structural counts below.

For verification only, an independent stable sort builds dense Ψ. Walking every original U arc supplies the full core histogram. A source in Z(C) occurs exactly |C| steps from the end of an old arc whose word ends in C. The verifier enumerates these rows and checks that their **entire sorted list** equals the independently computed [lo,hi). It compares the components of cut rows among these occurrences with V ∩ Z, and checks the exact mode and its multiplicity. The verifier never supplies interval bounds, winner names or depths to the heap search. [Panel program](panel.py) · [All inputs, endpoints and counters](panel.csv)

For the frequent section the top spelling shrinks from 15 to 11 to 7 bytes. With a known winning spelling two mask ranks per tape then give the exact selected mass. Its full intervals cost 300, 220 and 140 endpoint queries across the ten tapes respectively, or 20 queries for quote. A shortcut using those fixed names would still need to justify their selection for an unseen block. Selecting the frequent landing section from quote cost another 39 expanded states and 72,272 original run pieces across the ten, reusable across depths. Sorting atlas bands, establishing the mask and indexes, heap processing and residual reconstruction also consume work. The panel measures structural counts only.

Filling a gap changes which rows are selected. For exact transport on the original V the added ranks must be excluded from source cursors and from physical membership used in backward discovery. Alternatively the full interval can serve as a new landing section with its own induced dictionary and return map. An arbitrary marked rank may begin in a stripped prefix, enter an extra row before any selected row, or lie on a cycle disjoint from the new section. To reconstruct n marked bytes one may emit through the original permutation up to the first selected visit, follow exact returns, and truncate at n. A disjoint cycle requires the original marked path or a separately justified fallback. The panel records the first distances and rank identities from each original primary to both candidate sections. Frequent block 72 at depth eight has just one extra row, but its primary reaches that row after one byte and the first selected row after 218 bytes. At depth twelve those distances are five and 222. For quote on frozen block 0 at depth four they are six and 23. The other 57 primary/section/depth cases hit both sets first at the same rank. These geometry costs imply no timed speedup.

The independent exhaustive check covers every binary L and every nonempty interval through n = 8. It checked 217,766 whole-interval probes and 481,288 marked outputs across 63,462 valid cut assignments. All 58,750 typewise assignments gave exactly R_full intersections. Occurrence-dependent choices split a full run in 3,360 assignments, including 2,012 where B itself exceeded R_full. The tests include 28,982 disjoint starting rows, 51,144 mark/section pairs with a cycle length that does not divide n, and 29,754 with another rank having the same itinerary. Every mask including the empty mask was also checked against dense frequency truth through n = 5, giving 18,356 independent selector tests. [Exact receipt](exhaust.json)
