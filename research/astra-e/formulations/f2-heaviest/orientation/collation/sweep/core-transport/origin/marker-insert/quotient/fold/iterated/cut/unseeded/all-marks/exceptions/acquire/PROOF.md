# Recover the exception permutation and its clocks

Inputs are the original L runs, physical rank intervals for the k-context states, each state's modal byte and the true primary. Their acquisition is charged separately. Add the primary to the exceptional row set E even if its own predecessor is modal, retaining its actual byte. It serves as a synthetic cut. The desired result is the distance in physical LF steps from each event row to its next event, and that event's physical identity. The marked cycle and any requested byte horizon follow by walking the event cycle through the primary. A synthetic modal event may be suppressed in the compiled clock.

**Default geometry.** Within a state, LF of all occurrences of its modal byte is a stable increasing bijection onto one contiguous destination interval in its default state. Omitting a synthetic modal primary may split this destination interval into two. Every event also has a known LF image. Counts before the current L run give its physical destination by addition. One pass over the L-run/context overlay obtains all event points, their LF images and all default destination slices. Routing a point to its state can use predecessor in the sorted state endpoints. The oracle does not need a dense LF permutation for this input adapter.

**Open each cycle once.** The default states form a functional graph. Select one anchor state on each directed cycle. Give its input rows the consecutive virtual labels (anchor,0),…,(anchor,N−1) at age zero. An event e births its own real label at row LF(e), age one, having consumed the exceptional edge. Treat incoming routes to an anchor as final outputs independent of the anchor's virtual inputs. All nonanchor states now form a DAG. Process each source state once. Its incoming intervals partition the source interval: each physical row has either one default predecessor or one real birth, with the virtual input taking the place of all incoming routes at an anchor. Concatenate the incoming sequences by their known interval starts. At each exceptional source position extract its label and age, terminating that path. The remaining labels stay in order. Increase every age by one, then give the remaining sequences to the known destination slices. This is a direct stable LF transport, so a label's age is the exact number of steps since its origin.

An anchor's virtual input is initially one affine segment of width N, with consecutive labels and common age. Real births are unit segments. Joins, ordinal splits and uniform age additions preserve this representation. There are O(K+|E|) split, join, slice and label operations globally, apart from the balanced data structure overhead. Sorting incoming slices can use O((K+|E|) log(K+|E|)) comparisons. The total number of interval fragments created by splitting and the number alive are O(K+|E|). Groups of widths approaching n need no per-row representation.

**Reduce a closed default cycle to two sets of holes.** Virtual anchor origins that terminate at real exceptions form U. Real labels that reach the final anchor supply entry positions V. All other virtual origins make exactly one full default-state lap of length d, the number of contexts on this directed cycle. Their map from [N) minus U to [N) minus V is an increasing bijection: each surviving step is the stable modal LF map and the same states occur in the same order. This also proves |U|=|V|. Distinct default cycles have separate anchors, with no route from one virtual anchor to another. A real label arriving at v must follow this monotone partial map until a hole u, then take the virtual path from u to its terminating event. Its total distance is arrival age plus d times the number of full laps plus that final virtual age.

**FIFO solves the large monotone partial permutation.** On the ordered line cut at each prefix where the numbers of U and V points agree. No matching arc crosses such a cut because domain and target survivors have equal prefix counts. Between successive balanced cuts there is one sign of excess: when V occurs first, scan increasing ranks, and when U occurs first, scan decreasing ranks. Increasing stable matching is also stable in reverse order. In scan order, V is a new chain, U ends a chain. At every other target dequeue the earliest unmatched source, inheriting its chain with one additional map application. At every other source enqueue that chain. Prefix balance guarantees a label is available when required. A shared U,V point starts and terminates a zero-lap chain. Remaining regular rows outside all nonzero excursions are fixed; they have no event labels to route.

Across L consecutive ordinary positions with a queue of h live chains, each position rotates the queue by one and increments the popped chain's lap count. In bulk, add floor(L/h) to every chain, add one to the first L mod h and rotate that prefix to the end. No iteration over L is required. Hence O(|U|+|V|) queue operations suffice across all anchors. The separate partial-map verifier compares every completion to literal rank matching and tests enormous affine gaps.

With a deterministic balanced sequence supporting join, split and lazy range additions, this is O((K+|E|) log(K+|E|+1)) time after input geometry, plus ordered-fragment setup and event-cycle traversal; memory is O(K+|E|). Word arithmetic assumes counts and timestamps fit a word. The reference uses a randomized implicit treap. Its logarithmic operations are expected for an input independent of its priorities. A fixed seed gives reproducibility, with linear worst-case tree height and potentially quadratic total time. It does not certify the deterministic worst-case bound for that implementation. Every output exception still has to be emitted or handled downstream, and dense E can erase the value of the reduction.
