# Decode a byte BWT by reversing integer position maps

On an ordinary delimiter cut, store the length of each current type. A join replaces two lengths by their sum. The forward pass publishes the next weighted column and a list of affine intervals for the old physical ranks. It never stores the letters, children or identity of any composite spelling. An ordinary cut that removes at least a quarter of the current rows may be used in either orientation. Stop successfully at one row. This certifies that the original marked permutation was transitive because an ordinary cut contracts disjoint pairs within cycles and keeps at least one member of each cycle. If the quarter test fails, the test wrapper restarts the existing general marked inverse on the untouched original input. On arbitrary inputs it charges the work up to that decision. [Numerical constructor](encode.py) · [Fallback and exhaustive check](finite.py)

Let Pᵢ(x) be the start coordinate of the old type at rank x within the eventual terminal lap. The unique terminal has P=0. An old surviving rank takes P of its compressed rank. The old rank x removed immediately after surviving rank y takes P(y)+length(type(y)). Every merged word consists of two whole words in that order, so both coordinates are in the same terminal interval. Induction gives each original physical source its full coordinate. Since the original words are single bytes and the one terminal contains all original rows once, these coordinates are a permutation of 0 through n−1. Subtract the original primary's coordinate modulo n to obtain the bzip2 output basis. The byte to scatter at each coordinate is the original first-column symbol. Alphabet counts suffice to obtain it in physical order.

At each internal level expand the survivors from compressed ranks into their old physical positions. A survivor interval is moved to the right by its deleted prefix. Processing in descending destination order preserves every unread survivor, including overlapping source and destination. Gaps after expansion correspond exactly to removed ranks. For each gap the predecessor is a survivor in a single original source class, so one affine copy plus a constant reconstructs its positions from immutable survivor entries. The outermost level can read the compressed ranks for both kinds of interval and scatter bytes straight to output. One u32 buffer of capacity m₁, the first surviving mass, suffices. No original n-entry coordinate table is needed for ordinary emission. An optional audit switch separately writes the full coordinate permutation. [Native emitter](emit.cpp)

All **8,999,915** source positions on ten original columns matched a separate stable sort and full marked cycle walk. Every reconstructed stream of RLE1 tokens passed independent block recovery, libbzip2 bytes and its stored block CRC. On the frozen block P(primary) was 84,941. All ten took 25 cuts and collectively avoided 566,895 spelling joins. The proof adapter still built and reordered 852,077 numeric output-type entries summed across cuts. The 1,355,564 affine descriptors cost 16,266,768 bytes over the ten independent inputs. Reverse reconstruction read 24,241,607 and wrote 15,241,682 offset words and scattered 8,999,915 output bytes. Per-block maximum wire was 3,291,408 bytes and maximum coordinate scratch was 2,418,548 bytes. Native live storage additionally includes the returned n bytes, per-level sentinels, vectors and frequency bounds. During construction the reference Python implementation also retains the prior maps, active and refined columns, overlays, histograms and numeric-width objects. These figures are logical storage counts. Fresh process RSS and complete CPU require separate measurement. [Ten-block hashes, costs and CRCs](blocks.jsonl)

On **1,538** arbitrary binary last-column/primary pairs of length at most seven, 98 used the numerical path and 1,440 used the connected fallback. All marked outputs agreed with stable LF. The fallback includes both a heterogeneous two-row fixed-point column and a primitive five-row example requiring powers with this cut chooser. The executable is a standalone inverse-stage experiment. The ten recovered blocks establish block CRCs. No stream parser or combined-CRC test was added to this formulation. [Small counterexamples](small.json)

Run at the repository root on a checkout holding the ten frozen input records and the recorded original Wikidata corpus.
