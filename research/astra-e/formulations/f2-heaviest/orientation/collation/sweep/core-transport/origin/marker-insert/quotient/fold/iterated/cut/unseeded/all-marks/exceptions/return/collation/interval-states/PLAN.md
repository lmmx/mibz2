# Replace expensive prefix-context discovery by one sweep over arbitrary rank intervals

Partition physical ranks into intervals. For each source interval choose the modal pair (incoming byte, destination interval of LF). Its default subset maps increasingly onto one contiguous interval: intersect the full image of rows with that byte and the chosen destination interval. One source or target boundary can split at most one original L-run translation, so a direct classifier can count all pairs in at most R+2(C−1) affine pieces. Test regular widths 16,32,64,128,256,512 and 1,024 on the ten original inputs. Count complete costs of recognition, exception mass, default jump eligibility, and state population. No k-depth prefix hierarchy is assumed.

Test a stronger collation statement for *any* such interval-state predictor. Shift true exceptions one LF step backwards. The d−1 predecessor defaults from z reconstruct all interior bytes and states, while the two endpoint transitions pin the two true exceptions. For fixed spelling W·F[z], each Ψ^i through d+1 is increasing on its byte cylinder, so requiring all its ranks to lie in the resulting state intervals preserves convexity. Verify even full physical convexity, every weighted spelling and ordinary sparse LF. Seek counterexamples to dropping endpoint-state fields.
