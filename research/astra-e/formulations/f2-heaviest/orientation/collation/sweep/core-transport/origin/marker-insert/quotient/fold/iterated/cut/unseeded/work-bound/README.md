# Complete worst-case work from an ordinary marked BWT

For m positive-weight source rows and an output horizon of L bytes, the direct geometric construction admits **O(m+L) word-RAM time**, without building an array of one successor per ordinal. Count R maximal incoming runs and K distinct positive types at the start of a pass. K≤R≤m. Assume that row coordinates, byte lengths, positive repetition counts and the requested output endpoint fit in machine words. Supplied literals must be readable or their storage and acquisition must be charged separately. For original bzip2 bytes the initial grammar is at most 256 unit literals.

1. Prefix masses and one overlay of the incoming runs with the K source buckets take O(R+K) time and produce at most H=R+K−1 fragments. In each source row's class, distinct destination neighbors first occur in increasing destination-bucket order. Assign an ordinal to each new neighbor with a last-seen bucket and an integer counter per type. A counting prefix over those degrees gives each class its contiguous output ID range. The arbitrary-label conditional-expectation chooser needs two passes over each bucket's fragments and per-class pending signed mass. Alternatively one XOR histogram uses linear work. Either choice can be fixed independently of the primary.
2. Once colors are known, class counts, selected pairs and new weights cost O(H+K) time. A streaming constructor can build one ancestry list per target by scanning the H fragments in old destination order. The lists' combined length is at most H. A second scan deletes selected inputs and consumes those lists with monotone per-target cursors. Every step exhausts either an incoming piece or a list piece. Therefore time and emitted intervals are O(H+K). Counting deleted positions before the mark and before its sole predecessor is another linear scan. These direct integer-addressed operations need no sorting of arbitrary word spellings.
3. If the preliminary cut fails the quarter test, normalize powers. Let V be the number of interval predecessor queries in the backward construction. Each continuation consumes nonempty old ordinals with a unique nonself exit and distance, so V≤m. A split of a source interval charges one old run-boundary coordinate that cannot be visited in another interval. Total intersections are at most V+R−1. A single original histogram also provides all run bases and displacements.
4. Index the old RLE starts in a packed bitvector. Each machine word has a prefix count of starts in earlier words. The inclusive rank of starts through x is that prefix plus a population count of the current word masked through x. Subtract one for the zero-based containing run. This works even over arbitrarily many empty intervening bitmap words. Setup costs O(R+m/w) time and words on a w-bit machine with constant-time word arithmetic and popcount. Each query costs O(1). The extra query for an interior marked power uses at most R run pieces, and the entry's new ordinal comes from the same overlay. Total backward publication work is O(m).
5. The O(R+K) terminal fragments carry keys (type, repeat, exit side) and their original destination order. Sort their integer indices stably by the prescribed key using radix b=⌊√m⌋+1. Two digits each for the length component and the type, and one digit for the side, suffice. Reverse the length order in the positive exit group by using m−repeat. A linear pass assigns equal adjacent keys one ID, then writes each ID to its original fragment slot and coalesces the published RLE. No per-row scatter or hash table is required. Time is O(R+K+√m) and this sorting scratch uses O(R+K+√m) words. Identical powers on opposite exit sides may share a node by merging their opposite depth orders for each type. Even with separate nodes, any repeat of length at least two charges a removed old row.
6. With ρ=3/4 the active masses obey mᵢ₊₁≤ρmᵢ. All passes together cost O(Σmᵢ)=O(m). There are at most m−1 newly allocated power and binary grammar nodes, since each positive join or power can charge a permanently removed row at that phase. A complete marked root's byte height is at most two grammar edges per cut/power round above its original literals. One root descent finds an arbitrary byte in O(log m). A depth-first traversal of a span of length L visits O(L+log m) nodes. At each depth only the two boundary paths can be partially covered. Every wholly covered nonliteral in the expanded tree has at least two positive children. Repetitions with many identical children permit iteration or copying from an initialized span. Thus output preserves the full arbitrary-horizon bound. For bzip2 an ordinary RLE1 and checksum pass adds linear decoded-byte time.

Per-pass transient scratch, excluding stored grammar and the returned output, can be bounded by O(R+K+m/w+√m) words. On very sparse powers the existing comparison-search publisher uses O(R+K) working words and V≤min(m,O(R²)); each predecessor or key sort adds at most a logarithm in R. Select that route if its conservative R² log(2+R) bound is cheaper than m. This preserves the linear upper bound while allowing an enormous homogeneous run to remain compressed. The interpreter verifies the primitives and full power outputs. Its dictionaries, comparison-based support code and Python object allocations are outside the claimed word-RAM implementation.

The checker covers arbitrary ternary columns through seven rows, 12,346 lookup positions spanning many empty bitmap words, stable duplicate keys at digit boundaries and the real original frozen first power pass. On that pass 14,062 bitmap words suffice for 899,931 ordinals. The constructor issued 51,643 non-root lookups and visited 62,446 intersections before its 48,931-run output. It matched the original dense stable-LF oracle and comparison-search implementation. All ten original-byte blocks bypassed normalization in the actual guarded algorithm.
