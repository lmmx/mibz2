# Contract every event-free context before moving labels

If a source context has no exceptional or synthetic stop, every one of its rows emits its modal predecessor. Its entire interval maps by one translation onto a subinterval of the next context. Consequently any number of incoming label packets can pass through this state by adding its destination offset and one step uniformly. Composing a chain of such affine maps changes only a single offset and an integer length.

A directed cycle made entirely of event-free contexts needs no label processing. Each state width is at most the next state's width; hence all widths around the cycle agree and each state covers the whole next state. Physical LF bijectivity leaves no incoming edge from outside, including actual event births. The primary is an explicit stop, so its physical cycle is represented. Pure unmarked cycles need no exception clocks.

For each active context (at least one event or the primary), retain its original source interval and destination coordinate system. Compose every default packet leaving it through the first following active state, carrying its final offset and elapsed step count. Do the same for each event birth after its first LF step. All incoming packets at each retained state still partition its exact original interval. A virtual lap's duration is now the sum of the composed default-edge lengths, which is independent of its starting rank. The stable-hole FIFO theorem is otherwise unchanged.

The count of active states is ≤1 + K_(k+1)−K_k, because each nonunanimous context contributes at least one extra supported extension and only a synthetic primary can activate an otherwise unanimous state. It is also ≤|E|. Computing all composed translations costs O(K) state operations once plus the original input geometry. The subsequent transport uses O((K_active+|E|) log(K_active+|E|+1)) balanced-sequence work. Whole original intervals and DAG ropes are separate objects; the bound does not remove the cost of collecting the original k-context model.
