# A join lower bound from one source–image overlap sweep

Tag every initial conjugated translation atom with a distinct abstract symbol, even where two atoms both spell the same byte. For each retained rank, take its complete positive return word over these **atom IDs**. Let D be the number of distinct ordered adjacent pairs in the union of these words. An ordinary endpoint construction of this labeled exchange needs at least D distinct-tip joins.

Each initial atom carries a one-letter word. Every new word is the concatenation of two earlier words. All its internal adjacencies except the crossing pair were already present in those two operands. Therefore a join creates at most one previously unseen pair, formed by the last atom of the left operand and the first atom of the right operand. A self removal adds no pair. The final words contain all D pairs, hence J≥D. Word storage can collapse two equal byte strings, or a particular word operation can be cheap, but the same ordinary endpoint trajectory can always be decorated with atom-ID words. Therefore D bounds ordinary distinct-tip steps even when the implementation actually keeps only byte spellings.

For a given physical point y outside V, its direct predecessor edge comes from x=T⁻¹(y). If its cycle touches V, the atom containing x followed by the atom containing y appears consecutively inside a retained first-return word. Conversely, every internal adjacency occurs at exactly such an intermediate point. The incoming ID at y is determined by the target partition and the outgoing ID by the source partition. Since each atom has one interval on each axis, a particular ordered pair occupies their one contiguous intersection. With all cycles touching V, counting the nonempty source–target overlaps within the complement therefore computes D. The explicit m cut puts the complement in a suffix, so advancing the two interval iterators costs O(A) time, O(1) extra memory and no traversal of the marked word. Equivalently, count distinct internal boundaries of both partitions in that suffix and its first interval. The real verifier also checks the supplied primary visits every physical row on these ten blocks. When a complement-only cycle exists, one must count only overlaps realized on section-touching cycles. Counting all complement pairs may give a false lower bound. The canonically joined bands on a primitive cycle have no self removals before reaching nonempty V. With explicit section boundaries the A−B disappearance of live atoms is then exactly the number of equal-width joins. Thus J≥D implies at least max(0,D−(A−B)) unequal-width steps. The bound is independent of the complement ordering for a fixed set of physical atoms. If several original cycles all touch V, the same absence of complement-only self removals holds.

For the K8 model these two input partitions already certify that at most 203,758 of the 922,499 observed joins can disappear by ordinary reordering at the same physical refinement. They place no limit on a different reduction operation that can create many atom adjacencies at once, or a representation that accepts different final atoms. The argument extends to length q≥2: one binary concatenation can create at most q−1 new length-q substrings spanning its split. If Dq distinct length-q atom strings occur inside the final return words, then J≥ceiling(Dq/(q−1)). The small verifier checks this for q=2,3,4 while charging adjacency only on section-touching orbits. The two-character case is particularly cheap because its geometry is present directly on the original source and target partitions.
