# Intrinsic limit of a deterministic predecessor table on physical intervals

For any interval partition with C states, follow its default successor table h times from each state. That trajectory predicts exactly one length-h predecessor word throughout each entire interval. At any physical rank where h actual LF steps all match the model, that word must be the true one. Hence the number of all-default starts A_h is bounded above by the best unrestricted segmentation of the true physical length-h predecessor words into C interval constants. Charge λ per cut and maximize the relaxed agreement minus λ times cuts using the lazy-floor DP with every seam available. Its value plus λ(C−1) is a certified upper bound. Every exception disrupts at most h starts, so the bound gives a certificate E≥ceil((n−upper)/h). This applies to every possible choice of seams and transitions, including nonmonotone refinements. The relaxation may be loose because it drops target consistency.

Check attainable agreement and the dual bound by exhaustive physical partitions on small binary columns. On the ten original blocks use h=1,2,4,8,16,32 and λ=0,1,2,4,8,16,32,64,128,256,512,1024, plus the one-segment extreme. Evaluate the actual per-block state counts produced by the four adaptive policies, regular grids, and fixed k=8; record per-h disagreement ceilings and exception floors, and compare to realized scores. Distinguish all overlapping valid starts from disjoint eight-byte emitter batches. The dense oracle used for this screen is outside any worker.
