# A direct predecessor model for the marked byte column

Write Ψ for the forward stable successor, LF=Ψ⁻¹ for its inverse and F[x] for the source byte of x. The incoming byte is L[x]=F[LF(x)]. The depth-k word at x is F[x],F[Ψ(x)],…,F[Ψ^(k−1)(x)]. These definitions apply separately to every permutation cycle. Distinct ranks spelling the same periodic word need no tie-breaking.

For depth one the source byte buckets are the exact maximal equal-word intervals. If [l,r) is an interval for word u at depth j, the LF image of its a-labeled incoming positions is [B[a]+rank_a(l),B[a]+rank_a(r)). This is one interval by stable occurrence order. Its word is au. Distinct parents produce disjoint children inside the same initial byte bucket in original parent order. Distinct initial bytes already have disjoint ordered buckets. This proves both maximality and coverage by induction. A sequence of appended cumulative right endpoints per initial byte computes precisely the same intervals from run widths. No strings or global per-row rank arrays are needed.

At requested depth k this interval for au has length k+1 in symbols. Its ranks have the same first k symbols, so its entire positive image lies inside one current context. For each a, successive image intervals partition the whole F bucket from left to right. Its single cursor therefore advances exactly the number of depth-k contexts in that bucket, even if one context receives many extensions. The sum over all bytes is C_k. The most frequent incoming a, ties assigned to the least byte, gives the default word and this cursor's current state gives the exact default successor. Every other incoming run intersection has a known physical rank span, actual byte and poststate. Adjacent exceptions can merge exactly when they touch and both payload fields agree. Their physical order does not identify an output clock.

For R maximal original runs and C_j current intervals let H_j be their number of nonempty overlay pieces. The two sets of interior endpoints have a union of size H_j−1, so H_j=R+C_j−1−S_j for S_j common interior endpoints. Each distinct positive incoming byte in a context needs at least one such piece. Hence C_(j+1)≤H_j and C_k≤min(n,1+k(R−1)). Scanning all H_j pieces and clearing only encountered byte counts costs O(H_j+C_(j+1)+256) per depth. No 256-entry histogram is cleared per context. The final direct model takes another read of precisely the pieces in its nonunanimous contexts. It pays for up to C_k advancing poststate cursors and writes at most H_k exception descriptors. If C_(j+1)=C_j the refining partition is a fixed point and all deeper reported states may reuse it. The n-row input is never expanded during construction.

The per-level bound is sharp for a two-run primitive family L=b a^N, a<b. It has the (N+1)-cycle spelling a^N b. For j<N its distinct length-j cyclic words are a^j and each of the j words containing one b at a distinct position. Thus C_j=j+1 and H_j=C_(j+1)=j+2. Depth-by-depth enumeration uses Θ(k²) work through depth k≤N although the final context count is only k+1. That is a limitation of repeated explicit refinement. It does not establish a quadratic bound for every possible constructor. The native compressed witness has N+1=2³²−1, runs the full construction through k=1024 and emits exactly one exceptional row. A homogeneous input of the same size stabilizes at depth one even for requested depth 2³²−1.

Storage includes the original width/symbol RLE, two consecutive sets of endpoints during refinement, and the final endpoints, two default arrays and four physical-exception arrays. Each level has fixed alphabet-sized cursor/histogram scratch independent of n. Real retained vector capacities are counted separately from fixed objects and allocator transients. The stage-only fresh-process RSS accounts for the executable, input and allocator behavior of the native diagnostic. The binary ABI is little endian with eight literal magic bytes CTXMOD01; seven u32 values n,primary,k,C,D,exception_rows,primary_state; C records (exclusive source end:u32,default poststate:u32,default byte:u8); and D records (source start:u32,exclusive end:u32,poststate:u32,actual byte:u8). Its size is 36+9C+13D bytes.

On a true marked cycle, reverse event replay from primary is aligned to a horizon n when its lap divides n. In arbitrary multiple-cycle data, producing n forward bytes by filling backwards starts at Ψ^n(primary) or an equivalent known phase. The finite independent test checks both horizons n and n+1 starting at every marked ordinal. Construction itself is mark-independent except for the initial context ID.
