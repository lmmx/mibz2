# Price a linear worst-case construction without an ordinal successor table

The original-byte grammar has geometric active mass and works on every marked column. Test whether its remaining logarithmic predecessor search or sorting is inherent. Build a run-start bitvector with one prefix count per machine word; preceding-run lookup takes a count and popcount independent of empty stretches. Test the full backwards power constructor with this query interface on all tiny instances, an input with many empty bitvector words and the frozen first power stage. Compare the complete maximal-run, unseeded arbitrary-byte implementation cost in word RAM with the existing compressed alternative for very large sparse powers. Derive exact ordinary-publication, per-pass, end-to-end and working-space bounds, stating integer-width and positive-weight assumptions. The ten real byte columns bypass power publication, so this experiment concerns all-input guarantees.
