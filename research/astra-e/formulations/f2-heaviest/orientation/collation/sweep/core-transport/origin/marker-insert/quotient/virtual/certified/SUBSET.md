# Optimal number of rank records at any immediate-child budget

With the root removed and any authorized immediate branching children eligible for deletion, choose t children that minimize the number of complementary LF records. Removing one source bucket with r inside records loses at most the two old boundary bridges and creates at most one. Its savings are in [r−2,r+1]. Hence deleting another genuinely branching bucket (r≥2) never increases this exact index size. Choosing the t largest r is within 3t records of the optimum. The exact algorithm uses the previously established fact that each boundary has at most one compatible partner.

Delete the mandatory root and number the remaining sources in their original order, with compulsory retained sentinels at 0 and K+1. Let D[j,a] be the minimum cost ending with retained j after exactly a optional deletions. For a preceding retained i, every intervening bucket must be optional. The predecessor uses a−(j−i−1) deletions. The transition adds rⱼ and discounts one if i is j's unique compatible predecessor. As j increases, the plain predecessor minimum uses D[i,i+u] for fixed u=a−j+1. Maintain each diagonal minimum since the last compulsory retained source. Test the one potential compatible predecessor separately, then reset at compulsory sources and insert the new row's finite entries. This gives exact values for all budgets through t in O(Kt) work. O(Kt) storage supports a witness for each optimum; other counters and record/seam tables need separate construction.

This objective measures only complementary rank records. Final link mass, root recognition, per-class setup, child selectors and all actual computation remain paid separately. The real census records every optimal budget and its original dictionary spellings, so a fixed literal hypothesis can be checked against later blocks without fitting its identity repeatedly.
