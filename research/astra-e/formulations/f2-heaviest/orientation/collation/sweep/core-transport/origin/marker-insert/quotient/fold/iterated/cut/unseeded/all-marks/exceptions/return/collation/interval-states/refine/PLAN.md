# Choose adaptive physical states with exact zero-penalty target splits

Start from the F-byte buckets on the original L column. A candidate new seam at the end of LF(I filtered by byte b) for an existing source interval I is already a boundary of the ordered b images. It cannot divide any old (source,byte) occurrence interval. Thus adding any subset of these seams only improves or preserves total modal-pair mass when sources and destinations share the same new partition. There are at most R+C−1 nonempty source/byte intervals from R incoming runs and C states. Select a subset maximizing true modal mass minus λ per new seam. For each old source interval run a segmentation DP; the reward of one segment is its most frequent (byte,old target) count. A single allowed cut grants every label a possible new start at the best prior value minus λ. A lazy global floor suffices, so only the current label's score needs to be advanced when a physical transition fragment is consumed. Preserve an actual maximizing partition and charge all fragment scans, support-list construction, score entries, path nodes and phases.

Before considering a worker, verify the optimum against exhaustive subset enumeration on arbitrary tiny columns and all partial starting partitions. On ten real original blocks test λ=1,4,16,64 and at most 16 refining rounds. Compare exact prediction mass, realized eight-step marked coverage, final state count, variance across blocks and total work to fixed k=8, variable k=16 threshold 16, and simple regular physical tiles. A smaller state table alone does not justify native progression.
