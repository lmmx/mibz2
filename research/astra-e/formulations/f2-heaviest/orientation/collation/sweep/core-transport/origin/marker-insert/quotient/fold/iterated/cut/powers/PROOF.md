# Maximal equal-type runs give geometric contraction on every marked input

Let π be a finite marked forward permutation, increasing on every ordered source-type bucket I_a. Each occurrence of a emits the same positive weighted word W_a. The requested horizon is measured in original bytes; it need not be the length of the marked cycle. First split the marked source occurrence into a singleton type, preserving all original edges and words, as in the protected grammar construction. If the marked source is already fixed, return its word cyclically at the supplied offset.

## Stable source order of the power tokens

Set J₁=I_a. Let J_d contain original positions whose first d forward source labels are all a. If J_d is an interval, π^d is strictly increasing on it by composition of the increasing restrictions to I_a. The preimage of I_a under this map on J_d is therefore an interval J_{d+1}, possibly empty. Induction gives the assertion for every d. The two ordered pieces of J_d outside J_{d+1} exit on opposite sides: the first maps below I_a under π^d, and the last maps above. If J_{d+1} is empty, split the interval where the increasing image first exceeds the upper boundary. Thus occurrences with a given exact finite length d and exit side form one interval. Equal d alone does not require merging the left and right pieces.

Retain the source positions S whose incoming predecessor type differs from their source type. Relatively to S, intersection with any of those intervals is still one interval. The ordered alias (a,d,exit side) labels a consecutive group of retained sources. At a retained x the next retained source is precisely π^d(x), and x emits W_a repeated d times. π^d is increasing on that alias, so a stable ordinal column represents the new permutation exactly. Distinct aliases can share the same W_a^d power node. Empty aliases cost no records.

Every nonconstant-type original orbit splits into disjoint maximal runs starting at S. A constant-type cycle inside I_a is fixed pointwise: its order-preserving permutation on that finite set is the identity. These are the only old vertices not covered by retained runs. The primary's singleton type makes it a run start whenever its orbit is nontrivial, even when identical byte payloads have other IDs. That protected source has d=1 and retains its previous byte offset since the contracted run starts there. A marked fixed point is handled before normalization; unmarked fixed-point orbits may be omitted. The original requested horizon remains unchanged. This preserves arbitrary byte offsets, cyclic rotations, multiple cycles and repeated marked laps.

If e=Σ_a E_aa is the number of same-type original transitions, then |S|=m−e by counting all mismatching incoming edges. Every surviving macro edge joins distinct original source types, hence distinct macro aliases. When e=0 one can pass the existing zero-diagonal column directly to the cut and avoid all new indices and aliases.

## A depth and construction bound

On the zero-diagonal macro column the protected greedy delimiter cut removes at least |S|/4 with no assumption about the input. It preserves the anchor and the exact emitted spellings. Hence one power-and-cut round satisfies

    m_next ≤ 3(m−e)/4 ≤ 3m/4.

Positive integer row counts imply at most ceil(log base 4/3 of m_initial) nonterminal rounds. The sum of the input sizes of those rounds is at most 4m_initial. Immediate fixed-primary termination can leave other rows. The bound counts work done before that termination. A power node is created only when d≥2, with at most one per participating run even without node reuse. This requires at most the number of nonfixed same-type edges. One cut join per selected class is at most the number of rows the cut deletes. Summed over rounds the number of newly allocated spelling nodes is at most m_initial−m_terminal. Aliases, geometry and emitted ordinal arrays still require separate space and work.

A dense constructor builds the stable successor and retained-rank arrays in O(m) time, walks each retained run once and scatters one ID per retained destination. Initial and intermediate maximal runs, source classes and distinct adjacency contacts all number at most m at that round. Destination-owner overlay and source alias assignment can use append-only lists per old type: as old physical destinations are scanned, partner bucket IDs are nondecreasing for any given predecessor. The cut graph and stable stream replay likewise have linear-sized lists. Thus deterministic linear work in m_initial is possible for the complete sequence of ordinal constructions. This does not bound the constant or establish competitive peak memory.

The original output horizon n is at least the byte length L of the marked lap for the standard BWT contract. One implementation can materialize a full lap directly into the first L output bytes, rotate that prefix in place by the marked offset, then repeat it into the remainder. Each full grammar expansion of length L can visit at most 2L−1 nodes when a power emits its base once and duplicates its bytes. This follows inductively for positive literal leaves, binary concatenations and powers with d≥2. Its total emitted/copied byte volume is O(L) when each power copies only the additional bytes it contributes, and the final tiling is O(n). The reference writer also handles shorter, arbitrary requested spans using explicit partial traversal and reports its actual visited nodes and byte sources. [Writer](grammar.py)

## A sparse constructor for long self chains

An old incoming RLE record of a contributes one source interval [lo,hi) to π on I_a, with constant translation δ. Stable occurrence counters construct all such source intervals without a dense old permutation. One source-bucket/incoming overlay gives at most H ≤ R+K−1 fragments. Retain intervals in that overlay for which source and incoming labels differ, with their cumulative ordinal counts. This represents S and the map from an old destination in S to its retained rank.

Walk from each retained source until the first different source type. In one affine piece, the interval of source points that stay in I_a is the intersection of [lo,hi) and I_a−δ. For δ>0 take consecutively 1+floor((upper−1−x)/δ) forward steps while the source remains in that interval. For δ<0 take 1+floor((x−lower)/(−δ)). A zero displacement is a fixed point and cannot be reached from a retained source in a permutation. The piece query at the final different-type exit contributes one step. While a run stays in I_a, successive positions move strictly in the same direction by monotonicity. Every paid lookup traverses at least one original edge, and all runs are disjoint. Thus the actual query count J is at most the number of nonfixed original rows, including all exits. Long affine stretches often cost only one lookup.

The compressed constructor needs O(R+K+H) setup and O(J log R + (m−e) log H) point and scatter-index work with binary predecessor searches. The reference writes an explicit array of m−e destination IDs, then emits its RLE. In addition to the old/new dictionary and final output, its working storage is O(R+K+H+m−e). Stable ordered keys provide the alias ID on a single scan of S. These bounds distinguish an advantage for very sparse starts from cases where most rows remain. For the former protected obstruction F=a^N b and L=b a^N, one true run a^N plus one singleton b survive. A single clipped affine jump spans all internal a→a edges, one exits to b and one exits from b. The two-row normalized column collapses to the marked fixed point in one cut. This works with constant index and scatter sizes for arbitrary N. In the example with N disjoint a fixed points, those rows are omitted when b is marked, and an a primary returns directly.
