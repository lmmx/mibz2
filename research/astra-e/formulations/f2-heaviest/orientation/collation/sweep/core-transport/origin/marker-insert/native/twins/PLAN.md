# A bounded replication of sparse4 with a source-identical control twin

The completed 32-round eight-arm study at f37c557 missed the frozen advantage criterion against ordinary named quote. Its untrimmed sparse4/named log ratio was .93176 [.78900,1.10034]; the median round ratio was 1.021. The actual named median individual time was 1.82 ms, with a 208.57 ms maximum. A separate probe found sparse8's 327.23 ms maximum. This motivates a measurement of the control variation as well as the near-tie. The former study remains the registered decision.

Freeze 144 complete ten-block rounds, with named-A, named-B and sparse4 in one executable. A and B call precisely the same named Rust function through the same runtime wrapper, with separately allocated long-lived scratch objects. Use the same original run archive, not an inferred or regenerated corpus. Warm all three paths and verify each output. Change block starting point with round and reverse each alternate six-round cluster. Every block uses all six orders of the three arms per cluster. Time on CPU3 at nice +12, retain every observation, verify marked bytes after each call and do not drop large observations.

Use the geometric mean of full-round CPU ratios. For uncertainty group 6 consecutive log ratios and use their unweighted mean, leaving 24 balanced temporal units and a two-sided t interval. Report sparse4/named-A, sparse4/named-B and named-B/named-A, plus common first, publication, second, output and full CPU sums. If any output differs, stop. At 48 rounds, use **only** the eight completed control-pair cluster means to project the full 24-cluster half-width: 2.0686576 × sd(cluster log means) / sqrt(24). Stop for insufficient precision if this exceeds or equals log(1.08). There is no interim candidate criterion and no extension beyond 144 rounds. No production timing or promotion follows from this replication alone.
