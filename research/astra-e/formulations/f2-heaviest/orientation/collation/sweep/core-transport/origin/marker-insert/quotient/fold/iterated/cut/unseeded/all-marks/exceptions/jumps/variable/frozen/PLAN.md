# Learn a suffix-closed dictionary once and project it onto unrelated held-out blocks

Freeze training to original block index 1 alone and hold out each of the other nine systematic Wikidata blocks. Across all of them use exactly its suffix-closed k≤16 prefixes passing training thresholds 32, 128 or 512. Compute the physical occurrence interval of each retained cylinder on a target from its suffix interval and two true original-BWT rank queries. Prune empty children. The shared dictionary contains only parent indices and one prepended byte. Price treating each target physical component's modal prediction as a new local distribution. Measure active components, paid rank queries and comparisons, missing patterns, exception count and byte coverage of eight-step jumps. Check every retained cylinder directly against actual marked rotations. Compare with oracle per-block adaptive K=16/threshold 16, and report the literal dictionary size and full preparation requirements. A learned model always reconstructs exactly via the same sparse exceptions; held-out savings, including lookup and build cost, require measurement.
