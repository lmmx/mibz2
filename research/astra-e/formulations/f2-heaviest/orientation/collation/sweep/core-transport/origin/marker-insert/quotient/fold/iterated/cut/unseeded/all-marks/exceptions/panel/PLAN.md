# Recover the marked word by sparse exceptions to a default predecessor

Use each original rank's first k cyclic forward bytes as its context. Its most frequent preceding L byte, ties smallest, gives a default transition to the context one step backwards. Only exceptions require an ordered event carrying the true byte and next context state. Over one primitive lap start at the true primary, fill output backwards, and jump over precompiled sequences of default transitions between exceptions. Give the census k-context boundaries, exception clocks and restart states by oracle. Charge state count, transition and payload bytes, number of exceptions, useful default stretches, and singleton steps versus 4/8/16-byte phrase steps. Check a complete replay against the independent stable-row oracle on each of the ten physical columns, for k=1,2,3,4,6,8,12,16. Count how many distinct coordinates at every ordinary cut are actually needed to locate just the exception rows. Compare with the all-row reverse and record all uncharged context/clock acquisition work. Retain competing k values when one has fewer exceptions but more state. A test with oracle event coordinates alone cannot establish a performance gain.
