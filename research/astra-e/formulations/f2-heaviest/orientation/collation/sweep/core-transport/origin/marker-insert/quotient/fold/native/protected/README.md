A stock find corresponds to one logical proper token-suffix state of a positive d-return word, including the empty suffix. A suffix has a contracted representative precisely when one of its original rows survives. Each d-reachable row occurs in exactly one such original interval. The number of fully deleted intervals equals the actual rank-query saving on every tiny case and all ten tapes. Of 215,523 removed rows, 67,218 fell in partially deleted states. Even selecting every eligible ID without enforcing compatibility could eliminate at most 7,853 states across ten, only 137 above the observed feasible result.
