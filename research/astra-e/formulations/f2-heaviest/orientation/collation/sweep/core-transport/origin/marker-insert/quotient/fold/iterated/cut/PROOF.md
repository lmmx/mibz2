# Forcing a large contraction with a delimiter set of token types

The heaviest choice is optional. Choose any set T of old source types as simultaneous delimiters. For each old type k outside T refine k into its nonempty destination-bucket subclasses (k,j), ordered by old destination j. In the k source bucket each subclass is contiguous by stability. In the incoming column the destination owner j is known from its ordinal, independently of predecessor k. Thus one ordered overlay of the old R maximal runs and K source buckets computes all needed class pairs and masses. Every old run splits only at an old source bucket boundary, so the refined incoming column has at most R+K−1 records before coalescing. Types in T stay intact.

In the refined column contract every (k,j) with j in T. Each goes entirely to that one unsplit source class. No source is also a target. The number of rows eliminated is exactly the directed transition mass from outside into T. The new spelling is W_k W_j at those occurrences. Distinct aliases may carry the same old spelling by reference. Refining the original marked primary to a singleton once, and requiring its ID to stay outside T, ensures its marked source survives every ensuing pass. Its unique destination lies in exactly one subclass even in a subsequent refinement.

Let E_kj count the mass of transitions from k to j. The incoming and outgoing total masses of every type are equal because the underlying map is a permutation. This balance makes mass entering T exactly equal to mass leaving it for every cut. In the undirected weighted graph with edge weight E_ij+E_ji, ignore self-edges. A fair type coloring cuts half the nonself mass in expectation. Fixing the singleton anchor on one side leaves that expectation unchanged. Conditional expectation in any fixed vertex order finds a cut of at least that weight. Choose the side for each new vertex maximizing the crossing weight to vertices already assigned. The remaining edges have the same expected contribution between the two choices. Therefore **one pass removes at least (m−ΣE_kk)/4 rows**. If the marked singleton is not a fixed point, an off-diagonal edge exists. Row count strictly decreases until the singleton spells its entire marked cycle, even if unrelated cycles remain. Large self-transition mass can weaken the bound; further splitting and grammar work still have to be paid.

Once adjacency is available cut choice can be linear in vertices and nonempty type pairs in a fixed vertex order. An O(K log K) ordering heuristic is optional. A simple reference may sort pair keys to assign alias bases. Building the join costs run intersections, per-class metadata and node publication. Its ordinary RLE can be bounded by R_refined+h for h selected incoming records. Deleting the h selected records leaves at most R_refined−h runs. Stream replacement for any target j increases surviving run count by at most b_j−1, with b_j the run count of its source ancestry stream. This stream is made from the old j source positions, labeled by an incoming selected ID or j. If h_j selected runs land there, b_j≤2h_j+1. Summing gives the bound. The empirical test measures these terms, growth in the alphabet, grammar joins, total scans and output. A favorable contraction factor alone is insufficient evidence for elapsed time.
