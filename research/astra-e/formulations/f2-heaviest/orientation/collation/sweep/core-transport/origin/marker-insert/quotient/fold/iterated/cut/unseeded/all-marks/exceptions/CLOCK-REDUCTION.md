# Sparse exceptional clocks can encode another exact inverse BWT

Fix a context width k and an integer G≥k+2. For a source column L₀ of m arbitrary rows on ordered letters 0,…,s−1, let g(j)=G+s−1−j. Encode a source symbol j in forward order as b followed by g(j) copies of a, where a<b. Longer a runs sort earlier, preserving the source symbol order among b-starting rotations.

The expanded column can be built directly from L₀ without knowing its marked text. For j=0,…,s−1 in that order, take the subsequence of L₀ on letters ≤j; replace j by b and every smaller letter by a. Append a^(Gm) after the s layers. Let n denote the expanded length. The b-starting source ranks are B(x)=n−m+x. For binary input this entire formula reduces to b^(count of zeros), a copy of the original binary column with 0→a and 1→b, then a^(Gm).

**Exact return, including heterogeneous columns.** Besides the m b ranks, group all other source ranks by the number r of remaining a bytes up to the next b, larger r first. Within a layer use the original rank x whose b rank follows this a run; x occurs in that layer exactly when g(L₀[x])≥r. These ranks have the claimed lexicographic order. Equivalently the stable LF can be checked directly: LF from B(x) reaches the r=1 row indexed by x. At an interior r<g(L₀[x]), the preceding byte is a; these occurrences are ordered by x and match the next layer's entries. At r=g(L₀[x]) its preceding byte is b. In the whole column, these terminating b inputs occur in order of the old byte L₀[x], then of x. Their stable targets are therefore exactly B(LF₀(x)). This proves the induced permutation on the b ranks pointwise, including ties between repeated rotations and all disconnected source cycles. The distance of the backward return is g(L₀[x])+1. Each expanded physical row belongs to one such path.

**Exception ordering.** Every context containing b has only a predecessors; the code spacing exceeds k+1. All b predecessors occur in the all-a context. This context has sum_i (g(i)−k+1) occurrences over the m source symbols, at least 3m when k≥1, so a wins strictly. For k=0 the same majority follows from the total a count. Every default is a. All m exceptional physical rows emit b, and for k≥1 lead to the same poststate b a^(k−1). Starting at B(p), the first backward exception occurs at time g(L₀[p]) and subsequent b-to-b differences are the old symbol's g-value plus one. The backward clock on a full expanded marked lap therefore spells the entire old marked lap. For a primitive source and N=n, the initial backward context is that of B(p) and the expanded path is one lap. Arbitrarily large G sends the exceptional density to zero while leaving the arbitrary input inversion of m source rows inside clock acquisition.

For fixed positive source counts at prime m, every nonconstant source word is primitive. Mark its lexicographically first row p=0. There are m!/(m product_j m_j!) such necklaces. Their encodings have identical n, m, marked b rank B(0), entry state, modal arcs, exception-byte sequence, post-exception state sequence and complete cyclic (k+1)-spectrum. Nevertheless their ordered clock sequences must distinguish the source necklaces. Balanced binary counts alone require m−O(log m) bits of distinction. More generally balanced s-ary counts cost m log₂s−O(s log m) bits. The difference is temporal; the exceptional physical LF columns vary between sources and contain the information. The reduction gives a computational subproblem and a conditional information requirement, not a hardware time lower bound or a claim that every clock needs a full dense walk.

The historical Astra 1 uniqueness threshold concerns recovery from a substring spectrum and, separately, structural refinement of an interval forest. This reduction supplies an explicit family with matching spectra and controls exactly which additional marked clock data reconstructs the old source.
