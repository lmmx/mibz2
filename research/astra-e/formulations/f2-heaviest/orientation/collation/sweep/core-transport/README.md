# Transport an untyped core alphabet between different sections

A return W from an old source s∈U is split into a prefix P and a **positive** core C. Let z=Ψ^|P|(s), and let V consist of these cut positions, one per original arc. The old section U is one rank interval. V can have arbitrarily many components and the source prefixes can all differ. The objective here is to construct the old marked permutation from the core names alone during backward discovery. The prefix atlas is consulted only after the incoming core column is ready.

**Two-section collation.** For any set of starting ranks V that reaches an interval U, define each word to end at its first *positive* hit of U. The sources of each distinct word C form one bucket in the sorted order of V. Their destinations increase with source order. For two sources with the same C, all intermediate starting ranks share that byte prefix. Ψ along a common prefix is strictly increasing and cannot shrink rank gaps. At the end the two destinations are within |U|−1 ranks. At any strictly interior time, the endpoints lie outside U and cannot be on opposite sides, since that would require a gap greater than |U|−1. Hence every intermediate starting rank with membership in V also has its first positive hit after exactly C. No convexity of V is needed.

A constructor may retain the minimum physical V rank and number of occurrences of each core. Ordering by these minima gives the core alphabet. Alternatively, append the forward itinerary of any fixed q∈U to every C and sort the infinite keys. In the only ambiguous case one core is a prefix of another. After their common part the shorter has landed inside U and the longer is outside. The [common-tail comparator](../../) and its finite rank tie break therefore apply with q in the *landing* section. All forty real cases verified this order independently.

**Stable core transport.** Backward discovery from U emits just the RLE of C at each destination. In particular it never binds a terminal to a particular P, full word, original source, or next prefix. Starting at the beginning of each core's ordered V bucket, take the next width entries each time that core occurs in the incoming run stream. Stability assigns those entries to exactly their original destinations in U. The source-prefix atlas maps each interval of V ordinals back to consecutive original sources and gives their common P. Intersect the current V slice with those atlas bands. Each intersection is an original inverse-return translation on consecutive ranks, carrying one (P,C) spelling pair. A single merge initializes the per-core cursors. The band sweep costs O(K+R_c+B) for K cores, R_c destination core runs and B source-atlas bands, once core bucket order and incoming runs are supplied.

**Exactly one emitted band per maximal original token run.** Assume equal W receives the same cut depth, as for min(h,|W|−1). If adjacent destination ranks are labelled by the same W, their old sources are consecutive in its contiguous old U source bucket. Over the shared forward spelling W their rank gap starts and ends at one. The nondecreasing-gap property forces it to remain one at every step. Their source prefix atlas could never have split: during that prefix they have adjacent source and image ranks under the same symbol, hence occupy the same original maximal select run, and identical early-return status. Their cores and their physical V cut ranks are consecutive as well. The transport cannot split this adjacent equal pair. Conversely a transport intersection has a fixed P,C pair and therefore a single W. The emitted translations are exactly the maximal original token runs. This identifies B≤R_full≤R_c+B−1, a sharper bound on the terminal atlas than the original r+2 bound whenever the induced column has few runs.

The reference builds the untyped backward trie from original LF runs and boolean V membership. It composes the transport as described, sorts the resulting bands in source order and navigates the marked output by interval lookup. It never allocates an m-entry dense residual permutation or a separate full-word dictionary in its construction. The independent dense oracle used for assertions is outside the constructor. Sorting the reference's bands and binary-searching each emitted word still cost time. Existing second-stage implementations can instead consume the recovered full-token run stream, with their own storage and spelling costs.

Exhaustive comparison covered 22,520 objects, 145,448 marked outputs and 3,976 cases where distinct original words shared one core. On the ten real frequent sections all source partners, full and core word orders and primary outputs agreed for h=0,4,8,12, with the short-safe cap. The original 66,373 destination runs were emitted exactly once at every depth. At depth twelve the backward constructor handled 56,673 incoming core runs, the atlas had 42,024 terminal bands, and all 66,373 original translations were recovered by the single sweep. This is a representation and construction result; its throughput requires a native matched comparison.
