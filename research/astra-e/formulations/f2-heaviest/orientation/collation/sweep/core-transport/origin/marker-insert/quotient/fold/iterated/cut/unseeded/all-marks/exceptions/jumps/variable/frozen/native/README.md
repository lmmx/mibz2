# Complete marked inverse using frozen training patterns

The model trained once on corpus block 1 is compiled into shared read-only arrays. A word encodes its suffix parent and prepended byte in one u32. The three tables have 30,740, 12,879 and 6,527 entries. At each target call the native implementation consumes the actual cap-127 records, merges adjacent labels, builds per-byte occurrence-run indexes, projects every dictionary level, computes the component-specific modal predecessors, builds the complete physical jump index, and emits into the returned byte buffer. The native emitter handles marked nondivisor laps. The compared scalar, Lazy and Open instances are the unchanged Rust controls from the earlier capped-input panels. No target state, exception clock, physical index or output is carried across calls. Twenty-four balanced rounds produced 1,440 timed calls across all ten original inputs. The raw Rust timer includes native destruction of per-call scratch. Four consecutive six-round complete placements provide the independent units for the interval reported here (Student t with three degrees of freedom). The prespecified nine held-out targets exclude block 1. The wall and high-concurrency objective has a different denominator from these single-thread inverse CPU ratios.

The modal table has a real cost tradeoff: decreasing training dictionary size reduces physical projection cost and raises cost in the remaining rank lookup and exception walk. Even the fastest complete implementation in this experiment takes over four times scalar. The three thresholds failed the preregistered advance screen. The ratios give no target i9 wall claim. CPU4 was pinned; CPU0 and CPU2 had independently managed native research work. Hardware instruction/cache events were unavailable in this panel.
