# Invert the atlas into output coordinates without producing any concatenation grammar

Test whether forward cuts need only type lengths and old-to-new affine transport, then backpropagate the final one-row offset by contiguous range copies with a uniform addition. At depth zero scatter original bytes directly to cyclic output positions relative to the primary. This eliminates grammar-node construction, spelling ownership and grammar expansion. Charge all temporary arrays, every forward descriptor, reverse words read/written, random output byte scatters and the primitive/zero-power admission test. First reconstruct the frozen block and all ten original columns, check both each source offset and every independent libbzip2 output/CRC. Preserve a counterexample to the one-vertex admission and fallback conditions. The cap-budget result for earlier first-cut constructors still applies to any version retaining those costs.
