# Exact core recognition in the original rank space

A bounded backward search on original runs can find every original source contributing to a given shortened core, and can certify the most frequent core, without constructing the forward atlas or any first token column. The original and physical second words have a precise rotation relation whenever the selected sources share one prefix. This accounts for the otherwise surprising equality of the second dictionary byte counts on all ten frequent sections. [Algorithm](origin.py) · [Full first-hit interval primitive](../audit/)

Let Z(C) be the interval of all ranks whose first positive return to U spells C. Every position in Z(C) belongs to exactly one arc between consecutive visits to U, including an old source when its entire word is C. It lies exactly |C| bytes before that arc's destination. This gives the identity |Z(C)| = Σ f(W) over old words W ending in C, where f is original word frequency. Distinct old occurrences have disjoint arcs. A cycle disjoint from U cannot supply such a row.

For the cut at min(h,|W|−1), a core C of length greater than one occurs precisely when W ends in C and |W|=h+|C|. For a one-byte C the length condition becomes |W|≤h+1. Starting at Z(C), extend backwards through all original LF children for at most h steps, clipping U before each extension. At depth d, the intersection with U is the exact old source interval of the corresponding W=P·C. Accept it at d=h, or at any d for one-byte C. Children can be generated by grouping the clipped interval's original L runs by symbol. A path that has already touched U cannot be extended as part of the same old word. This exactly recovers every original source and its prefix, in separate intervals if necessary. The intervals at one extension depth are disjoint and have total width at most |Z(C)|, giving at most h·|Z(C)| scanned run pieces for a supplied C, beyond recognizing its endpoints. Recording literal prefix copies, heap entries, index construction and later reconstruction cost additional work.

A best-first search across C certifies the mode. For a fixed preceding spelling, its sources inject into Z(C), so every longer suffix descendant has frequency at most |Z(C)|. The implementation also bounds extensions by the mass outside U. On the sixty real cases its complete winners, tie counts, selected masses and physical component counts agree with the independently produced forward-atlas result. [Small exhaustive tests](small.json) · [All real source cohorts](wikidata.csv) · [Independent atlas method](../audit/panel.csv)

If every selected source has the same prefix P, advancing them all by |P| preserves source order. An old second word travels from one selected old source to the next and has form P·Y. The corresponding physical second word is Y·P. Both have the same length and frequency, and the map is injective on old words since the known P restores them. Their compressed marked permutations are identical up to this uniform shift and the corresponding change of byte offset. All 31,358 second partners and their word rotations passed at each of h4, h8 and h12 on the ten frequent sections. They gave exactly 5,525,525 distinct second spelling bytes at each depth. The quote selections used 137, 804 and 5,231 different originating prefix bins across the ten blocks at those depths. A common-originating-prefix explanation does not apply to these cases. Two of the small tests exhibit fragmented physical sources even when every originating prefix agrees. [Native second-stage diagnostic](../two-section/native/)

## Pricing a dictionary certificate

Suppose the frequencies of a few old words and their source intervals are already certified. For a suffix C, remove all their contributing occurrences from |Z(C)| to get an upper bound u on unknown occurrences. Add back only known words whose actual shortened core equals C to bound its own frequency. For the subtree add back every known word whose shortened core ends in C. For strict descendants, omit those with core exactly C. The monotone known-word ranking uses the original first-hit search and is charged. Any bounded extension interval whose whole mass is explained by known words can dispense its eligible old origins immediately. This certificate is exact even when multiple shortened cores tie and the compressed input has multiple cycles. [Pre-data test](certificate-plan.md) · [Implementation](certificates.py)

At frequent h8 the original uncertified backward search scanned 353,224 run pieces across ten blocks. The 1-, 4- and 16-word certificate searches including old-word discovery scanned 364,627, 366,797 and 269,784. The earlier forward-atlas and masked mode selection used 124,632 forward intersections plus backward run pieces. None of the three certificate budgets passed the preregistered size gate on any frequent tape. Certification reduces the cost of some backward probes but cannot justify a paid native mode finder on this path. At quote h8 the uncertified backward mode required only 114,966 pieces versus 272,122 for atlas intersections and masked search together. These are different primitive costs. All 67,560 small budget/section/depth cases and all 180 real captures matched independent exact modes and source intervals. The Python certificate also stored 93,724 bytes of suffix keys for the sixteen-word frequent panel. [Raw certificate observations](known-wikidata.csv) · [Small tests](known-small.json)

A decoder choosing a *fixed* positive first-hit spelling requires no mode search for correctness. It can locate Z(C) by two endpoint queries per byte. Using Z(C) as an entirely new section requires its own mark and returns. Using the exact former physical section H additionally requires excluding every unselected position in Z(C). A real mark can hit one of these holes before any member of H. [Marked counterexample](../audit/)
