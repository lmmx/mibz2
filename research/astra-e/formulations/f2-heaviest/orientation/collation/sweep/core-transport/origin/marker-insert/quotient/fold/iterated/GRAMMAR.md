# Exact marked reconstruction by repeated whole-class absorption

Each nonempty round removes at least one row. It preserves the weighted sum Σ f(k)|W_k|, because every removed successor contributes its old spelling to exactly one surviving source. An intermediate dictionary with one spelling per positive-frequency ID therefore has at most the original total byte mass. Rebuilding that dictionary at every round can repeatedly copy the same bytes. Instead assign an immutable concatenation node (old k, old g(k)) per chosen ID and keep the current spelling node of each surviving ID. The new nodes point into an older generation. An old dictionary can serve as leaves. Size is at most K₀+Σ|D_i| nodes, with lengths and two references per internal node, independent of copied byte lengths. At any stopping point expand one whole remaining orbit from its marked token, using the stored byte offset on its first word and the requested original horizon. With a single remaining row, no residual permutation or second token dictionary is required. Unbalanced grammar depth calls for an iterative stack. Output work and scratch must be measured.

**Singleton anchor theorem.** In a finite marked weighted permutation, a source ID A of frequency one can absorb its successor whenever the marked A vertex is not a fixed point. Its single destination belongs to one other source class. A remains present with multiplicity one, the marked start retains its place in the concatenation, and its orbit loses exactly one vertex. Repeating reaches a self-loop spelling the entire original orbit. This argument covers each nonprimitive or disjoint-cycle input by using the marked orbit and repeating its spelling to the byte horizon. It does not require every other remaining row to lie in that orbit. If the original marked source has a repeated ID, split that source bucket at its marked ordinal into a left range, one singleton and a right range, dropping empty sides. At destinations, partition the old ID's stream by occurrence rank at the same two positions. This creates a stable token column in one run scan with at most two additional RLE records and at most two extra IDs. It preserves every edge, byte, source order and mark. Thus every marked weighted input admits identification plus folding to an exact *one-word representation of its marked cycle*. Always choosing the anchor can take one round per old orbit vertex; existence supplies no speed bound. A native implementation must charge how it locates, forms and emits the useful contractions.

There is also a schedule guarantee if the marked singleton A is reserved as a survivor. Never allow a chosen class to target A. If A is not yet a self-loop, include A in some future round; it is always legal alone. Any maximal-cardinality or maximum-positive-weight compatible selection from these eligible IDs makes progress while A is not a self-loop. There are only finitely many vertices. The final A spelling therefore covers its entire original marked cycle. This does not assert that arbitrary schedulers preserving a particular A reach it in logarithmically many rounds.

## Exact marked oracle and output ownership

The protected implementation reproduced every requested byte on 40,341 marked weighted small cases, including 34,239 marks on an orbit with other rows outside it and 26,486 nondividing byte horizons. Its result can stop with other components present. On all ten quote tapes the complete marked word consumed the whole input and the final system happened to have only one row. The protected grammar created 470,938 initial and concatenation nodes in total. Its 1,484,391 cumulative old input runs were close to the unrestricted schedule's 1,484,250. The number of rounds ranged from 61 to 255 per tape.

A complete first copy of an internal grammar word records its output range. Later requests for that node copy the desired subrange from already-emitted bytes. Requests covering only part of a node do not register it as a full occurrence. The two ends of a marked rotation can then be clipped at any offset. In the reference extractor 1,980,569 of 8,999,915 bytes came directly from old leaves and 7,019,346 from earlier output. It processed 872,393 node requests and used at most 510 explicit stack entries on a single tape. These are structural counts for a Python immutable-node oracle. The native implementation with plain iterative expansion has its own measured storage and throughput.
