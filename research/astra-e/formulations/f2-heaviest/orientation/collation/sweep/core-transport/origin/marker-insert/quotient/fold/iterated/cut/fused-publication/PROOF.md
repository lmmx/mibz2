# A source-bucket cursor replaces each ancestry stream

Let the old weighted stable token column be L and its forward permutation P. Write C[k] for the start of source class k and S(x) for the class containing source rank x. At destination p with incoming label k=L[p], the unique predecessor is

    x = C[k] + rank_k(L[0:p]).

The old graph chooser designates target colors T. Refine each outside source k by the destination bucket j=S(P(x)) in increasing j order, and let A(k,j) be the resulting outside alias. A target bucket k remains a single ID k′ if it retains any rows. The cut bypasses each outside-to-target edge x→y by deleting the destination y. The cut never deletes two adjacent vertices because the predecessor of a deleted row is outside, while the deleted row is inside. The produced incoming RLE is in original destination order with deleted rows omitted.

There are three publication cases at old destination p with source label k.

1. If k is outside and S(p) is a target, p itself is deleted. Skip it.
2. If k is outside and S(p) is outside, its predecessor survives and has outgoing class A(k,S(p)). Emit that ID.
3. If k is a target, p survives. Let u=L[x], the incoming label at its unique old predecessor. When u is outside, x has been deleted and the bypass starts in alias A(u,k). Emit A(u,k). When u is a target, x survived and the output label is k′. In the latter case k′ necessarily exists because x is a surviving row in k's own source interval.

For fixed target k, x takes values C[k], C[k]+1, ... as old occurrences of k are consumed. One suspended cursor into that old contiguous bucket supplies u directly. Secondary ranges for different k are disjoint. If k has no outside predecessor, every outgoing label of k remains k′ and the secondary read is unnecessary. Coalescing equal emitted IDs constructs exactly the old two-hop contraction on the sorted survivor ranks. With H old joint slices, the outer stream visits at most H slices. Across each target the aligned secondary cuts have at most its outer occurrence pieces plus its bucket pieces minus one. Thus secondary chunks over all targets are at most H plus the number of old slices in queried buckets. The fused writer can reread those source ranges, even though it publishes output once. It does not build a new incoming alias stream or a target ancestry stream.

## Three choices of rank information

* The graph-backed slice variant uses each old slice's pre-color ordinal among the distinct neighbors of its old source k. Because every outside alias survives with positive old outgoing count, its final ID is first[k]+ordinal, independent of its new weight spelling. Target classes with zero remaining mass are omitted when computing first. The chosen graph supplies each join and its canonical rank before publication.
* The raw-RLE variant avoids even materializing the H old slices. Its chooser accumulates old transition pairs in increasing destination order for each source and records the original run containing each bucket start. The outer cursor over k outside advances monotonically in k’s old neighbor list. A suspended target cursor that encounters u outside binary-searches u’s retained list for neighbor k and obtains the immutable ordinal. It pays for this directory and the lookup; no per-row or per-slice alias labels are allocated.
* The graph-free chooser already constructs H original input slices and visits them in source-bucket order to choose colors. It can place the old ordinal in the existing slice field when first constructing the slices, before the colors exist. It keeps the original bucket starts, source degrees and per-target ingress counts. Once colors are known the writer assigns each source's final rank interval and keeps only used-width counters beside the old starts. A secondary emission of A(u,k) temporarily records the join's right target k **in that alias's final dictionary slot**. Every joined alias has positive source mass and occurs in the resulting stable column, so all necessary slots are filled. A single source-order pass over those output word slots installs final handles and appends grammar nodes in exactly donor order. Empty slots retain the old source word. All donors and fusions therefore use identical numeric grammar IDs and marked IDs, including after subsequent power passes. ## What still needs global information

The first rank interval of each old source depends on frequencies of preceding classes and on whole target buckets that disappear. The start of a queried target bucket depends on global cumulative old frequencies. Seen counts or cursors for suspended targets distinguish their current source ordinal. The bucket lookup is a genuine data dependency. With one row each of types 0,1,2 and T={2}, the old incoming columns [2,0,1] and [2,1,0] have the same frequencies, colors and first incoming label. Their first new incoming labels are A(1,2) and A(0,2), respectively, determined by the third old input position. A strictly forward consumer given only that common prefix cannot know which to emit. Access to the old source range, an equivalent precomputed map, or deferred output can supply it. This argument does not give a lower bound on the size of an ancestry table.

A protected singleton old mark q outside T survives every pass. It has exactly one outgoing neighbor subclass and its marked ID is first[q]. Its byte offset stays unchanged. More generally a surviving row p has new rank p minus the number of earlier deleted destinations. When p itself is deleted, its old outside predecessor x=C[u]+rank_u(L[0:p]) acquires the mark with the length of its old spelling added to the offset. The preceding deletion count at x consists entirely of deletions in lower old source buckets, since u is outside. The checks exercise general marked rows. The native decoder uses the donor’s one-time protected singleton split, and preserves the separate interval power normalization exactly.
