# Sharp worst-case number of monotone cursors

Let a given source bucket receive N disjoint query intervals in their required processing order. The order of their distinct starts is a permutation. One forward or reverse cursor can serve any monotone subsequence. With the complete query schedule supplied free, the worst-case minimum number of independently directed cursors is **the largest k with k(k+1)/2 ≤ N**. The bound holds for every ordering of the search trie. It is also attained by a primitive BWT over four token symbols whose actual heaviest choice is the delimiter.

Write Tₖ=k(k+1)/2. For a permutation of N<Tₖ₊₁ elements, let h be its longest increasing subsequence. If h≤k, partition into at most k decreasing subsequences by the length of the longest increasing subsequence ending at each element. Two elements in chronological order with the same such length must be strictly decreasing. If h>k, remove one increasing subsequence of at least k+1 elements. The remaining length is below Tₖ and induction covers it with at most k−1 cursors. This gives a constructive k-cursor assignment for offline rank requests.

For a sharp example, concatenate k decreasing blocks of lengths k,k−1,…,1, using strictly larger values in every succeeding block. A decreasing cursor touches only one block. With a such cursors, one of the largest a+1 blocks necessarily receives no decreasing cursor and has length at least k−a. Each increasing cursor can cover only one member of this block, requiring at least k−a additional cursors. This holds for every 0≤a<k; if a≥k the bound already follows. Retaining this pattern as a subsequence realizes the same lower bound at all lengths N from Tₖ through Tₖ₊₁−1.

Any permutation π of N source queries can arise on a single parent chain in a real marked token BWT. Use the fixed alphabet d<c<a<b. Encode each rank in π by a distinct fixed-length, lexicographically ordered binary string over a,b. Form the cyclic text consisting of a long d run and the N phrases c·code(πⱼ), written in reverse j order. Make the d run longer than the entire phrase payload. There is just one maximal d run and d is the unique heaviest symbol. The initial d-bucket has one nonterminal singleton child, and the entire phrase payload is visited in backwards text order on that single chain. The source order of the c positions is precisely the lexicographic order of their distinct following codes. Thus the required c ordinals are π. This construction need not have four *BWT runs*. The separate four-run arithmetic family attains the same square-root growth with a sharper q-cursor optimum on that restricted family.

The bound is about the number of cursors with perfect future knowledge. Constructing the itinerary, assigning lanes, and storing or predicting future ranks can consume the work the decoder aimed to avoid. The verifier constructs covers and independently computes the optimum by exhaustive subset dynamic programming on all permutations through N=7. It realizes the triangular extremal cases through 105 c queries by sorting actual rotations, deriving the integer LF column, and checking every required query and parent.
