# A signed displacement-level cut with implicit survivor coordinates

Let T be the exact physical LF permutation. Put j(x)=v₂(|T(x)−x|) for every nonfixed row x, and use a constant color on fixed points. Give x the color bitⱼ₍ₓ₎(x) xor pⱼ₍ₓ₎. Write N for the number of nonfixed rows and E for the number of nonfixed edges whose two endpoints have the same level. A nonfixed point cannot enter a fixed point in a permutation. If the levels on a transition are equal to j, adding T(x)−x always flips bit j. If they differ, choosing level phases independently and uniformly gives crossing probability 1/2. Expected total crossing is (N+E)/2. On every cycle the numbers of zero-to-one and one-to-zero crossings agree. Hence removing the zero-to-one source rows contracts at least (N+E)/4 rows for some phase choice. The removed set contains no two consecutive states. Complement every color globally if necessary so the supplied primary has color one. This protects **any** primary without paying a one-row correction or changing the number removed. The marked cycle can be shorter than n. This population bound concerns all physical rows.

For each observed unordered pair of distinct levels i,j record its mass A and its raw unequal-bit mass D. Equal phase choices contribute D crossing edges; opposite phases contribute A−D. The diagonal contributes its full mass. Assign the levels in ascending order, choosing the best crossing to already assigned levels and breaking ties toward zero. This is conditional expectation because unassigned phases still make every incident off-diagonal edge cross with probability 1/2. A separable upper bound on twice any attainable contraction is the sum of max(D,A−D) over all pairs, including the diagonal. An exact offline Gray-code search fixes the smallest active level to phase zero and visits the 2^(K−1) assignments on K actual levels. It updates just the flipped level's neighbors. This exponential step is optional and is charged separately from the linear greedy construction. For ordinary bzip2 blocks K≤20.

The guarantee is sharp for a realizable primitive column. On L=(1,0,1,0), LF is the cycle 0→2→3→1→0. Its levels alternate between 1 and 0. The two possible relative phases each give two crossing edges and one removed source. Thus even the best eligible phase vector attains exactly N/4.

## Linear overlay and exact coordinates

For each affine L-run intersect its image with the physical L-run partition. The images tile the target, hence the total number of nonempty intersections is at most 2R−1 for R runs. Within one tile, x and y=T(x) have constant levels j and l, and y−x is constant.

- If j=l, the raw bits always differ. The removed sources use one specified bit of x.
- If j<l, use coordinate y. The two relevant raw bits are 1−bitⱼ(y) and bitₗ(y).
- If j>l, use coordinate x. Adding a multiple of 2ʲ leaves bitₗ unchanged, so both tests use x.

Consequently the hole predicate on a tile is a conjunction of at most two unshifted coordinate bits. For low bit a and high bit b, a block of 2^(b+1) positions contains exactly 2^(b−1) choices of either specified pair. Its matching high half starts on a full low-period boundary. A clipped prefix requires only counting the requested low bit in the part of that half it covers. Subtract two prefix counts for an arbitrary interval. This proves the constant-time two-bit histogram and rank formulas without iterating physical rows. The imbalance |2D−A| of an off-diagonal tile is at most twice 2^min(j,l), since an aligned full low period balances exactly and each clipped end has imbalance at most 2^min(j,l).

Original LF images for each byte arrive in increasing order. A source-run cursor per active byte can be initialized at each F bucket in a single sweep and advanced only over that bucket. During the tile sweep bin weighted observations by higher level, then collect each lower level in reusable storage resetting only touched bins. The signed graph and exact greedy bound use O(R+σ+w) word operations and space for alphabet size σ and w possible bit levels, including all input-dependent tiles. With fixed byte alphabet and machine word size this is O(R). A general affine exchange can use its already sorted image order to perform the same overlay; an unordered image index needs to be built or sorted.

The complement predicate admits exact survivor select. For a two-bit tile with high half-length H=2^hi, each complete period has 3H/2 survivors. In the nonmatching high half every coordinate survives. In the matching high half insert the opposite prescribed low bit into the remaining ordinal. This handles marked global color reversal in the same formula. Offset truncated tiles by their preexisting prefix survivor count. Store cumulative survivor counts and tile source ends. A binary search locates the required tile and arithmetic recovers the physical row from its compact ordinal. The inverse rank uses the same counts. With this implicit representation an exact contracted step needs either one or two T steps and one or two original spelling handles. The representation has O(R) tile records and O(log R) search cost per physical lookup, with constant-time local rank/select. Materializing the resulting affine column is a different cost. Recursively querying many implicit layers can multiply per-query work; the first-layer construction alone provides no bound establishing competitive whole decoding. ## A two-run input whose entire normalized exchange becomes singletons

For m=2ʰ≥4 take L=1ᵐ0^(m+1), n=2m+1 and primary 0. T(x)=x+m+1 modulo n is one cycle. The first m rows A have level 0; the last m+1 rows B have level h. With phases equal there are m+2 crossings. With opposite phases there are m crossings. Equal phases therefore achieve the exact optimum. After globally flipping to protect 0 the removed rows are m−1 and the m/2 even ranks m,m+2,…,2m−2.

The 3m/2 retained rows in physical order are 0 through m−2, the odd ranks m+1 through 2m−1, and finally 2m. In A the true first-return words alternate between the one-byte word (1) and two-byte word (1,0). The early odd B ranks m+1+2i send their compact sources to 2i+1, so adjacent source ordinals with the same spelling have different translations. The last odd B row has word (0,1) and row 2m has word (0,0). The A/B seam has different first letters. Thus every surviving row is a separate maximal interval if both its spelling and its unit-slope translation must be constant. Three joint physical tiles suffice for the implicit map. A small original run count and a one-or-two-step contracted orbit do not bound the ordinary interval output size.
