# Whole-interval predecessor paths without rank queries

The source is a true capped last column, primary and context depth. The inclusive constructor coalesces caps, obtains the physical context intervals, intersects them with the actual last-column runs and resolves each intersection's image using one monotonically increasing LF cursor per byte. At a branching context it stores each slice's exclusive right endpoint, physical translation, preceding byte and destination state. The terminal locates the correct slice by scanning tables of up to four entries or binary search in longer tables. This is the complete exceptional and modal transition table for that context.

A context contained in one maximal run sends its entire interval to a subinterval in one destination context by translation. Summing these translations composes a path up to its first branching context. Interval widths along each smooth path are nondecreasing. In a pure cycle all widths agree and each source image fills the entire following interval. Since LF is a permutation, such a cycle has no incoming edges from outside the cycle. Its translations sum to zero. Each physical row returns after exactly the cycle's number of states. The index stores the reversed cycle word once. A marked cycle rotates this stored word to the forward phase at the supplied state and repeats it directly for n bytes.

For a smooth forest component, each parent chooses its smooth child of greatest physical width. Chains are allocated from their heads towards these children. A chain's bytes in increasing array index are exactly the forward output spelling for its backward LF traversal. The choice bounds segments for one path by 1 + floor(log₂ n), since crossing to a parent from a nonchosen child at least doubles interval width. On a complete primitive lap a child-to-parent edge is traversed once for each physical row in the child. Thus keeping the largest child independently minimizes the number of memory copies across all partitions into static disjoint paths.

Each renumbered smooth state retains four 32-bit words and one literal byte. They record the full physical translation and length to the next branch, chain head and parent above the chain. A bounded jump ending partway along a chain can recover the exact resulting state by subtracting its length from the renumbered ordinal. If it ends in a different smooth state, subtracting that state's remaining translation from the starting total gives the true physical displacement just taken. The public group operation therefore preserves both exact physical row and successive state even when a raw horizon truncates it. The emitter uses the independent unit transition to measure a lap only on a nondividing mixed-cycle mark, then repairs the existing suffix to the forward phase.

The fixed context constructor, all temporary state tables and construction of the prepared index are currently supplied for free in the conditional timed comparison. The retained index capacity includes literal words, path/branch/cycle descriptors and all irregular slice records.
