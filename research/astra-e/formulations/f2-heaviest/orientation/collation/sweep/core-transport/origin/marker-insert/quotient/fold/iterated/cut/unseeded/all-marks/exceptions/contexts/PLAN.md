# Direct construction of predecessor defaults and physical exception ranges

Start with the original byte RLE and marked source ordinal. The states at depth k are the nonempty rank intervals of the first k cyclic forward bytes. For each such interval scan its intersections with the original incoming runs. An incoming a contributes one nonempty extension to the next partition. Its width is the a mass in this parent. Append its cumulative right endpoint to a's bucket in parent order. Process only touched histogram entries and pay the per-level alphabet arrays explicitly.

At the requested depth select the most frequent incoming byte with smallest-byte tie. All ranks of an (a,parent) extension go by LF into the same current state. Get that poststate with one monotonically advancing cursor per active byte. Emit a default byte and its poststate for each context, plus physical intervals for every other incoming byte and its true poststate. Coalesce only adjacent intervals whose byte and poststate both agree. Conditional writers can later order these exceptions using independent clock information. No dense row-to-position, LF, rotation enumeration, or ordered clock enters the constructor.

Test a binary model file including boundaries, defaults, poststates, exception starts and ends, and marked initial state. Compare every field against independent pointwise stable LF/Ψ on tiny arbitrary columns, multiple cycles, periodic words and variable marks. On the ten true original byte columns compare the complete native model to the dense oracle and its totals to the separate panel's states, transition edges and exception rows for k=1,2,3,4,6,8,12,16. Record each per-depth overlap, histogram entries touched, cost of exception publication, bytes and hashes. Price each requested k independently from the same original RLE through complete model construction; exclude any oracle work, file IO and ordering of physical ranges. Freeze twelve rotating/reversed passes across all eight k values and ten tapes for standalone median thread CPU, range, and one fresh-process RSS measurement per original tape/k. These are conditional construction prices, with no decoder or target throughput claim.
