# Which marked information the next column can supply directly

Each positive alias frequency in rem is precisely the number of surviving source rows assigned that new ID. Preserving their existing renumbering order gives its exact source prefix sums B′, with one addition per surviving ID. The ordinary mark transport computes x′ before publishing the new incoming column. At the first emitted piece intersecting x′, its ID is therefore L′[x′]. If a piece of width w merges with an existing final RLE cell of width h, offset t maps to raw offset h+t. Later coalescence at the right endpoint changes neither this offset nor the raw-run ordinal.

The prefix implementation resets each retired live rem cell to its compact ID's B′ value. While the emitted column has not yet reached x′, add completed widths to their own counters. The containing piece gives LF′(x′) by adding only its within-piece offset to the counter before that piece. If P is the number of old overlay slices and M the total length in records of the disjoint per-target ancestry maps, at most P+M pieces can be emitted before coalescence. An old slice is advanced monotonically and every interior map boundary is crossed at most once overall. Moreover M≤P. The prefix charge is proportional to the number of actual emitted pieces through x′, which may differ from the number of maximal new RLE cells.

The delayed implementation saves the new raw offset, run index and incoming label a. During the next old-column overlay it adds the widths of earlier raw runs labeled a. No full-column histogram is needed. This can allocate prefix overlay slices on a terminal fixed mark before detecting it. The first input and any normalized column use the original ordinary histogram once. Both representations retain a K′+1 source-base vector until the next round.

If a consumer receives only the new source bases, marked raw index, within-run position and incoming label, completing LF′ may require linear information about the new RLEs. For t≥1, place t binary slots on each side of a fixed central a. Separate all slots with b and include b at the ends. In slot j choose a or c on the left and its opposite on the right. This has 4t+3 unit raw runs. Frequencies of a,b,c are t+1,2t+2,t. Every case has the same marked destination ordinal 2t+1, source b, incoming a and raw offset zero. Its LF rank is exactly the number of a slots on the left. A deterministic algorithm that probes neither slot of pair j cannot distinguish the two completions of that bit. Each probe reveals at most one bit, so at least t probes are necessary in this access model even with random access to both sides. This lower bound is conditional on that small supplied state. Publication can pay earlier (prefix counters), or the compulsory graph overlay can pay later (the one-label sum). The 2,046 finite witnesses and their one-bit neighbors check the formulas.
