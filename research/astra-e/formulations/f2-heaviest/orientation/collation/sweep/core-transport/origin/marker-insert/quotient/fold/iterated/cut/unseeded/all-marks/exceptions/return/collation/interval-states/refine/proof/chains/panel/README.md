## Three counting arguments

1. In a deterministic path with ℓ vertices, the selected set must be a suffix. There are ℓ choices if its terminal is mandatory, otherwise ℓ+1 including the empty choice. Multiplying across paths gives an upper bound once the flexible support constraints are restored. Its log₂ ranges from 79,145.10 to 202,263.79 per block; the frozen value is 83,200.81.
2. Force every terminal. To satisfy each flexible terminal whose support interval still contains no forced seam, process intervals by increasing right endpoint and add that rightmost coordinate if still uncovered. Of 689,591 flexible supports, 600,943 already contained a terminal; 31,653 further points suffice to hit the remaining intervals. Force the deterministic successors of all these points. If the earliest forced vertex on a path is its jth, numbered from the source starting at one, there are j admissible positive suffix lengths. Arbitrary choices in this product all contain the forced set and therefore satisfy every flexible terminal. The product has log₂ from 28,262.23 to 69,379.28 per block (frozen 29,629.73). Its minimum instance on each block already selects many rows, so the next construction gives the separate small-budget guarantee.
3. Start with just the σ−1 mandatory F seams. Identify each flexible terminal z whose support interval contains one such F seam or z itself. Adding any subset of these isolated terminal vertices preserves all constraints. The M qualifying terminals range from 1,476 to 2,456 per block, including 1,550 on frozen. For a budget of B states choose exactly min(B−σ, ⌊M/2⌋) terminals. The binomial coefficient supplies a certified lower bound. The integer bit lengths in the receipt preserve a conservative exponent without floating-point ambiguity. On frozen, the bounds are 2²⁵⁸ at B=128 and 2¹³⁰⁵ at B=512.

The calculations used original donor cap bytes and stable LF, with independent equality of all deterministic incoming arcs at the original L-run interiors. They took no decoder timings. Marked output, compact construction, score optimisation and an i9 comparison are independent obligations.

## Single-translation acceleration

For each deterministic edge z→Ψ(z), its affine image atom is the image under LF of the unique physical L run containing both Ψ(z−1) and Ψ(z). Consecutive edges in the same atom may be advanced by one clipped division using its constant physical displacement. The census walked each path in the required support direction, compared original run IDs, and checked that each observed endpoint was the stated origin plus the streak length times the displacement. **All 8,309,431 original edges on the ten real blocks belonged to singleton bursts.** This sufficient same-atom jump condition elides zero edge lookups. It leaves open summaries combining different atoms. [Real bursts](affine.csv)

For L=1^g 0^(g+1), n=2g+1 and Ψ advances g modulo n. Between its one start and stop the deterministic path alternates image runs, realizing 2g−1 singleton bursts. For L=1 0^(n−1), Ψ advances one modulo n. Every deterministic edge is in the image of the long zero run, producing one burst of n−2 edges. The same native estimator confirmed g=1 through 64 in the first family and n=3 through 127 in the second.
