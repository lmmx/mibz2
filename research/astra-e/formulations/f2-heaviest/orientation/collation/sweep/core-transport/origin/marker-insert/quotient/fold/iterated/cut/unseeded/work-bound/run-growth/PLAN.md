# Can a productive cut always preserve the incoming run count?

Constant or nonincreasing run counts across geometric contraction would bound the entire grammar by O(R log m) productions. Test both orientations of every type cut on small marked BWTs. Distinguish a single prescribed cut from existence of some cut satisfying 4q≥m, and allow searches restricted to single-cycle, zero-self-transition BWTs. Compare one-step worst cases to a general interpolation between bounded run growth and geometric row loss. This asks about all-input complexity of this exact ordered construction.
