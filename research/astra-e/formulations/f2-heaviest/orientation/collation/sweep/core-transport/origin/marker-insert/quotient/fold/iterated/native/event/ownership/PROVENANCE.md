# First complete occurrence on an immutable term grammar

The class-fold grammar has one immutable production per contraction and strictly older children. Its mark supplies a byte offset b inside a length-L terminal spelling. Emit [b,L) then [0,b), followed by repetition and truncation if necessary. For a leaf, copy its requested range from the original named dictionary. For a binary production first encountered only on a partial span, split that span at the saved left length. Such a visit cannot certify a complete source copy. When a complete occurrence is emitted for the first time, its starting byte position becomes the owner of that production for this output. A later full or partial request [i,j) can read the interval [owner+i,owner+j) from the completed prefix. Each output instance initializes one u32 slot per internal production. The all-ones sentinel denotes an unpublished production, with no separate validity array. Leaves have no ownership slots.

Eager publication needs no completion frame. At any instant during depth-first traversal, partially expanded full productions are ancestors. A hit on an unfinished owner would require a descending path of strictly decreasing birth indices that returned to its ancestor. Thus once found by any later request, even in the second marked span, the owned production has finished. Position zero is valid. A fresh output must clear the slots. The source offsets survive capacity growth and the copied intervals are checked by the safe vector API. An auditing build additionally checks that the *whole* earlier occurrence already fits within the written prefix.

The readiness proof and first-occurrence schedule are due to the earlier Cells study. Its destructive rule-operand tags and wrap-around ownership serve a different grammar and memory representation, and its first-visit work was a simulated trace. The first F2d ownership study instead eliminated a first dictionary through symbol discovery. Neither paid for this terminal FIFO event grammar and its clipped internal-node ownership. The independent recent Python reference explicitly installs the owner on a close frame after its full expansion completes. Here the same semantic owner is installed on entry in a side table and the tree traversal order stays unchanged. Real metrics can differ between the global anchor scheduler and natural dense FIFO because they construct different DAGs.
