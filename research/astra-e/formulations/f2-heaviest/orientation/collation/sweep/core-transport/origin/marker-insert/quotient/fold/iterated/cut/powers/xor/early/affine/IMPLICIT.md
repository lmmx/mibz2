# A compressed successor that returns its word without publishing the new exchange

Each old band e has width w, old source x, old image y and label e's word. Keep the positive ordered hits from the selective intersection. For hit j let l_j, h_j be the physical middle endpoints, a_j its zero owner, and P_j the total width of hits strictly earlier in that list. P_0=0. If an owner's hit slice is [f,g), the deleted width d_e is P_g−P_f. A zero owner's compact source width is w, its compact image width w−d_e. A one owner's widths are w−d_e and w. Prefix sums give both owner bases. All words can be returned as either the one old word or the two old words carried by a crossing, so an interned ordinal dictionary is optional. The implementation stores historical rule IDs to compare labels exactly.

For a query at compressed **image** rank v, locate its old image owner e, and let u be its offset from the compact image base. Write S_e for the compact source base. An owner with no hits immediately returns (S_e+u, W_e). For every other owner:

* Color one. The old image survives throughout. Its corresponding middle coordinate in the old source is p=x+u. Binary-search the last hit start ≤p in the owner's slice. If p is in hit j, the true compact predecessor source lies in the complete zero-source band a_j at S_a+p−y_a; the forward word is W_e W_a. Otherwise j earlier hits, counted as an exclusive list index q, precede p, and the result is (S_e+u−(P_q−P_f), W_e).
* Color zero. The old compact image is the complement of hits in the old interval [y,y+w). A hit j begins after l_j−y−(P_j−P_f) retained offsets. Choose q as the first index in the slice with l_j−P_j > y+u−P_f (or g if absent). All hits in [f,q) precede the selected old offset, including adjacent hits sharing the compact boundary. The zero source is complete, so return (S_e+u+P_q−P_f, W_e).

The sequence l_j−P_j is nondecreasing since hit intervals are disjoint. Both tests use standard upper-bound queries in contiguous ranges on one global list. The formulas give the old affine source and the emitted word for every compact row. Binary search among surviving image-owner starts and within its hit slice gives arbitrary access without a residual row table or either new canonical tiling. Mark movement remains subtraction of deleted width below the protected original rank. Old bands, compact owner bases and O(J) shared hit metadata remain live.
