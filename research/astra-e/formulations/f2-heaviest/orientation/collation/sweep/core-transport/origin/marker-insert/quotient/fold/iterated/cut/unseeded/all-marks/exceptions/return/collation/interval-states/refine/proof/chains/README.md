# Compress jointly admissible predictor cuts to mandatory gap paths

Consider the entire family of additions to an arbitrary old physical partition P which never subdivide an old (byte,old target) bin inside a new source state. Among them maximize S(Q)−λ times the number of added seams, with λ≥0. R is the number of maximal original L runs and C=|P|. The endpoints of Q include all old seams. This is a global optimization within the jointly histogram-neutral family. Other partitions can also increase the number of hits. [Underlying equivalence](../README.md)

## Exactly R−1 mandatory paths before protecting old seams

For an interior target gap z at an F-byte boundary, adding it needs no witness. Otherwise a source cut must separate u=Ψ(z−1) and v=Ψ(z), where u<v by stable ordering in their common F bucket. Its allowed witness interval is [u+1,v], both ends included. If v=u+1, add a directed mandatory arc z→v. The map is injective. Every original pair of adjacent equal L bytes at rows v−1,v supplies exactly one such arc, since LF(v)=LF(v−1)+1. There are n−R arcs on n−1 vertices. Every component is a simple path or a directed cycle. The exact number of paths, counting isolated vertices, is R−1 on every column. The path starts are precisely the interior original L-run boundaries, which have indegree zero. The path ends are the interior LF-image-run boundaries, of which σ−1 are F seams and R−σ have a nonsingleton witness interval, with σ the number of used bytes.

Drop the outgoing mandatory arc of every inherited old seam; its presence is already authorized. Dropping h such arcs gives exactly R−1+h paths, at most R+C−2. On each resulting path Q's selected seams must be a suffix. If its terminal is an inherited seam, include a nonempty suffix. Any remaining cycle must be selected whole or left empty. At a selected terminal which is neither inherited nor an F seam, require at least one selected or inherited seam in its inclusive interval [u+1,v]. These constraints are jointly necessary and sufficient. They are exactly the support condition for each newly added cut, including mutually supporting endpoints. A physical path is generally out of rank order, so determining whether some chosen suffix crosses a numeric witness interval is a real part of the optimization.

## Recover the paths directly from the original run starts

Sort the original runs by byte, retaining their physical order within each byte, to obtain the LF-image tiling. In the interior of a target run, the mandatory successor is a single translation from its image start back to its source start. At the border between two same-byte image runs the inclusive support interval starts at the exclusive source end of the first run and ends at the source start of the second run. This geometry requires O(R) storage and O(R+256) construction using byte buckets. The reference uses a comparison sort. A static predecessor lookup in the image tiling retrieves a gap action in O(log(R+1)) time. The path starts after protecting P consist of the R−1 original physical run seams plus the successors of every removed arc. Enumerating from these starts visits every resulting path vertex exactly once and never enters an intact cycle.

Equivalently, let D be all original source run starts, including 0. For each d in D, take its positive LF first return to D. Its image starting at LF(d) and ending at the return is precisely one of the paths **in reverse order**, except for the trivial list [0] when LF(d)=0. Before the return, all nonendpoint source gaps are in the interior of a single L run and hence have their mandatory inverse. There is a bijection between the R−1 ordinary paths and the nontrivial-in-this-sense return records; a positive-coordinate one-vertex list is retained. This identity gives an exact original-run section for obtaining path lengths and endpoint pairing. Publishing Q still requires the actual numeric coordinates of its selected suffixes.

A long stay inside one affine image run can be represented by one clipped arithmetic progression. It can still take one run lookup per edge. For L=1ᵍ0ᵍ⁺¹, n=2g+1, LF is a primitive rotation by −g. The single path begins g,2g,g−1,2g−1,…,1,g+1. Its edges alternate between the two image runs. This rules out a general low operation count from consecutive-in-one-run batching alone. The modular description is cheap on this specific family.

## Exact handling of periodic and heterogeneous rotations

Give each row its infinite F,Ψ future. These periodic words are sorted in physical order by stability. For example iterating the stable one-byte sort shows the order is valid for every finite prefix, hence for the infinite words. Rows sharing one infinite word form a contiguous *fiber*. Its predecessor byte is uniquely determined by the primitive period, even if the column contains several disjoint necklaces. Thus LF maps each entire fiber increasingly onto the entire fiber of its preceding rotation, with the inverse Ψ establishing surjectivity. In one primitive necklace, the t distinct phase fibers all have a common width g, and both maps preserve the within-fiber offset. In particular its physical row cycles have length t even when g>1.

For j=1,…,g−1, the jth interior gap in every phase fiber forms one mandatory cycle of length t. Conversely a mandatory cycle keeps its adjacent physical rotations adjacent with equal first byte under all Ψ steps. They have identical infinite futures. These are all the cycles. The remaining base path vertices are exactly the boundaries separating distinct futures. If d is the total number of these distinct rotations, the base paths visit d−1 vertices; the R original-run returns above take a total of d physical steps. Each necklace has a run start on its lowest lane. Otherwise each row on that cycle would be positive and have the same L byte as the row immediately below it. Applying LF to those preceding ranks would preserve the adjacency for a whole cycle and give identical periodic futures, contradicting minimal physical rank within the fiber. Since the lowest lanes are disjoint and there are R run starts, there are at most R distinct necklaces.

To find the fibers without enumerating cycles, collect the base path coordinates, sort them, add 0 and n, and take the intervals between them. Apply Ψ to each lower endpoint. This permutes the fibers in their phase cycles and their widths give g. With no cuts inside fibers this needs space O(d+R), plus the cost of sorting or indexing those d coordinates. If the old cuts touch sᵢ distinct interior offsets in necklace i, their broken mandatory paths add tᵢsᵢ vertices. Thus the total path-row population after protecting P is d−1+Σ tᵢsᵢ. It can be much smaller than n, but a primitive input has d=n. The complete all-cycle classification does not require a marked row. The original decoder's marked stopping horizon and CRC obligations still apply downstream.

## Four offset choices per slab suffice for an optimum

An old cut inside any fiber of a necklace makes its offset *special throughout that necklace*. Divide the offset line [0,g] at all such special offsets. In the open integer range a,…,b between two consecutive special levels or sentinels, every chosen seam is an intact cycle: choosing offset j adds a physical cut in every phase fiber. No inherited cut or mandatory-path choice occurs in that range. The old vote (L[x],state_P(LF(x))) is constant there in each individual fiber; LF transfers offsets unchanged and every internal old boundary was made special. The constant vote can differ between phase fibers.

A nonsingleton witness interval has endpoints at fiber boundaries since it starts and ends at original run endpoints. If it contains any strictly interior offset of one fiber, it contains them all. Which offsets of a nonempty slab subset were selected therefore has no effect on feasibility, provided at least one is retained. The path and other cycle selections can stay fixed.

* With two or more selected offsets, remove all except the two extremes j₁,j₂. In every phase fiber the affected adjacent segments between j₁ and j₂ all have the same vote; combining them preserves the source-only modal mass. Now move j₁ left to a and j₂ right to b. Every row moved into the middle pure segment contributes one hit and removes at most one hit from its old segment. This remains true if the two source intervals neighboring different fibers happen to be shared. The score can only increase and the boundary charge can only decrease.
* With exactly one selected offset j, keep it common to all phase fibers. While it varies in [a,b], each individual old-label count for each new source interval is affine in j. Moving ends stay inside homogeneous slabs and cannot cross any other chosen cut. This applies also when both ends of an interval move. A maximum of affine functions is convex, so summing the per-source maxima gives a convex function of j. It has a maximizer at a or b; the charge stays fixed. Joint neutrality guarantees this source-only calculation equals the actual simultaneous score throughout.

Consequently it is sufficient to try the offset sets ∅,{a},{b},{a,b}, deduplicating them when a=b. Apply the replacement one slab at a time. There are at most R+C−1 nonempty slabs, one per repeated necklace initially and at most C−1 extra from special offsets. This compression deals with arbitrary multiplicities and old cuts inside tied rotations. It preserves a maximizing solution and can discard other feasible partitions. ## Tractability and exact tests

For F-bucket starting states the paths have lengths ℓ₁,…,ℓᵣ₋₁ and no outgoing mandatory arc is dropped. The search provisionally tries at most 4ᴿ ∏(ℓᵢ+1) possibilities before checking flexible supports. Fixed grounded endpoints reduce this count. For general P it is bounded by 4^(R+C−1)(n+1)^(R+C−2). Checking all flexible endpoints in numerical boundary order and scoring by run/source/target intersections is polynomial per choice, so this is an exact XP algorithm parameterized by R+C. This bound does not establish fixed-parameter tractability or hardness. The reference enumerator explicitly stores each finite path's possible suffix tuples for clarity; a streaming implementation can retain one integer threshold per path and only materialize the current selection. A selector seeking fewer operations on real data needs more structure or an objective-specific bound.

The independent ten-block panel measured 690,474 original paths, of which 539,025 are singletons. On every block its witness construction certifies at least 2²³⁷ truly viable F-refinements even with a budget of 128 states. Enumeration at Wikidata sizes is excluded by these counts. No bound on a more efficient optimizer is inferred. [Independent real geometry, feasible counts and matched historical profile](panel/)

Among these columns 165 have intact periodic-gap cycles.
