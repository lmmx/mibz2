Use the ten original Wikidata blocks at indices 1, 41, 85, 134, 176, 225, 269, 313, 359 and 397, fixed in the capped scalar comparison. Freeze k=8 for the first screen. Supply the range implementation the original maximal width/symbol runs, primary, original row count, and exact physical k8 context starts/modal bytes. The range arm gets all initial supplied input conversion, context discovery, and subsequent dense marked output free. It may reuse one working state across calls. The scalar arm gets the real production scanner/front-produced capped Runs, n and primary, and must write the full original inverse bytes. Before timing, compare each input cap sequence byte for byte with the earlier capped donor's oracle-checked cap file. For scalar verify all produced raw bytes. For range verify every canonical triple against an independent membership-packet constructor built at dd836e65 from original-L plus the true indexed CLK MASK for k=8. Independently check the canonical output digest and source context digest against the thirty-model receipt. Exact equality is required on the warm cycle and after every timed call. Compare outside each clock. Failures disqualify that call.

Fix one pinned worker, one warm cycle and 24 paid paired complete rounds across ten blocks. Rotate block order each round. Balance arm order separately per block so each arm is first exactly twelve times. Record native thread CPU and wall time around each stage. Aggregate by the round's sum of ten block times and use geometric mean paired ratios with a two-sided 95% t interval over four disjoint six-round groups of log ratios. Report the same per-block paired intervals, both raw endpoints, CPU allocation and hardware identity. Time complete construction, including allocations and materialization of its result, with one reusable state per arm. File reading and correctness comparison are outside clocks. Match CPU affinity for 60 separately launched one-block, one-arm resident-memory runs (three per arm/block). Only the selected arm's starting input and state should be in memory; sample VmHWM before reading its validation output. Publish both pre- and post-call HWM; the range arm's provisioned geometry may itself set the pre high-water value.

If the optimistic construction/scalar CPU lower confidence limit is at least one, this implementation already uses an entire scalar inverse budget before acquiring the context model or emitting a byte. Stop at k8 and preserve that obstruction. If the interval crosses one, the screen is unresolved and cannot establish a gain. A clearly sub-parity constructor warrants fully charged model and writer measurements. This is a local stage study; it cannot establish a production, CI or i9 result.
