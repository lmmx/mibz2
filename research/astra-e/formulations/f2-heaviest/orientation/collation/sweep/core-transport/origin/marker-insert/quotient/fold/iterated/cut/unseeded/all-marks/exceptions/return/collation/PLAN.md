# An ordinary weighted BWT on the exceptions, without a chronological event table

Physical traversal and reordering of the sparse event ring used up the measured chronological terminal budget. Test whether its order can instead be handled by a second true BWT. Shift each true exception one byte backward so its boundary predicate is a set of forward (k+1)-byte prefix cylinders. This shift reorders the sparse ranks by stable sorting the original exception rows on their actual preceding byte. A forward return word W followed by the next boundary's entire pattern P should define one contiguous interval of selected ranks; advancing Ψ by |W| on it is increasing. The weighted alphabet may then be represented by (length, first exception byte, next pattern) without storing every W. For a given next pattern its first k bytes are the post-exception state and determine all intervening default predecessors.

First check on arbitrary small columns, including multiple cycles and empty exception sections. For every selected source and true return, verify stable reindexing, reconstruction of W from the triple, contiguity, monotonicity and ordinary sparse LF on the contracted object. Test the cheapest short-lookahead counterexample. On all ten original k=4,8,16 panels price the number of selected rows, return classes, sparse incoming runs, number of label changes and the representable alphabet width. Keep the original primary treatment explicit: omitting an artificial sentinel preserves locality of true exception boundaries and requires a separate phase query when the primary is outside the section. Count only mathematical structure until acquisition, marked phase and output are priced.
