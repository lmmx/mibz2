# Fresh-process memory calibration

Use bzip2recover to extract each of the same ten original blocks from the full corpus. In a new process per arm/block, use frozen Scanner and run frontend on that one compressed block. Drop compressed input and frontend symbols, read VmHWM, run a single inverse from the retained real Runs and original primary, and read VmHWM again, before opening reference output. Check each result against the previously authenticated marked raw output and verify record count/mark. Use three fresh processes per arm and block, with identical linkage, ordinary allocator, no warmed kernel scratch and no other block resident. Report median and maximum whole-process high-water in KiB. This stage omits RLE1, worker concurrency, stream CRC and output-writer queues. These process peaks do not establish production memory.
