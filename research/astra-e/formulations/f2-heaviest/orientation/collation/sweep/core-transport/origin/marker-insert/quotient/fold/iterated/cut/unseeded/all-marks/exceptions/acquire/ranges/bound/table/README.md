# One retained mark can require K/2 uncontracted table probes

For the marked cyclic inverse, consider an explicit table of the K positive fixed-length k contexts. Supply all source boundaries, the primary and its context, and the knowledge that every context is unanimous. Each local table query returns one state's modal predecessor and default LF poststate; the proof also allows returning both states of a paired entry at once. The only retained physical rank is the synthetic primary. Its unique weighted return band has source and target zero, width one, and an elapsed time equal to the physical LF lap of the mark. The cost question is finding that elapsed time from the supplied **uncontracted** table. The interface gives no component labels, contracted cycle lengths, promised transitivity, or separate compressed input index.

**Realization as a stable BWT.** Let K=2^k for k≥1. In lexicographic order index the K rows by all k-bit strings. Write each row as u0 or u1 for its (k−1)-bit prefix u. Independently select one orientation per pair. Send one member to 0u and the other to 1u under LF. The incoming L bit is the first bit of its assigned target. Exactly half the rows emit each bit. Among rows emitting b there is exactly one row per u, and their source order increases with u. Stable occurrence sorting therefore sends these rows to bu in precisely that order, realizing the specified LF. Its inverse Ψ takes b₁…bₖ to b₂…bₖz for a bit z. The first k forward source bits from a row are exactly that row's index, so all K contexts are distinct singleton intervals for every orientation choice. Every table consequently has the same boundaries, the same marked ordinal, and no true modal exceptions.

A one-cycle choice exists at every k. Use an Euler circuit of the binary de Bruijn multigraph on length-(k−1) words, whose edges are k-bit words. Each edge is preceded by its matched incoming edge in that circuit, and the two edges leaving a vertex are paired with the two entering it. This selects one of the permitted orientations at every vertex and exhausts the K physical rows in one marked lap.

**Query lower bound.** Fix such a one-cycle table and primary zero. If a deterministic exact algorithm stops before inspecting every pair orientation, flip an uninspected pair u0,u1. This swaps the successors of two distinct positions on the original cycle. Cutting its two outgoing edges and crossing their targets splits that cycle into two nonempty cycles: the former arcs between the two positions close separately. The marked lap strictly decreases whichever resulting component contains the primary. The two instances give identical answers to every query made by the algorithm and require different elapsed fields. Hence at least 2^(k−1)=K/2 pair probes are required on the one-cycle instance, even though there is only one birth and one output band. The family varies k; the statement is uniform in the explicit state-table size. It does not bound a richer interface that already supplies cycle summaries, nor assign K/2 random accesses to a particular compressed RLE algorithm. If several pair choices are packed into one word, the probe unit must be adjusted accordingly.

**Positive promised case.** With a certificate that the marked physical LF has one lap covering all n rows and the synthetic primary is the only retained row, the exact packed triple is (0,0,n) without any transition probes. Flipping the pair violates that promise, so the preceding indistinguishability proof would then compare an inadmissible alternative.

There is a separate shortcut when the input is promised to be the complete cyclic rotations of one text, possibly a power, and all its positive k contexts are unanimous. Each entire context interval maps into one successor context. Every successor context receives some positive LF image by bijectivity. Its function on the K contexts is therefore onto, hence a permutation. Each successor interval has a single predecessor context, so their widths agree and the increasing LF maps equal offsets to equal offsets. The physical lap of a row is exactly the length of its context cycle. The cyclic text visits every positive context while reading its letters backwards, putting all K states on the same context cycle. Thus the sole synthetic return takes **K** steps, even if several equal-offset physical lanes give more than one LF cycle and K<n. For a homogeneous positive input, including depth zero under unanimity, K=1. This shortcut uses both the one-text and unanimity promises. Distinct singleton contexts in the lower-bound family give K=n, and the switched table's disjoint cycles cannot describe rotations of one text under these promises.

The distinction locates the residual cost in range routing. Resolving smooth state redirects of a supplied table can require a linear pass in K. When the original run/context overlay has H pieces, H≥K, so this pass can be charged to O(H) geometry work. Subsequent labeled routing on the contracted relation can depend on the number P of elementary positive births.

**Exact finite check.** One verifier independently recomputes stable occurrence ranks and the physical k-byte symbol sequence for every feedback table at k=1,…,5. For every one-cycle instance it flips every orientation, checks that two nonempty cycles now cover the table and records the marked lap at primary zero.
