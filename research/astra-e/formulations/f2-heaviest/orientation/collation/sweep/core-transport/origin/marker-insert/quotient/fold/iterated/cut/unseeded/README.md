# Marked reconstruction with no distinguished type

A positive weighted BWT needs only a current source ordinal x and offset s in its outgoing word. The initial input requires no split. The cut chooser may use any colors independently of x, and the termination test needs only one point query. Let c be the row's outgoing type. At position x in the incoming run column with label a, compute LF(x) from the base of a and the number of earlier occurrences of a. If LF(x)=x the inverse LF successor also fixes x, and its one-word cycle is W꜀. Emit the original requested horizon from this word cyclically from s, even when c has other occurrences in any number of disconnected cycles.

**Ordinary cut.** Source refinement preserves every old ordinal before contraction. If x survives subtract the number of earlier deleted rows. If it is deleted, its sole old predecessor y survives because selected source and target types are disjoint. Recover y by stable occurrence rank in the refined selected class. Move the mark there and add its old word length to s. As the surviving word now spells Wᵧ Wₓ, the new offset is in range. The implementation uses the original fold's ordinal transport directly.

**Power step.** Let y=x initially. While L[y]=c move to LF(y). Each such move prepends a complete old W꜀. The first y with L[y]≠c is the retained entry to this maximal run of type c. If both y and its first predecessor are in c and the displacement is negative, every next predecessor while in c is smaller by strict order preservation on positions with incoming label c. Positive displacement gives the reverse monotonicity. If the first displacement is zero it is the terminal fixed row already detected. A maximal same-label L-run has one constant displacement, so jump in one operation to the first point outside that run. A strictly monotone walk visits each old RLE piece at most once, including the terminal piece. Compute the compressed ordinal as the count of retained entries strictly before y, plus its within-interval displacement. The new byte offset adds the number of old LF steps times ∣W꜀∣. It remains inside the new positive repeated word. The reference implementation costs O(R+K) preprocessing and ≤R predecessor lookups on the marked power step, independent of its potentially enormous uncompressed distance. The other phases consume the same ordered retained column as the earlier power proof.

If a nonterminal step has an ordinary cut deleting at least one quarter of the active rows, take it. Otherwise normalize powers and contract a certified cut. There is a nonself edge on the marked cycle whenever the mark is not fixed and its entire cycle is not monochromatic. Every finite monochromatic cycle of a stable occurrence permutation consists of fixed rows by strict monotonicity. Thus a nonterminal power pass keeps a nonempty boundary and the next cut shrinks whole active mass by at least a quarter. The original geometric-depth and total active-mass bounds hold without a marked singleton.
