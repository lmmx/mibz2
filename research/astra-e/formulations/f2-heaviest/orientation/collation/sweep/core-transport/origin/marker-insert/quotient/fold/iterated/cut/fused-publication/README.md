# Publishing the geometric cut directly from the previous incoming column

The cut can write its final incoming run sequence in one forward output pass. When it encounters a target class, one monotone cursor into that old class's source interval gives the label entering the skipped predecessor. The publisher still reads those old ranges, computes cumulative class counts and reorders grammar handles into stable source rank order. The sparse rank directory variant can avoid buffering even the old run/bucket overlay. [Proof and three-case rule](PROOF.md) · [Arbitrary-mark counterexamples and exhaustive test](small.py) · [Test counts](small.json)

The 3eb3982 implementation and raw receipts check every one of 251 published roots from ten real Wikidata blocks, including all incoming runs and widths, every word and its exact grammar index, and the singleton marked ID. Dense traversal produces the same 8,999,915 marked inverse bytes. The stored original libbzip2 checks cover post-RLE1 SHA-256 and block CRC, reproduced by the checker. The native small test adds 13,567 arbitrary-column/mark inputs, 23,740 contraction passes, 4,705 normalized passes and three required long normalization examples. The separate mathematical test enumerates all 337,264 general marks across 53,504 arbitrary cut/column pairs. ## Reproduction

Run from the repository root. Use the original ten numbered input folders generated by the frozen powers study. It reads the true source mark, emits unexpanded maximal runs and authenticates each original block. The native experiment only reads the four-digit folders. Complete reproduction also needs the Rust reference binary built by the capped donor procedure and the original Wikidata compressed corpus. [Original input export](../powers/README.md) · [Rust reference build](../powers/xor/README.md)

```bash
d=$(dirname "$(rg --files | rg 'cut/fused-publication/PLAN.md$')")
cases=/workspace/work/astra-powers-original/native-ten
work=$(mktemp -d)
results=$(mktemp -d)
taskset -c 0 nice -n 16 python3 "$d/build.py" "$work/fused"
taskset -c 0 nice -n 16 "$work/fused/fused" > "$results/native-small.csv"
taskset -c 0 nice -n 16 python3 "$d/check.py" "$work/fused" "$cases" "$results"
taskset -c 0 nice -n 16 "$work/fused/fused" price "$cases" > "$results/graph.csv"
taskset -c 0 nice -n 16 "$work/fused/fused" stream "$cases" > "$results/joint.csv"
taskset -c 0 nice -n 16 python3 "$d/raw-build.py" "$work/raw" > "$results/raw-manifest.json"
taskset -c 0 nice -n 16 "$work/raw/raw" gate "$cases" > "$results/raw-trajectory.csv" 2> "$results/raw-small.csv"
taskset -c 0 nice -n 16 "$work/raw/raw" price "$cases" > "$results/original.csv"
for a in 0 1 2 3; do taskset -c 0 nice -n 16 "$work/raw/raw" memory "$cases" "$a" > "$results/raw-rss-$a.csv"; done
ref=/workspace/work/astra-powers-original/capped
taskset -c 0 nice -n 16 python3 "$d/caps-run.py" "$work/raw" "$ref/panel" corpora/wikidata.bz2 "$work/caps" build
taskset -c 0 nice -n 16 python3 "$d/caps-run.py" "$work/raw" "$ref/panel" corpora/wikidata.bz2 "$work/caps" price
taskset -c 0 nice -n 16 python3 "$d/caps-rss.py" "$ref/rss" corpora/wikidata.bz2 "$work/caps"
python3 "$d/caps-report.py" "$work/caps"
```

## Cost of removing the original slices too

The 7b7c9c9 constructor computes the same greedy colors by scanning disjoint old-RLE source buckets. It retains 854,131 distinct outside alias ranks over the ten trajectories and zero old joint slices. Its largest single old-alias directory, including outer vector headers and each retained inner capacity, is 841,860 bytes. Its largest cursor/ordinal capacity is 361,344 bytes. These maxima may occur at different depths. Dictionary, incoming RLE, interval normalization, grammar and output still require memory. The final 2,226,170 output runs across all ten histories exactly match the donor throughout. [Raw-RLE plan](RAW-PLAN.md) · [Pass counts and actual capacities](raw-trajectory.csv) · [Small check](raw-small.csv)

The original-RLE constructor takes 1.663 [1.547, 1.787] of the sliced fusion's complete reconstruction CPU. Selection takes 1.595 [1.474, 1.725] and publication 1.827 [1.657, 2.014]. Binary alias lookup, repeated old bucket decoding and allocation of per-class rank directories buy slice elimination at a substantial cost. Against the original graph-free compact donor the complete ratio is 1.322 [1.176, 1.486]. The sliced fusion repeats its gain in this independent 16-round four-arm panel at 0.795 [0.755, 0.837] of the compact donor. Four disjoint four-round groups supply the intervals. In separate processes decoding the same ten RLE roots in sequence, high-water peaks were 9,580 KiB for raw old-RLE, 8,792 for sliced fusion, 9,532 for the graph-free compact donor and 11,128 for the raw weighted graph. This construction's asymptotic space reduction did not reduce the process peak relative to sliced fusion on these inputs. The proof gives no comparable space lower bound for a different representation.
