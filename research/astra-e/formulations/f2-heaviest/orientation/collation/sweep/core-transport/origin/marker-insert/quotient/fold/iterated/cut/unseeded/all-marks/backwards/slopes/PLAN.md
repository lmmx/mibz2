# Can the final cyclic scatter be represented by a small affine partition?

For some two-run rotations the unit-translation atlas needs one interval per source while one modular slope represents the complete position permutation. Test that generalization on the ten fixed original byte columns. Give the constructor the complete true offset permutation for free. For each physical source interval allow an arbitrary intercept and any slope modulo the marked lap. Find the exact minimum number of such intervals, with and without first-byte bucket constraints, and count rows covered by monochromatic affine spans of at least 4, 8 and 16. Explicit singletons/pairs can always fill a failed partition, so charge two source positions per affine span as free parameters and report the remaining implied positions. Separately test whether explicit buckets have frequent modular differences worth sharing. To pursue a native full constructor from this evidence alone, require at least half the source positions to be implied on eight of ten blocks and a cut-spanning way to find them. Oracle-derived slopes have no measured acquisition speed.
