# Locating the single marked emission without counting the published prefix

If x survives, its output row is emitted from the already known slice containing x, at the same within-slice offset. If x is absorbed, its representative p lies in source bucket a=L[x] outside the cut. Every row of that old bucket survives and its every refined alias is live. Its first new position is B′[id(first[a])]. Thus p's old offset in bucket a is exactly x′−B′[id(first[a])]. Locate that offset among only the existing physical destination-order slices spanning old bucket a. Its old slice and local offset once again specify the marked output event. There is no need to observe any other old slice's individual emissions. Within the single marked slice, the donor may split its output when its ancestry map changes. Observe only the pieces of that one slice until the mark is found, including any merge into an earlier raw run.
