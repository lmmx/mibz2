# Extremal sources recognize every complete one-query class

Let x and y be the first and last ordinal in B_c. Advance both by Ψ while they remain in the same non-delimiter first-column bucket. Within each such bucket Ψ is strictly increasing, so all trajectories initially between x and y remain between their two images. If both endpoints reach B_d simultaneously, the entire B_c has one common symbol itinerary to its first future d, hence is precisely one full query interval. Conversely if B_c appears as one full query then its two endpoints have this same itinerary and necessarily pass the test. A differing first symbol before success disproves full-bucket membership. If the endpoints agree for m steps without seeing d in a column of m rows, the first endpoint's cycle is disjoint and this bucket cannot be fully queried. This covers all LF cycle structures, including width-one source buckets.

The first Ψ images of the two extremal c sources are already the first and last occurrences of c in L. Later steps need one select for equal endpoints or two for distinct endpoints and one source-class lookup. A certified complete class p allows early success as soon as both endpoints enter B_p, because its proof applies to every subset. The depth for c is steps so far plus the known depth for p. The falsifier processes types in nonincreasing frequency, uses positive certificates only, and charges select operations, first steps and a separately constructed 2R-word select table (old LF start and destination start per run, plus type offsets). A select table is additional work if the original decoder only built backward LF. Type-base searches also need the order of original bases.

A marked LF rewind before reaching d can enter a known complete class at most once. On a cycle meeting d define δ(x) as forward distance to the next d, zero on d. An LF hop to a non-d source increases δ by one. Every rank of a complete class c has the same δ, namely its certified itinerary depth. Thus the rewind can encounter c only once, including after other classes outside the certificate. A cycle disjoint from d contains no rank of any complete class. Unlike the deterministic-successor certificate, membership need not form an initial prefix along the mark. Scanning a complete class once for that exceptional mark therefore still costs at most the full streamed-class piece count in total.
