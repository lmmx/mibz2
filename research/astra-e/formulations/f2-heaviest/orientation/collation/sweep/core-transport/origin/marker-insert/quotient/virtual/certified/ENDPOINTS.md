# Extremal sources recognize every complete one-query class

Let x and y be the first and last ordinal in B_c. Advance both by Ψ while they remain in the same non-delimiter first-column bucket. Within each such bucket Ψ is strictly increasing, so all trajectories initially between x and y remain between their two images. If both endpoints reach B_d simultaneously, the entire B_c has one common symbol itinerary to its first future d, hence is precisely one full query interval. Conversely if B_c appears as one full query then its two endpoints have this same itinerary and necessarily pass the test. A differing first symbol before success disproves full-bucket membership. If the endpoints agree for m steps without seeing d in a column of m rows, the first endpoint's cycle is disjoint and this bucket cannot be fully queried. This covers all LF cycle structures, including width-one source buckets.

The first Ψ images of the two extremal c sources are already the first and last occurrences of c in L. Later steps need one select for equal endpoints or two for distinct endpoints and one source-class lookup. A certified complete class p allows early success as soon as both endpoints enter B_p, because its proof applies to every subset. The depth for c is steps so far plus the known depth for p. The falsifier processes types in nonincreasing frequency, uses positive certificates only, and charges select operations, first steps and a separately constructed 2R-word select table (old LF start and destination start per run, plus type offsets). A select table is additional work if the original decoder only built backward LF. Type-base searches also need the order of original bases.

A marked LF rewind before reaching d can enter a known complete class at most once. On a cycle meeting d define δ(x) as forward distance to the next d, zero on d. An LF hop to a non-d source increases δ by one. Every rank of a complete class c has the same δ, namely its certified itinerary depth. Thus the rewind can encounter c only once, including after other classes outside the certificate. A cycle disjoint from d contains no rank of any complete class. Unlike the deterministic-successor certificate, membership need not form an initial prefix along the mark. Scanning a complete class once for that exceptional mark therefore still costs at most the full streamed-class piece count in total. ## Recovering the exact answer with partial select storage

A select for the first or last ordinal of any source type is simply that type's stored first or last incoming destination. This also applies after the first hop. Start from the cheap deterministic closure. Advance the remaining endpoint pairs until mismatch, a known positive continuation, or a pair equal to the two extrema of another full source bucket. The latter transfers the undecided result to that bucket and adds the number of elapsed token steps to any positive depth. Resolve those start-to-start edges as a functional graph. A directed cycle without an included terminal never sees the delimiter. The full original Ψ is a permutation, hence (x,y)→(Ψx,Ψy) is injective. Traces from different starting pairs cannot share an interior state before one trace reaches another starting pair. This segmentation therefore avoids rediscovering shared interiors without a hash table indexed by arbitrary endpoint pairs.

When an unknown interior select is first required, suspend its query. Batch every currently missing source type and rescan the old RLE to build only those types' select lists. Reuse the lists throughout. Every selected list is built once. Every additional sweep reads the entire old RLE, and is separately counted. Using the deterministic closure, repeated extremal observations and positive hits can remove the need to store many full select lists. Actual repeated sweep work may dominate even if only a handful of postings are ultimately consulted. [Adaptive constructor](selective.py)
