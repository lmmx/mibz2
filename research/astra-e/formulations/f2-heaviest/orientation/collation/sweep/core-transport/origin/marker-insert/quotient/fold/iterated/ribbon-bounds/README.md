# Original gaps bound an exact sparse successor at every folding depth

Let S be the living vertices after any sequence of whole-class folds. The forward map on S is the first return to S of the original token permutation. Each fold deletes middle vertices of paths of two. Composition yields exactly the first retained successor, even on multiple cycles. Logical labels retain their original source type during this unsplit fold schedule. This topological assertion also holds for any nonempty subset S, independent of the schedule producing it.

In physical original-rank coordinates, a ribbon is a maximal consecutive source interval of one original type whose destinations are consecutive in the same order. Initial token RLE has R ribbons, one per maximal incoming run. Let c be the number of physical source intervals in S and b the number of internal adjacent pairs with exactly one endpoint in S. The induced physical ribbon count T obeys **T≤min(|S|, R−1+c+b)**, with b≤2c. Ascending source order and stable destination order inside the old domain support a run-by-run representation throughout. The gap bound itself also permits arbitrary S with nonmonotone induced maps inside an old type.

Start one ribbon at the beginning of each component. For any remaining broken adjacent pair x,x+1 of survivors, follow their simultaneous old forward images while they occupy one initial ribbon. A failure of original type or translation charges the old seam at their current pair. A first unequal return to S charges the physical S boundary at the images. If both return together before either charge, their end ranks are consecutive in order and the same-type pair would not have been broken. While uncharged, an original adjacent gap maps injectively to one adjacent gap. The two paths from different starting gaps cannot reach the same witness: trace back under that injection to the most recent pair both in S. A named old seam or named section boundary therefore pays at most once. The proof distinguishes the two names even if their physical index coincides. This gives the inequality. Actual interval maps can coalesce more at the end of paths.

In particular, deleting increasingly many rows from the end of one physical interval can leave very few pieces despite a long schedule. The two-run singleton example can require Θ(m) one-class contractions even though its retained set has at most two physical components. Other deletion orders may create many components. This bound constrains peak map storage and makes no general sublinear claim for cumulative maintenance.
