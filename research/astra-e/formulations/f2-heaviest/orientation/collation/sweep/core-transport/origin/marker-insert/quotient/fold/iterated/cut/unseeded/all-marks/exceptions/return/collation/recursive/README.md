# Recursively reconstruct sparse prediction errors in their own marked order

The previous construction gives an ordinary BWT on annotated return-class IDs. The same theorem therefore applies to this smaller integer alphabet, even when its symbols represent many preceding-level tokens. Measure lengths in *current tokens* at each step. A return class records its length, its first lower-level symbol, and the poststate associated with the next boundary. To expand a class, place the first symbol at its beginning. Starting from the stored poststate write the remaining length−1 default predecessors backwards into its destination interval. Expansion needs no literal spelling directory.

The requested recursive result is one marked periodic spelling whose length divides the physical lap on that orbit. Let g be the number of forward steps from the current primary p to its first true shifted boundary y. Recursively obtain one valid period of selected classes starting at y. Expand that period as above and rotate right by g modulo its expanded length. This recovers a valid marked period starting at p. The physical first-return cycle contains an integer number of them, so eventual repetition to the requested bzip2 length remains exact in the nondivisor case. If the marked cycle misses the section, traverse its default state cycle backwards starting from the mark's context, and reverse that one spelling. Since physical and state transitions agree all along that orbit, its state period divides the physical lap. This covers an empty global section and an empty marked section even when other physical cycles contain exceptions. The reference pays the primary-to-section walk explicitly. **Universal progress.** With m active symbols, alphabet cardinality A and fixed context length at least one, there are at least A nonempty contexts. The sum D of their modal counts is at least A. In each context its modal count also covers at least 1/A of its occurrence mass, so D≥ceil(m/A). The child mass m−D is therefore at most m−√m. This bounds the number of positive reductions by 2√n and the sum of all active masses by n^(3/2), using m^(3/2)−(m−√m)^(3/2)≥m. These are worst-case structural bounds. They require charging the work of discovering contexts, computing and ordering return bands, constructing the child column and expanding every output layer. For k=1 the one-step √m guarantee is sharp: a circular Euler tour of the complete directed graph on A labels with loops contains every ordered pair once. Its primitive BWT has m=A² and every one-symbol context saves exactly one modal occurrence. The code checked A=2 through 16.
