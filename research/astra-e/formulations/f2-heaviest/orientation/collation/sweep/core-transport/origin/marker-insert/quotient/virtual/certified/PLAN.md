# Pre-certifying full-bucket queries before building a search index

Split the source alphabet into first-column buckets B_c. The stable source class c has all its forward destinations in B_p exactly when the first and last incoming occurrences of c both lie in B_p. In that case write c→p. Start a set A with the chosen delimiter d and close it under predecessors of those unique successor edges. For every c in A other than d, all its rows appear as one child of the sole complete query to B_p. Induction along the unique route to d proves that B_c itself is queried exactly once and in full. The route also determines the depth and spelling of this child in the backward trie before that trie is built. This certificate is sufficient. A proper subset of an uncertified parent's rows can have a single future itinerary, so one-query classes may remain undetected.

The start and end of the observed incoming positions for each label can be collected in one column scan. Binary search in sorted bases costs O(K log K); an ordered joint endpoint sweep over run/bucket intersections assigns the same unique edges in O(K+R) once bases are ordered. Original native IDs need not already have this order, so charge sorting or an equivalent indexing step. A reverse adjacency list and queue compute closure in O(K) work and space. This uses the same deterministic-successor relation as the adjacent token-fold study, with the additional requirement that the unique successor chain ends in the decoder's chosen root.

The ordinary marked LF shift can start outside, or in any certified bucket. If its current row belongs to B_p and the next LF lands in certified B_c≠B_d, c→p implies that p is certified and depth(c)=depth(p)+1. Thus before the first hit of B_d the shift can visit certified buckets only in its initial prefix. In that prefix their depths grow strictly, so it probes each certified bucket at most once. If a reducer omits those buckets from the random index, the exceptional marked probes can each scan that bucket once, with total probe work bounded by the number of certified input pieces. This argument includes other LF cycles.
