# Exact canonical modular bands from width-q strip paths

The modular Rauzy tower already produces the minimum number of source bands compatible with the emitted original byte word and an increasing unit translation on retained ranks. Semantic word coalescing cannot reduce any of its layers. An independent construction found those same bands by walking interrupted width-q strips backwards from the original run seams. It matched **every band width and destination in all 418 real layers**, as well as every first return and original marked block byte. The representative-walk implementation built more grammar joins than the existing surgery at each tested radix. We retained the theorem, structural constructor and measured work without a native timing claim. ## Equal words preserve the entire strip

Retain physical ranks congruent to p modulo q. A canonical band is a maximal consecutive set of these ranked sources with the same positive backward first-return byte word and a unit translation of their normalized destination ranks. For a common byte b at two distinct ordered original ranks x<y, stable LF gives

```text
LF(y) − LF(x) = number of b in L[x:y] ≤ y−x.
```

Equality holds exactly when all of L[x:y+1] equals b. Then every rank of the closed interval undergoes the same physical translation. After any equal prefix the gap remains positive and never increases. Adjacent sampled ranks are distance q apart. If their complete positive return words are equal, their final positive gap is a multiple of q and at most q, hence exactly q. It follows that **every intermediate gap was q**, every original closed strip translated uniformly, and the two endpoints had the same membership residue at each step. Conversely, following only such uniform strips up to a positive residue return gives identical first-return words and destinations q apart. Consequently, for adjacent sampled sources equality of the word already implies the required ordered target adjacency. Equal cyclic rotations on different permutation cycles remain distinct ranks. The proof uses no unique-step or primitive-lap assumption.

## Partial gap map, exact count and sharpness

For N original ranks let Y be the valid strip starts, 0≤y<N−q. Define G(y)=LF(y) precisely when y and y+q are in one original L run. On a run of width w this is a translation on max(w−q,0) strip starts. Its images are disjoint, so G is a partial injection whose components are finite paths and intact cycles, with isolated vertices included as paths. Along a path enumerate the starts congruent to the selected phase. Every one except the last has a next sampled G iterate and gives a successful merge. The last gives the only nonmerge. An intact cycle contributes no failed adjacency. Thus B, the number of canonical retained bands, is exactly one plus the number of finite strip paths touching the selected residue. This applies also when no strip fits and the section contains one row.

Every finite path has one sink. If A=Σ min(q,w) over the old band widths and g=min(q,N), there are exactly A−g sinks. Therefore B≤min(retained mass,1+A−g). For N≥q with R original runs, this gives B≤1+q(R−1). There is an exact two-run **primitive** witness for every q. Choose N=q²+3q+1 and L=b^(N−q−1) a^(q+1) with a<b. Its LF is rotation by q+1, coprime to N. All q sink starts lie at the single run boundary. For the next q−1 reverse moves they remain inside the large translated run, where Ψ subtracts q+1 and hence visits every residue modulo q including the starting residue. Every phase therefore touches all q finite paths, giving B=q+1. The finite gate tested 2,079 q/phase instances of this family. ## Computing bands and a full tower

Enumerate the complementary sink intervals in source order. Split each into at most q arithmetic progressions of stride q. For each progression, walk backwards through the image intervals of old bands. If the entire packet has the selected residue, all its starts are the terminal selected occurrence of distinct gap paths; publish their consecutive normalized cut coordinates and stop. Otherwise split only as needed at the boundary of an inverse-valid strip domain. Continue by the inverse translation on valid pieces, and discard paths with no predecessor. Reverse paths are disjoint up to their stopping points, so the sum of visited packet widths is at most max(N−q,0). Intact cycles need no traversal. Sorting and merging published cut ranges gives all maximal widths. Follow the original map from just the first sampled row of each band until its next sampled row. The returned coordinate determines its destination, and the emitted pieces concatenate to its common word. These representative paths occupy disjoint portions of the old permutation, so the sum of their lengths is at most N.

At a later level suppose the old section is the physical residue modulo s and its stored bands are canonical for original bytes. Two adjacent new retained rows are now qs original ranks apart. Equal complete return words force uniform translation of that entire original strip at every *byte* step. The q+1 intervening old-grid rows stay separated by s, and all make their positive returns to the old residue at the same byte times. Their old return words and old normalized translations therefore agree at every macro step. They must belong to the same canonical old band. The converse follows by composing such old bands. This proves that the strip test on old normalized ranks gives exactly the canonical next layer, even though the old labels are variable-length words. An arbitrary weighted exchange need not have this property. The identity permutation on three rows colored 0,1,0, with q=2, has equal endpoint words and ordered targets without uniform interior color. [Minimal arbitrary exchange witness](limits.txt)

## Why full-tip surgery is already canonical

For an ordered interval exchange with distinct arc identities, define H on adjacent-row gap starts by the translation inside each top arc. Its range consists exactly of interior gaps of bottom arcs. Consider a full-tip step with h current rows and h′=h−min(top-tail width,bottom-tail width) retained rows. The retained gap set is [0,h′−1). At the bridge gap h′−1, at least one of the two axis orders has an arc boundary; hence this vertex lacks an incoming or an outgoing H edge. It cannot be an interior vertex of a returning gap path.

Every other removed gap lies inside both tail intervals. For distinct tips, the predecessor of each such gap lies strictly below the bridge on the bottom-tail arc's source, and its successor lies strictly below the bridge on the top-tail arc's image. The new composition of width w creates exactly these w−1 two-edge shortcuts. All old direct interior gap edges with both ends retained persist. Where a former edge leads to the bridge and stops, the corresponding new gap cannot continue. Coincident full tips delete an isolated identity interval, and its interior gap loops are unreachable from the retained set. Thus the gap map of the reduced two-axis partition is exactly H's partial first return to the retained gaps. This argument accounts for both strict/equal size cases and singleton widths. Empty retained gap sets require no shortcut.

Partial first-return maps compose on nested subsets. The final retained residue boundary appears in both axis orders of the original modular exchange and survives each full contraction until reached, so clipping never stops partway through both tails. This alignment was proved independently in the original trajectory audit. Within a residue bucket the original conjugated arc interiors are exactly the q-wide strip translations. Bridges between residue buckets are boundaries on both axes. The final retained arc interiors are therefore precisely the successful strip gaps proved above. This yields exact minimality for the first round and all later canonical rounds. In particular, the existing relation B=A−equal−self implies the new measurable identity equal+self=g−1+number of finite paths missing the chosen phase. Every real layer satisfied it. An independent enumerator checked all 31,287 single full-tip surgeries through five arcs with widths 1–3. In contrast, 13,835 of 20,219 arbitrary partial clips differ from gap first return. The smallest test witness has widths (2,2), reversed bottom order, and one deleted row.
