# A weighted ordinary BWT on true prediction errors

Let F be the first column, Ψ advance in output order, and LF go backward. Let U contain the true errors of a k-byte forward-context predictor: x is selected exactly when L[x] differs from its context's modal predecessor. Move the section to V=LF(U). A boundary in V is now recognized entirely by its next k+1 bytes, b·c, with b an exceptional predecessor of context c. Sorting U stably by its incoming byte gives V in physical rank order because LF(x)=C[b]+Occ(b,x). A synthetic primary sentinel is handled outside this recognition rule.

From a selected source y in V, let W be the forward word up to but excluding its next boundary z and let P be the k+1 bytes at z. Every rotation beginning with W·P satisfies the same local boundary test at zero and at |W|. It fails the test at every strictly intermediate position, since all required k+1-byte windows lie inside W·P. Conversely every occurrence of that annotated return has this prefix. Its source class is a complete, contiguous lexicographic cylinder. Ties among identical rotations respect the stable order. Within the cylinder Ψ^|W| is increasing because all its sources share W. Order the classes by their first selected source. Scatter each source class label to its return destination's selected rank. Stable sorting this new incoming column recovers the complete forward first-return permutation. Thus this is an ordinary, weighted second BWT with a canonical alphabet, without globally numbered event clocks. This uses the full next-boundary pattern as a uniform bound on lookahead. [Executable and arbitrary-column checks](ordinary.cpp)

A class needs no literal spelling dictionary. If the preceding forward boundary has exceptional byte b and the next boundary has pattern P, the first k bytes of P give the true state just after applying the *next* prediction exception backwards. Follow the default predecessor graph for |W|−1 steps from that state. Reverse those bytes and prepend b. Consequently the triple **(|W|, b, P)** and the pair (W,P) classify exactly the same return. The next pattern can itself be identified by the next exceptional byte and its pre-exception k-context. This avoids comparing or copying long literal return words in a sparse publisher.

On arbitrary ternary last columns through length eight, all 29,520 depth/column models and 221,436 marks passed. This includes 103,812 marks on cycles with no selected boundary; the oracle uses its direct marked basis on these cycles. It checked every physical shifted row, sparse return partner, regenerated spelling and reconstructed marked output. Bare words can fail to group contiguously: the first small witness has L=22102211 at k=1. Across the tested tiny population k extra bytes happened to suffice. On real inputs k extra bytes failed on all ten k=4 blocks and nine k=8 blocks. The full k+1 rule always passed. [Finite receipt](small.txt) · [Real lookahead tests](blocks.csv)

On ten primitive original columns, the k=8 second columns have **409,432 selected rows, 95,150 return classes and 148,077 incoming runs** in total. The largest single-block alphabet was 19,747. The annotated class spellings would occupy 2,206,359 bytes across the inputs if each were stored once literally. The forward primary-to-section walk used 226 steps in total. At k=4 there were 1,122,585 rows, 219,840 classes and 296,655 runs. At k=16 there were 229,013 rows, 78,606 classes and 115,962 runs. This is an exact residual for recursive or ordinary inversion. Existing byte-specific scalar scratch and alphabet assumptions do not automatically apply to its much larger alphabet. The dense reference intentionally prices structure only. A direct publisher must charge obtaining the return bands and their payload labels, phase, ordering, and ultimately spelling the output.
