# Inducing the incoming token column on any contiguous rank interval

Let U=[a,b) have positive width m. A return word starts at a row of U, follows positive forward Ψ steps and ends at the next row of U. The original stable LF run table suffices to construct both the source bucket and the incoming column in destination order. No preceding word marker, forward suffix array, or global cyclic inverse is required for this construction.

**At most two partial terminals in the entire trie.** Start the backwards search on U itself. For each live interval, partition its last-column rows by byte. Stable LF sends each byte group to a single interval J, since occurrences of that byte between the first and last selected ranks in the parent are all included. Its width cannot exceed the parent width, hence never exceeds m. Publish J∩U as terminal and continue on J outside U. When both pieces are nonempty, the terminal part is one end of J, and the live remainder is a single interval. A partial terminal contains a or b−1, according to which boundary J crosses. Terminal images at distinct nodes are disjoint: a rank in U has exactly one next positive forward return, with a unique spelling and depth. At most one partial child can therefore consume either boundary. The bound two is sharp even over two bytes. Last column 1,0,0,1,1,0 and section [1,5) attain it.

Every rank on a cycle that meets U occurs in exactly one live node. Start at that rank and follow Ψ until the first hit of U, allowing zero steps. Its distance and spelling identify the node; running the construction backwards recovers that unique occurrence. Ranks on disjoint cycles occur in none. If H live nodes make lookups in the original r-run column, the number of scanned run pieces is at most H+r−1. Each live interval pays one piece, and disjointness lets each original interior run boundary increase the total by at most one. H is exactly the number of distinct proper return-word suffixes, including the empty suffix. A complete spelling that also occurs as a proper suffix occupies a node with both terminal and live mass. This explains why treating whole-word terminals as leaves fails on a general section. H is a cost of this constructor. There is no established H lower bound on arbitrary induction algorithms.

**Recovering destination order.** Each destination asks which word ends there. At a terminal node all stopped ranks have the same word and form exactly its contiguous source bucket. Keep their width and side. At the root of each live subtree, its original L run order is a selector. Consume the next ranks of the corresponding child stream for each selector run and concatenate these pieces. Stable LF preserves occurrence order within a selected byte. Prefix or suffix the resulting live stream by the node's terminal part as recorded. Induction from the leaves gives the exact incoming token BWT on U and the source bases of all return words. Stable matching of the incoming tokens in source-bucket order yields exact first returns. The [marked reconstruction check](../) covers entrance prefixes and cycles disjoint from U.

The reference stores child paths, lookup pieces and bottom-up node streams. If N is the number of rows on intersected cycles, live mass sums to N and terminal mass to m. At most N+m run records appear across all expanded node streams, even counting every intermediate stream. Reading and spelling out each distinct word costs D total bytes, where D≤N from the disjoint occurrence arcs. A direct binary-search run directory costs O(H log r + r) to discover the intervals, plus selector/word assembly. The reference retains per-node metadata. The at-most-two bound does not remove the lookup or writer costs. [Exact implementation](induce.py)
