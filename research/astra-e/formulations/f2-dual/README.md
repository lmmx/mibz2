# Recover the delimiter-token BWT from adjacent gaps

F2b discovers each left-extension interval of a delimiter-ended word. The dual construction recovers the exact run boundaries of the token BWT before visiting the phrase words. It takes capped run records, merges them into maximal runs, and stable-sorts their LF images with byte counts. A run from [a,b) to [e,e+b−a) is a translation in either direction. The code stores both orders.

Let d be the delimiter and Q the contiguous F bucket of d. Each row of Q is the image of one L delimiter. Trace LF from those images until the next L delimiter, collecting non-delimiters. Reversing the collected bytes and appending d gives the token in the corresponding after-delimiter rank. An L delimiter terminal also supplies its previous section rank by a single translation. The mark rewind counts bytes, detects a cycle without d, and otherwise leaves the offset within its first forward token.

## Gap correspondence

An integer gap g lies between rows g−1 and g. If those rows have the same L byte other than d, their LF images are adjacent; translate g by their common run displacement. A gap between equal d bytes terminates with identical words. A gap separating unequal L bytes terminates with different words, including a delimiter/non-delimiter mismatch. Thus an **interior gap of Q** starts a token-BWT run precisely when its translated gap reaches an original L-run boundary before equal terminators. All paths from Q terminate since both individual delimiter rows belong to cycles that visited a delimiter.

The inverse of a continuing step is uniquely determined by the single LF-image run containing the gap strictly in its interior. A gap on an LF-image seam has no such inverse. An inverse crossing a delimiter run is forbidden. Starting once at every original L-run boundary, follow these unique inverse steps. Reaching the interior of Q yields a token-run boundary; a seam or forbidden step discards the seed. A route encounters at most one interior Q gap, since its only possible preimage there lies in a delimiter-run image or at its seam. The number h of successful reverse steps is exactly the common initial length of the two unequal preceding words read backwards after their common ending d.

If the original column has r maximal runs, the token column has at most r runs. Distinct seeds have disjoint reverse itineraries because a continuing preimage gap lies strictly inside an original run and the forward continuation is functional. Each of the n−1 row gaps can therefore incur at most one reverse probe. Forming both run orders takes O(r+256) time once capped runs have been coalesced. Sorting t surviving section boundaries costs O(t log t) comparisons in this implementation. An explicit RLE answer necessarily writes t run descriptors. Word discovery and dictionary output still have to be priced independently.

## Labels and validation

The first labeller walks LF from the leftmost row of each token run. Consecutive representatives can reuse h saved displacements from the preceding walk: the preceding run's entire width followed one uniform path, and the two neighboring boundary rows agree under the first h steps. A reverse-prefix trie assigns exact word IDs without hashing bytes probabilistically. The band stores both its source and LF-terminal destination and therefore supplies all return arrows, without a dictionary sort. The sum of representative walks is at most n before sharing because distinct section starting rows travel along disjoint LF row paths to the next terminal. Their dictionary still includes a byte copy per distinct spelling. The Python implementation materializes the residual token table and spells one marked period for verification.

The property test audited 25,217 column/mark/delimiter cases including 6,800 delimiter-free marked cycles. ## Reusing the affine suffix of a return

The follow-up labels the same bands by maximal intervals of rows in the *interior* of previous returns. At the terminal delimiter run the map to the section is affine across the entire run. To prepend a nonterminal step from run R with displacement δ, intersect R with the previous certificate translated by −δ and add δ to its destination displacement. The destination rank and remaining spelling agree across this whole interval. Storing the most recent certificate per physical run reduced frozen label lookups from 128,155 to 77,561, costing 24,485 certificate tests and 71,428 writes in the Python experiment. Retaining all certificates reduced lookups to 77,265 but required 1,177,608 comparisons with this list implementation. On ten blocks the last policy used 1,067,752 lookups against 1,585,376 and performed 983,435 writes. All 11,706 policy/section checks and all ten comparisons with the independently checked band/word table passed. [Certificate policy experiment](memo.py) · [All measurements](memo.csv)

The returned right endpoint is the **exact next word boundary**. Translations are maximal until the first differing symbol or unequal stopping time. An adjacent row beyond their intersection must therefore spell a different word. Conversely every row inside it follows the same direct itinerary up to the identical stopping step. Taking its right slack at each successive section representative enumerates all true bands and makes the reverse seed search and sort unnecessary for a complete decoder. The reverse-gap theorem independently predicts the boundaries.

For contiguous sections I(P) of compound words, split each LF image at the two section endpoints as necessary. The return stops on the first transition landing in I(P). A letter mismatch, or one landing inside while its neighbor lands outside, still proves a true boundary. An endpoint lying in the interior of an image run only splits that particular run; at most two additional run intervals are needed. The scalar implementation computes the bounds when tracing. Nonempty token words are returned in forward reading order.

The native cache uses previous **dictionary prefixes** instead of interning every byte in a trie. While tracing backwards, the remainder of a word from any interior point is a prefix of the completed forward spelling. A certificate therefore needs only its row interval, destination at the left end, dictionary start and prefix length. A hit copies those exact bytes and newly traced letters extend them. An uncached one-row interval can be discarded after use since distinct section representatives travel along disjoint individual row paths. For a block of n rows, storing one spelling per band totals at most n bytes because the disjoint return paths, weighted by band width, cover at most n rows.
