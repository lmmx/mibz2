# Cyclic recurrence instead of LF

**Object.** A seed of k bytes and a common binary linear recurrence over shifts of the marked byte stream. This would replace LF construction, marked-row ordering and random pointer chasing with a sequential recurrence. It requires finding the seed and coefficients directly from the last column. We first give the proposal an oracle that supplies the true marked stream and the true return length for free.

**Invariant.** Let d be the number of steps to the first return of the marked row, and let A_b(x) encode bit b of the d emitted bytes, low power first. Circular shift is multiplication by x in GF(2)[x]/(x^d+1). For a binary polynomial q, annihilation of all output bitplanes is equivalent to divisibility of every q A_b by x^d+1. Write g=gcd(x^d+1,A_0,…,A_7). Bézout shows that this is equivalent to (x^d+1)/g dividing q. The unique monic generator thus has minimal degree d−deg(g). Reversing shift direction reciprocates the polynomial and leaves its degree unchanged. The argument allows repeated factors, shorter spelling periods, and arbitrary disjoint LF cycles. When d does not divide n the emitted answer is truncated after n bytes; using the marked period prevents a spurious boundary in the screen.

**Falsifier.** Compute the exact minimal degree on a real marked period and compare it with d. If k is close to d, the proposed seed-as-explicit-bytes representation already needs nearly the entire result and cannot recover most bytes by a compact recurrence. This test does not exclude sparse high-order operators with a separately compressed seed, nonlinear grammars, or computation specialized to a finite prefix. The dense LF used to derive the oracle is a screening expense. It would have to disappear entirely in any candidate, as would the cost of discovering coefficients from reconstructed output.

`screen.py --small` compares the formula to direct enumeration of every possible tap set up to the minimal order, on all length 1–7 strings with symbols 0,1,2. For the real screen, pass `.irec.xz` files from the pinned Astra C inputs. The script reads only the initial runs and primary, constructs the independent stable-sort oracle and computes exact polynomial gcds with python-flint 0.9.0. `python3 -m pip install python-flint==0.9.0` supplies the dependency.
