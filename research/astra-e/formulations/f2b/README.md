# F2b. Quote phrase BWT with contracted unary paths

The scorer entry implements the F2 left-extension construction directly from run records and reconstructs the entire marked output. It fixes the delimiter to byte 34. Contraction happens **during** interval discovery: a unary byte never acquires a node object. On frozen the node table falls from 70,561 objects to 3,689, with the same 2,716 distinct phrases, 135,716 section rows and 6,133 token BWT runs. Building still makes 70,560 interval lookups. [Earlier derivation](../f2/) · [Full-corpus counts](geometry.csv)

**Node and order invariant.** A node represents a nonempty prefix interval. If its interval lies wholly in a single non-quote L run, every row makes the same next left extension and its LF image is an order-preserving interval of the same width. Append the byte to the edge spelling and continue in that image. The output stream before and after this step is identical. At the first terminal/branch interval, the saved bytes form a path segment in left-extension order. Reverse that segment and concatenate the parent's reversed segments to spell each dictionary word. If an interval crosses L runs, emit the ordered selectors and form each child by coalescing its stable LF slices. A quote selector is terminal. Reverse creation order is a child-before-parent topological order, so the F2 inverse stable merge applies without revisiting contracted nodes. When a terminal quote maps to row `x`, subtracting the beginning of F's quote bucket gives the exact token bucket's first index at its **first** terminal selector. This follows because no earlier L quote lies in the interval before this selector. No dictionary sort or duplicate rank lookup is needed.

**Lookup and marked output.** Each 64-row page has a 32-bit first-run index and a 64-bit mask of its interior run starts. One popcount gives the containing maximal run. A separate array contains each run's original start, LF start and byte. Rewinding to the first preceding quote transfers the primary before constructing the dictionary. An absent quote or a quote-free marked cycle falls back to Segmented. The leaf runs generate token Ψ in one 32-bit cell per section row, packing its successor and phrase ID with a checked field-width guard. The dictionary starts at the transient mark offset and then emits whole phrase slices until exactly the requested number of inverse bytes have been written. The kernel's production admission uses the same cap-density and sparsity pre-gates as LazyCells, with Segmented on all refusals.

**Resource result.** On 228 admitted large blocks the native implementation independently matched all 205,197,794 inverse bytes from Segmented. Discovery issued 19,750,839 page lookups, saved the same number of edge bytes, materialized 987,682 52-byte nodes, and wrote 4,313,576 selector records. The inverse merges processed 5,390,514 pieces. There were 30,868,395 token cells to build and 30,868,579 dependent token visits to expand. The separate dictionary stored 23,393,313 spelling bytes. The frozen arm's retained capacities for all navigation/dictionary vectors totaled 2,399,160 bytes; the one-worker corpus high water reached 5,060,464. These exclude the output vector, decoder and occasional fallback scratch. Whole-worker peak RSS still has to be measured.
