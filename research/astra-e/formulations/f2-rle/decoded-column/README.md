# Can the count edits move into the BWT itself?

Start with an original primitive cycle of n raw RLE1 bytes. Delete every true count row and insert k copies of its repeated byte in the same text gap. Call the new marked circular text T′. If its BWT could be updated cheaply, an ordinary inverse on that updated column would write final bytes directly. This is a formulation-level alternative to patching return spellings. The costs include classifying true counts, recovering their rows, ordering altered rotations, updating their predecessor labels and transferring the mark, before paying the inverse of the new column. Grammar-free order preservation is the initial falsifier here.

**Certificate of fixed relative order.** For each surviving literal position x let w be the raw substring from x up to, but excluding, the next count position on the circle. If w occurs at exactly one original row, its unique prefix still appears at x in T′. Two surviving rows with such a unique unchanged prefix retain their mutual order: their two prefixes cannot be prefix-comparable because both occur in the original text, so they have a first unequal byte before either prefix ends. When there are no count rows the entire rotation order is preserved. The statement concerns pairs of certified source rows. An inserted rotation or a changed uncertified rotation can still enter between them.

**Finding exceptions.** Start at each true count row. Walk backward on LF, extending the FM interval for the unchanged letters preceding it, stopping at a singleton or the preceding count row. Subsequent extensions before the preceding edit remain singleton because they contain the observed source occurrence and backward extension cannot increase width. Every surviving start visited at width greater than one is potentially displaced. Across all edits this uses at most one source traversal and two rank queries per candidate plus one final extension per edit, with O(V+h) natural sparse storage for V candidates and h edits. Sources with distinct cyclic rotations are required for this screen; the general marked-component fallback can handle periodic or malformed inputs. Production would use sparse FM navigation to materialize actual start identities. Here a dense original orbit, the full decoded text and cyclic doubling supply an independent checker.

**Exact lower and upper bounds on movement.** Delete the old count rows and look only at unchanged literal starts. Write their new cyclic ranks in original rank order. The complement of the longest increasing subsequence gives the minimum number of these original rows which must be extracted and reinserted to sort them. Independent new cyclic sorting also verifies strict monotonicity of **every** row outside the certified exception set. Frozen needs at least 89 literal moves, with an upper bound of 5,221 local rescans. There are 34 deleted source counts and 103 inserted letters. Across the nine systematic admissions the minimum varies from 34 to 223, the proven upper bound from 41 to 23,821, and the longest single context from 4 to 830. The worst observed gap in this sample is stream 134 with 214 necessary rows among 23,821 uncertified literals. These counts do not price the subsequent sorting of the uncertified set or justify constructing a dense suffix array during decoding. [All observations](geometry.csv) · [Exact checker](probe.rs)

An exact next screen is to merge the uncertified and inserted rotations into certified source ranks using corrected continuations, counting comparisons, symbols visited, compressed-rank calls, changed BWT run records and memory. The unknown is whether the interval-extension phase can approach the far smaller lower bound, or whether it already costs more than the parser avoided. Any primitive-cycle specialized worker needs an exact primitive/cut check and a full fallback.
