# Updating the marked cyclic BWT after exact RLE1 edits

For a circular string with fixed row identities, let Q(P) be the permutation obtained by sorting each position x by (first byte of x, rank in P of its successor). Q iterated d times sorts d-byte prefixes with P as continuation tie-breaker. For distinct rotations a fixed point of Q is therefore the cyclic suffix order, and iteration reaches it within n applications. A transient periodic intermediate text may have equal rotations; this primitive-cycle experiment can abort under an explicit cap and retain the original finish.

If the order of every row outside M is the same in P and P′, the order of every predecessor outside pred(M) is the same in Q(P) and Q(P′). Their first bytes agree with their previous keys, and their successors preserve relative order. In particular, after moving one active row, only its text predecessor needs reconsideration in the next application of Q. Its target in Q(P) is C[c]+rank_c(L_P, rank_P(succ(x))), where L_P holds the actual preceding byte in the current list order. If this target is its present position, Q(P)=P.

Replacing one byte initially changes only its own sort key. Deleting y initially drops its row from the original order. The surviving keys retain their relative order except possibly the predecessor a of y, whose successor changes to the following row j. For inserting a fresh symbol b just before j with former predecessor a, first place the new row among the old list minus a at C_old[b]−[F(a)<b]+rank_b(L_old, rank_old(j)). This counts rows other than a by their key relative to (b,rank_old(j)); a's own successor equals j, so the strict second term excludes it. Reinsert a's old slot into the coordinate system and insert the new row at that location. Now only a can be misplaced. Updating the L label at j and the row identities at each operation gives the true dynamic predecessor map. The verifier rebuilds and independently sorts the decoded primitive circle to check every final coordinate.

On the canonical frozen block, 34 semantic count edits required 125 elementary insertions/deletions/replacements. Sequential repair moved 6,638 rows, with a longest predecessor chain of 540. Stream 134 required 23,887 moves for 94 count edits, compared with a 214-original-literal minimum for the final simultaneous transformation. Single-edit propagation is exact but several independently updated sites can reorder the same contexts repeatedly. The page-based verifier maintains dense source identities and uses simple per-page character counts to measure this work. It supplies no claim of low worker memory. **Simultaneous changes.** Initially remove all count rows, placing each run of inserted bytes in the corresponding old slot. All surviving original rows preserve mutual order. For the first application of Q, an inactive row has its old byte and an old surviving successor. Two such rows retain their mutual order under the new keys, even with arbitrarily placed inserted rows between their successors. The initial active set may thus consist only of inserted rotations and surviving predecessors of count gaps. Calculate the target ranks in Q(P) of these active rows. Outside the set the current order is already correct. A row is retainable with all inactive rows exactly when its old and new gaps among them coincide. Within each coincident gap, a longest increasing subsequence of its target ranks preserves the largest subset that can stay without extracting an inactive row. Move the rest M by extracting all of them and reinserting at their sorted final target ranks. Now P′=Q(P). By the predecessor invariant only pred(M) need be active in the next epoch. An empty M proves a fixed point. Cyclic prefix expansion still supplies a finite primitive termination bound; a practical budget can reject difficult instances early.

Batching removes transient reorderings between similar edit sites. Stream 134 fell from 23,887 elementary row moves to 470 distinct move operations over 13 epochs with 631 rank queries. On stream 313 there were 74 actual moves versus 8,647 sequentially and a final 74-literal minimum. Frozen used 701 moves and 838 ranks over 30 epochs. Every final rank on all nine real blocks agreed exactly with independent cyclic sorting. The total absolute displacement can be large; a flat memmove for each relocation is inappropriate.
