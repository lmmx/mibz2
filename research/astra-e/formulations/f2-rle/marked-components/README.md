# Sparse count-byte substitutions for arbitrary marked cuts and overlapping cylinders

Let Ψ be the forward permutation of BWT rows and F its byte labels. H is the union of the backward-search intervals for bbbb over all bytes b. Protect D = H ∪ ΨH ∪ … ∪ Ψ⁴H. Designate a mark p and cut the predecessor edge into p. The goal here is the first marked **lap**, followed by a certificate deciding whether that lap supplies all n raw bytes required by bzip2. An unmarked component may use any cyclic convention with positive supplied mass.

**Boundary independence.** A complete RLE1 action consumes a group of four equal bytes followed by one count. Its five rows must belong to D by definition. Its decision inside a contiguous D fragment therefore cannot depend on bytes before an unprotected predecessor. Otherwise some action involving an outside byte would touch the fragment, contradicting the definition of D. More explicitly, a different parser state at the entry can only matter by consuming the first byte as a count or by completing a quartet that began before the entry. Either event places the outside predecessor in a five-row window. This also covers strands of one to three equal letters that begin before entry. They do not affect any substitution if their shared run ends before reaching four equal letters. Reset the parser at every D entry from outside and at p. Follow Ψ until the next unprotected row or return to p. Record each actual fifth row y as a substitution of k copies of b for its original single byte. In each fragment, recording a substitution resets the recognizer. Intersecting candidate windows thus charge only those events reached by the actual RLE1 parse. A pending count at a fragment exit is possible only just before p, because the next byte following the quartet is protected. Record that incomplete terminal quartet as an error flag.

**Wholly protected components.** A D cycle with no entry from outside and no mark is disjoint from the marked cycle. Give its rows unit mass and leave their bytes untouched. No parse convention on that cycle enters the result. A wholly protected marked cycle has an entry at p. Components with both dirty and clean rows all have identifiable dirty entries. These rules cover every permutation, including cycles shorter than a five-position window.

**Global mass.** Set G = n + Σ(k−1) over all substitutions so obtained. Every component has strictly positive assigned length. Within a parsed component, the actual five-position groups are disjoint after the cut; a group replaces just one byte and contributes at least four bytes. Clean bytes, cut incomplete quartets, and wholly unprocessed components retain positive length. On the primary's component its first lap spells exactly its assigned length. That length equals G if and only if the lap covers all n rows. When this condition holds, an incomplete terminal quartet is a real format error. When the marked cycle is shorter, the exact n-byte decoder falls back to parsing the repeated marked word through its true end. The error flag alone would incorrectly reject some partial cycles. For this certificate the four trailing equal bytes remain provisionally counted in the mass; on a genuine error stock's partial output excludes those four bytes.

**Work and limits.** Given exact H intervals and the sparse navigation structure from the compiled-cylinder construction, collect at most 5|H| rows and their Ψ-successors. Sorting and deduplicating uses O(|H| log(1+|H|)) comparisons, then at most |D| row visits and O(|D|) space recognize the events. Indegree membership or a sorted predecessor lookup identifies each fragment start. Components with no start need no traversal. No independent locator for raw text positions is assumed. To patch a retained edge, find the original owner and within-word offset of each substituted row as in the predecessor construction, or trace the aligned group starts with translated-interval bundling. A narrow event cap still legitimately rejects dense H; this theorem removes the disjointness and primary-placement restrictions, without claiming a bound on return-owner tracing. For canonical large Wikidata the earlier disjoint test already passed every event-admitted block, so this generality alone predicts no corpus speedup.

The independent test constructs dense Ψ and uses stock scalar RLE1, including partial output on errors. It checked all 917,506 marks on all binary last columns through n=15, including 766,826 with intersecting windows, 365,058 with protected marks, 691,486 with at least one wholly protected unmarked component and 40,446 truncated first-lap quartets. It checked exact lap bytes and error state before comparing the mass decision with the true orbit length. The earlier certificate applied to 125,680 of these marks.
