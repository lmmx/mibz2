# F2. Construct the BWT of delimiter-ended phrases by inverse stable merges

**Object and replaced phase.** The source is the capped RLBWT and the marked row. Choose a fixed set of delimiter bytes. Each byte interval between successive delimiters, including its ending delimiter, is one phrase. The algorithm constructs the phrase BWT by traversing suffixes of the phrases in FM order, then undoing local stable partitions. The residual is an ordinary BWT over a larger alphabet. A dense token Ψ table and a dictionary recover the complete marked byte sequence in this prototype. The previous delimiter constructor tracked each source interval separately through its forward refinements. Astra C instead learned translation certificates along the marked output cursor. The returned phrases are related to both, but here the order is recovered by inverse merges over disjoint suffix intervals. **Disjoint interval theorem.** For a nonempty word `w` in `(non-delimiter)* delimiter`, let `I(w)` denote its FM prefix interval. The entire language is prefix-free. Thus all nonempty intervals `I(w)` for distinct words are pairwise disjoint, even across depths in the trie whose edges add a byte on the *left*. This follows directly from stable LF occurrence matching. Equal-length cylinders partition the rows by their successive F emissions, and an interval for a longer compatible prefix lies inside its shorter prefix interval. This proof requires no single-cycle assumption. The rows whose future contains a delimiter belong to exactly one such interval. If there are `q` nonempty nodes and `r` maximal input runs, at most `q+r-1` nonempty run/node intersections can occur. Start with one piece per interval. Each additional piece crosses a different interior boundary of an L run. Recognition and the cost of finding each interval's first run are separate costs.

**Exact phrase-BWT construction.** A section row `b` has `L[b]` in the delimiter set. Section rows retain original rank order. At the filtered root, scanning L's delimiter runs selects one child `I(d)` per present delimiter. At `I(w)`, each intersected L run of a non-delimiter `c` selects rows of `I(cw)` by LF; they are stable and contiguous in their child interval. A delimiter selector terminates at completed word `w`. Build the leaf-label stream of each node from the children upwards. A terminal selector inserts repeated `w`. A child selector of width `k` takes the next `k` labels from that child's run stream. The invariant is that this stream labels each row of `I(w)`, in its **original endpoint order**, with the full phrase immediately preceding its associated section row. Stable selection proves the induction. The root is the phrase last column.

Distinct outgoing phrase words are prefix-free. Their suffix comparison agrees with the byte collation, and equal phrase words preserve relative rank under LF. A complete word `w` with interval beginning at `s` therefore has token-first-column start equal to the number of delimiter L bytes before `s`; its multiplicity is the number of those bytes inside `I(w)`. This supplies the token buckets without sorting the dictionary. The real-output validator checks every token successor, every phrase spelling and the complete marked inverse against independently stable-sorted dense Ψ.

**Mark and fallback.** Rewind from the primary by ordinary LF until the current L byte is a delimiter. This section row's compressed rank is its delimiter rank. The number of rewound bytes is the primary's offset in that row's outgoing phrase. Follow token Ψ, skipping that prefix once and emitting exactly `n` bytes, with truncation or repetition at a short cycle. If the rewind returns to the primary without a delimiter, its cycle has no representation in this section. The prototype signals fallback, and a production wrapper must dispatch to the original inverse. The worst-case mark-rewind work is a full marked orbit; a capped rewind with a normal fallback is another exact option.

**Charged work and initial result.** The example program includes the cap scan, maximal-run metadata, binary first-run lookup at every node, all selector intersections, dictionary copying, inverse-merging child run fragments, token-link construction, mark transfer and final spelling. It counts uncharged validator work separately by keeping the dense oracle outside the constructor. Frozen with quote produces 135,716 token rows, 2,716 distinct words and 6,133 token runs, matching the #371 token mass and completed pieces. Its 81,863 selector intersections and 18,994 emitted merge pieces coexist with 73,276 first-run searches, 83,454 materialized dictionary bytes and 135,716 constructed token links. Each emitted byte is still written. The previous 124,080 source-fragment visits and these differently priced counters give no timing ratio. All 12 real combinations match dense Ψ. **Falsifier and next experiment.** The simple trie stores 72 bytes of node fields per node, before selectors, token links and dictionaries. Its 70,560 nonroot quote nodes alone are 5.08 MB on frozen. Disjoint visits have not solved workspace or the dependent search for each node. On the three blocks, quote has respectively 66,872/70,561, 76,546/81,301 and 158,602/166,476 single-child alias nodes, counting the filtered root in those denominators. Inverse output for such a node is its child's output exactly. Contract maximal such chains into spelling bytes before creating node objects. The frozen representation would need only 3,689 remaining metadata objects if the root is also aliased. This counts potential compact objects; it still charges one row lookup and one spelling byte per discovered unary extension. A compact, fully reconstructing implementation is the test.

## Reproduction

The input SHA-256 is `82f65ace0731962d04443bbda4cebfdccd336106049751060f477941c2c29915`. The checked-in extractor uses the same public, research-only run-front interface as the scorer. Given a checkout at this experiment's commit and an already prepared corpus:

```sh
out=$(mktemp -d)
study=research/astra-e/formulations/f2
cargo build --release --locked --manifest-path bench/moonshot/Cargo.toml --target-dir "$out/build"
rustc --edition=2021 -O "$study/extract.rs" --extern mibz2="$out/build/release/deps/libmibz2.rlib" \
  -L dependency="$out/build/release/deps" -o "$out/extract"
"$out/extract" corpora/wikidata.bz2 "$out" > "$out/inputs.csv"
c++ -std=c++17 -O2 -Wall -Wextra -Wpedantic "$study/factor.cc" -o "$out/factor"
"$out/factor" small
"$study/census.sh" "$out" "$out/factor"
```

The small test exercises every primary and delimiter subset for binary columns of lengths 1–9 and ternary columns of lengths 1–6. Across 80,896 marks, 57,236 follow the section and 23,660 have a delimiter-free marked cycle. Both the success outputs and that fallback distinction are checked by the dense oracle. Tests run with assertions enabled.
