# Reconstructing the root token BWT from synchronized selector cursors

The contracted delimiter trie already contains stable partitions. At each node, its ordered selector stream says which child receives each rank, or that the word ends here. The node's expanded stream equals the root token-label stream projected onto terminals in its subtree. Filtering a node stream by one selector is precisely its child's order. Induction from the root proves the projection invariant even when the marked byte LF permutation has multiple cycles. The existing section-mark transport and second token induction can consume the resulting root stream unchanged.

Store one cursor and an offset per node. Descend from the root through the current selector to a terminal. The minimum remaining width of all selectors on this path is the length of the next run of this terminal label. Every row before that minimum follows the same path. At the next row, at least one exhausted selector changes. The highest exhausted selector either ends the traversal or chooses a different child or terminal. If it has no successor inside a child, its parent must also stop selecting this now-exhausted child. Distinct choices have disjoint terminal sets, and consecutive equal selectors were already coalesced. Thus precisely one maximal run is emitted at each descent. Advance only the cursors on the visited path. An unvisited subtree consumes no ranks.

Let V count contracted nodes, W distinct words, T root token runs, S selector pieces, and d(j) the number of visited nodes on the path of root run j. Treat the local terminal as an extra leaf when a node can also select children. Each nonleaf has at least two choices after contracting unary nonterminal edges. There are W leaves, hence V ≤ 2W−1. Each interior boundary of an emitted run exhausts a distinct nonfinal selector piece, so T ≤ S−V+1. At a given node the projected sequence has at most one run per root run which visits it. Materializing and storing every node stream needs M = Σᵥ R(v) pieces. Always M ≤ Σⱼ d(j). The cursor algorithm writes T result pieces, needs O(V) cursor state and O(max d) temporary path space, and does O(V + Σⱼ d(j)) work after discovery. It visits the path once to descend and once to advance. The original selectors, first dictionary, second induction and final output still incur their full costs. For a single word marker the earlier bound also gives T ≤ r, the number of original BWT runs. [Run bound](../f2-bounds/)

Across the 228 real admissions, root-only reconstruction writes 1,786,472 pieces. The materialized alternative wrote 5,390,514. Here the projection visits 7,739,733 nodes, each requiring cursor reads and updates. On the frozen block the respective counts are 6,133, 18,994 and 27,156. All 228 run counts and dictionary cardinalities match the materialized construction; all 205,197,794 inverse bytes match Segmented. The marked small-column property checks 11,264 admissions. On the nine systematic blocks with 30 rotations, merge CPU was 1.642 [1.310,2.058] of dynamic refill. The full inverse ratio was 1.019 [0.909,1.142] versus refill and 1.124 [1.036,1.219] versus Lazy. This establishes that intermediate streams can be eliminated, but the path visits are expensive on this host. The reported scratch capacity column in the older geometry harness omits the new path and existing second-level storage; it is unsuitable for a peak-RSS claim.
