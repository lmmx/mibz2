# Defer totals and admission until geometry exists

The reversible log permits late rejection. The MTF pass writes each log word and enforces the run-symbol limit without advancing a cumulative decoded-row counter or incrementing a virtual cap count. The subsequent paid iterator already advances a position to recover the marked geometry. It checks max_len before passing each run to the queue constructor, bounds speculative geometry by the maximum legal row count, and verifies the primary against the final row total. The retained count and post-primary strip count now directly certify the frozen edge budget. When the edge guard succeeds, cap density is irrelevant. When it fails, a log pass evaluates the exact virtual cap count; a rejected block restores its symbols and replays the stock complete worker. A successful direct run and a fallback therefore obey the original policy for any valid input. The malformed case may discover a different internal failure first; rolling back and replaying the original worker preserves the public error and output.

All 431 real blocks, their 209,700,196 final bytes and all verdicts in 252 full-worker comparisons agreed. Both in-place variants restored 33 nonempty rejected prefixes; the deferred arm had written 6,064,904 packed bytes across them because it could discover oversized input later.
