# Single two-bank selector

The 32-rank tables store each destination's source in one of two banks. In the 64 KiB form the active bank contains its four-bit source index and the other bank contains 0x80, the AVX2 zero-shuffle control. A single byte per destination holds (source % 16) OR (source bank × 128). Use this byte as the low-input shuffle control and toggle bit 7 for the high-input control. Exactly one shuffle contributes the original byte. This halves the immutable table to 32 KiB with the same exact coverage and every MTF, RLE2, and output dependency. Two XORs depend on the loaded controls and can execute independently of the previous MTF state. All 961 rank pairs and all 32 positions can be checked on the identity permutation, proving the substitution for arbitrary bytes by positional equivariance.

Run a separately frozen same-storage panel for copied stock, the 64 KiB wide table and the 32 KiB compact table, with the 383 true active fronts, 12 order-balanced repetitions at each of three stack depths and the same (admit/decline, length, actual cap records, both counters) gate. The complete wide/scalar evaluation remains independent. This tests the memory versus instruction trade; no locality or i9 throughput follows from the smaller object.

The compact implementation matched stock through 11,770 adversarial front cases and 431 real blocks, including every capped record, accepted length, and both counters on the successful fast path. The three fresh 12-pair process comparisons on shared scratch gave compact/wide ratios of 0.985, 1.025, and 1.024. The corresponding median arm times across processes ranged from 43.1 to 46.7 ms. Performance evidence here leaves the table-size improvement as a storage result. The 64 KiB complete worker and the ordinary scalar remain the unchanged candidates in the whole-process experiment.
